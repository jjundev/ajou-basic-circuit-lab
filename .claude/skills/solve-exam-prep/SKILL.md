# solve-exam-prep — 기말고사 대비 문제 풀이

기전실 프로젝트 `기말고사 대비/` 의 교재 문제를 **주차별 강의노트·정리노트·교재(책/)를 1순위 근거**로 풀고, concept-explain 의 "동기 → 핵심 통찰 → 근거 → 한 줄 요약" 철학을 문제풀이에 이식해 설명한다. 근거에 필요한 공식·정의가 없으면 책(교재) → 일반 회로이론 순으로만 보강하고, 그 사실을 본문에 밝힌다.

자매 스킬: `explain-lab-preview`(개념·원리 대화 설명) · `create-measurement-checklist`(측정 항목) · `make-lab-report-cover`(표지). 이 스킬은 그중 **"푸는" 짝**이며, 위 스킬들을 런타임 호출하지 않고 철학·인프라(PDF 템플릿)만 차용한다.

이 스킬은 이 프로젝트(`C:\Users\Hyunjun\Desktop\현준대학\기전실`) 안에서만 동작한다. cwd 가 다른 프로젝트면 자동 트리거되지 않는다.

이 스킬은 **풀이를 생성·저장**하지만, 소스 자료(강의노트·정리노트·교재 사진·보고서·manifest)는 **읽기만** 한다. 기존 파일을 수정하지 않는다.

## 입력 해석 (순서대로) — `manifest.csv` 가 인덱스

`기말고사 대비/manifest.csv` 스키마: `date,seq,kind,problem,file`
(예: `6월11일,1,new,10.39,01_new_10-39.png` → 6월11일 1번, 신규, 교재 문제 10.39, PNG 파일.)

1. **교재 ID**(`9.54`, `10.39`, `14.42`) → `problem` 컬럼 조회 → 그 행의 `file` 로 PNG 경로 확정.
   - 같은 ID가 `new`/`rev` 여러 행에 있으면 **`kind=new` 행을 우선**(동일 문제·동일 PNG). 없으면 가장 이른 날짜 행.
2. **날짜+번호**("6월11일 1번", "6월11일 첫 문제") → `date`+`seq` 조회 → PNG.
3. **날짜 단독**("6월11일", "6월11일 풀어줘") → 그 날짜의 모든 행 → **일괄 모드**(아래 「일괄·스케일링」).
4. **PNG 경로 / 스크린샷·이미지 첨부** → 그대로 문제 원본으로 사용(manifest 조회 생략).
5. **붙여넣은 문제 본문** → 그대로 사용(manifest 조회 생략).
6. 직전 대화에 미해결 문제가 있으면 그것.
7. 아무 단서도 없으면 한 줄로 묻고 대기:
   > 어느 문제를 풀까? (교재 ID `9.54` · 날짜+번호 `6월11일 1번` · 스크린샷 첨부)

**ID 미스**: manifest 에 없으면 시험범위 장(6·9·10·14)에 한해 `기말고사 대비/problems.pdf` 보조 조회. 그래도 없으면 "manifest·교재에서 `<ID>` 못 찾음 — 오타인지 확인하거나 스크린샷/본문을 붙여줘"라 안내하고 대기. 빈손 추정 풀이 금지.

## 문제 읽기 — PNG 가 ground truth

OCR 텍스트(problem_texts.json 등)는 없다. **항상 해당 PNG 를 Read 로 직접 읽어** 회로도·소자값·소스 표기(예: 100∠0° V rms)·다부분 (a)(b)(c) 를 확정한다. PNG 가 회로 그림을 포함하므로 텍스트만으로 추정하지 않는다. 다부분 문제는 **1문제로 센다**(공부계획 규칙: "9.12(a)(b)(c)는 1문제").

| 우선순위 | 패턴(Glob) | 비고 |
|---|---|---|
| 1 | `<N주차>/**/*정리노트*.pdf` | **보통 9주차만 존재.** 출처(교수 자료 vs AI 생성) 미확인이면 **강의노트와 동급**으로 취급하고, AI 산출 의심 신호가 있으면 책(교재)으로 강등. 인용 시 출처 라벨 필수. |
| 2 | `<N주차>/**/*강의노트*.pdf` | 전 주차 존재(경로 상이) |
| 3 | `<N주차>/책/*.{jpg,jpeg,png}` | 교재 원문 사진. 회로 정리·예제·공식의 직접 근거 |

| 5 | 일반 회로이론 | `⚠ 강의 밖` 라벨 |

**학생 보고서는 authority 에서 제외**(자기 답으로 자기를 검증하는 순환 방지): `*예비보고서*.md`, `*결과보고서*.md`, `output/*.md`, `보고서 by ai/`, `pre_review*`, `result_review*`. 읽지도 인용하지도 않는다.

### 단계 상승 규칙 (객관적)

문제에 필요한 **특정 정의·공식이 1순위 근거에 실제로 있으면 그것만 인용해 풀고**, **부재가 확인될 때만** 한 단계씩(강의노트 → 책 → 일반이론) 올리며 **상승 사실을 본문에 명시**한다(예: "강의노트에 최대전력전달 공식이 없어 교재 일반 이론으로 보강 — ⚠ 강의 밖"). 회로 해석 문제(주파수영역 node/mesh, Thevenin, 최대전력)는 lab 노트가 순수 이론을 안 담아 책/일반이론으로의 상승이 흔하다 — 매번 되묻지 말고 라벨 달고 바로 풀이한다.

## 출력 구조 — concept-explain 을 문제풀이에 이식 (6단)

단순 공식 대입이 아니라 "왜 이 도구인가 → 결정적 한 수 → 근거 → 검산" 흐름. 각 단계는 마크다운 헤더로 분리.

### 1. 문제 정리 (Setup)
PNG 에서 읽은 **주어진 것 / 구할 것**. 소스·소자값·주파수를 단위까지. 다부분 (a)–(d)는 표로.

### 2. 무엇을 묻고 왜 이 도구인가 (개념 동기)
이 문제가 시험하는 개념·기법(phasor 변환 / 임피던스 / 주파수영역 node·mesh / Thevenin / 최대전력전달 / 필터·공진)을 짚고, 그 접근이 **왜 자연스러운지** 동기 부여. 1순위 근거 인용. AC 정상상태 문제면 **phasor·임피던스 변환을 기본 접근**으로 삼고(시간영역 미분방정식 대신), 왜 그 변환이 자연스러운지 한 줄로 짚는다.

### 3. 핵심 통찰 (Aha)
이 문제를 푸는 **결정적 한 문장**. (예: "최대평균전력 ⇔ 부하 임피던스 = Thevenin 임피던스의 켤레 Z_L = Z_Th*.")

### 4. 풀이 (Worked solution)
단계별, 각 단계 근거 명시. 공식은 1순위 근거에서 인용. **복소수 산술을 명시**(직교↔극형식 변환 보이기). 모든 양에 단위. 복잡한 식·전달함수·piecewise 는 펜스 코드블록 또는 들여쓰기 0 독립 유니코드 줄(§수식 출력 계약).

### 5. 검산·직관 (Sanity check)
**전력 평형**(공급 = 소비), **극한 케이스**(필터 ω→0 / ω→∞, 공진 ω=ω₀), 크기·위상 타당성, 단위·차원, rms/peak 일관성. 1순위 근거가 짚은 흔한 함정 반영.

### 6. 한 줄 요약
> 인용블록 한 문장 — 이 문제가 각인시키는 개념.

**스케일링**: 단순 수치 계산이면 2·5단계는 짧게 줄여도 되나, **1·3·4·6 과 단위·근거 인용은 무조건**.

## 하드 규칙

1. **모든 물리량에 단위와 형식 명시** — Ω, V, A, W, VAR, VA, rad/s, Hz. 복소량은 직교(a+jb) 또는 극(M∠θ) 형식을 분명히. (확률 스킬의 `otherwise = 0` 에 대응하는 이 도메인의 하드 위생 규칙.)
2. **규약 선언 의무** — 매 풀이에서 다음 중 해당하는 것을 명시: rms vs peak(진폭), 각도 단위(° / rad), 각주파수 ω 값, 기준 노드, 임피던스 부호(인덕터 +jωL, 커패시터 −j/(ωC)), 전력의 ½ 계수(peak 진폭일 때 P = ½|I|²R, rms 면 P = |I_rms|²R), 전력 종류(유효 P / 무효 Q / 피상 S). **AC 회로 최대 오답원이 부호·rms/peak·½계수다.**
3. **AC(정현파 정상상태)는 페이저 우선** — 정현파 정상상태 문제는 시간영역 미분방정식이 아니라 **가능한 한 phasor·임피던스로 변환**해 푼다(Ch9 주파수영역 / Ch10 AC전력 / Ch14 필터·공진). 복소 임피던스 대수가 부호·rms/peak·위상 오류를 줄이고 1순위 근거(강의노트)의 접근과 맞는다. **예외**: Ch6 과도응답처럼 정상상태가 아닌 시간영역(시정수 τ·미분방정식) 문제는 페이저가 성립하지 않으므로 시간영역으로 푼다.
4. **1순위 근거 강제** — 강의노트/정리노트(또는 책)를 **실제로 열고** 정의·공식·접근을 인용. 없을 때만 상승, 그때 단계 상승을 본문에 명시.
5. **언어 한국어**. 직접 인용("정리노트에 따르면…")과 파생 결론("따라서…")을 분리.
6. **출력 = 채팅 응답 + 자동저장**. 생성한 풀이는 「저장 기능」대로 .md 자동저장(사용자가 "저장하지마" 하면 그 건만 생략). 기본 1문제씩(깊이 우선), 여러 개면 순차.
7. (선택) 복소수 다단계 계산이 무거우면 `python` 으로 수치 검증 가능하나 필수 아님 — 기본은 해석적 검산.

## 수식 출력 계약 (터미널 렌더링 강제 — 4중)

채팅·.md 출력 환경은 GFM 터미널이라 인라인 `$...$`·디스플레이 `$$...$$` 를 렌더링하지 않고 raw 로 노출한다 — `$B_L = -\dfrac{X_L}{R_l^2+X_L^2}$` 같은 소스가 날것으로 새고, 표 셀이 이를 더 악화시킨다(확랜 solve-problem 에서 사용자 확인). 모든 수식은 **터미널-네이티브 평문**으로만 출력한다. 이 계약은 (1) frontmatter description, (2) 본 섹션, (3) 6단 §4 풀이·「참고 예시」, (4) 「응답 전 자가 점검」 — 네 지점에서 중복 강제된다.

**1) 금지 (채팅·.md 출력에 0개):** 인라인 `$...$` · 디스플레이 `$$...$$` · 모든 LaTeX 매크로(`\frac` `\dfrac` `\begin{cases}` `\boxed` `\angle` `\cdot` `\sqrt` `\mathbb` `\text` `\left` `\right` …) · KaTeX/MathJax 문법 일체.

**2) 평문 표기:** 유니코드 기호 ∑ ∫ ∞ ≤ ≥ ≈ ⇔ → ∠ ∥ · × ± √ ² ³ ∴, 그리스 ω λ μ σ π Ω θ α β, 아래첨자 ₀–₉ ₙ ᵢ. 분수 = ASCII 슬래시 + 명시적 괄호: `1/(ωC)`, `(R₂)/(R₁+R₂)` — 분자·분모가 다항이면 각각 괄호, `a/b+c` 처럼 모호하게 쓰지 않는다. 변수·함수는 plain ASCII: Z, V, I, ω, H(jω), Z_Th, V_oc, I_sc, X_L, X_C. 복소: 100∠0° V, Z = 3 + j4 Ω = 5∠53.13° Ω.

**3) 복잡도 사다리 — 인라인/표 셀 vs 코드블록을 한 기준으로 결정:**
- **안전 (인라인·표 셀 허용):** 분수 바(`/`)가 0개이거나 괄호로 감싼 단순 비 1개 이내 + 중첩 없음 + 줄바꿈 없이 ~20자. 복소 합 `3 + j4 Ω`, 단순 비 `(R₂)/(R₁+R₂)`, 거듭제곱 `ω₀²`, 단순 거듭제곱 `e^(−jωt)` 등 포함.
- **코드블록/독립 줄 필수 (인라인·표 셀 금지):** 중첩 분수·case(piecewise)·전달함수·복소 다단계 전개·2줄 이상 유도·줄폭 초과. 펜스 코드블록 또는 들여쓰기 0 독립 유니코드 줄로 분리. piecewise·위상 스펙트럼의 코드블록 + ⎧⎨⎩ 는 이 경로의 **대표 사례(예외 아님)**.

**4) 표 셀 (예: §1 다부분 (a)–(d) 표):** 위 "안전" 식만. 분수·중첩·복소 전개가 필요하면 셀엔 라벨/참조(`Z_L → 식 ①`)만, 실제 식은 표 **밖** 코드블록/독립 줄로 뺀다.

**before → after 앵커:**

```
✗ $B_L = -\dfrac{X_L}{R_l^2+X_L^2}$
✓ B_L = −X_L / (R_l² + X_L²)
```

**적용 범위:** 이 계약은 **채팅·.md 출력에만** 적용한다. `pdf` 인자 산출 분기(「선택: PDF 산출」)는 MathJax 가 실제 렌더하므로 본문을 정식 LaTeX(`$...$`/`$$...$$`/`\frac` 등)로 **재작성**한다 — 유일한 예외이며, "verbatim 유니코드"는 채팅↔.md 에만 적용된다.

## new vs rev 차등 (spaced-repetition 존중)

- `kind=new` → 6단 전체.
- `kind=rev` → 공부계획 규칙("복습은 풀이를 외워서 쓰지 말고 식 세팅부터 다시")을 따른다: **처음부터 재유도**하되 채팅은 간결. 기존 `풀이/<id>.md` 가 있으면 "신규로 푼 풀이: [링크]" 한 줄 교차링크 후, 최신 재유도본으로 덮어쓴다.

## 일괄·스케일링

- **1문제** → 채팅에 6단 전체 + .md 저장.
- **날짜 일괄(>3문제)** → 1회만 확인: "N문제 순서대로 풀이·저장할게 — 채팅엔 핵심 통찰+최종값+한 줄 요약, 전체 6단은 .md" → 순차 풀이, 각 .md 저장.
- **≤3문제** → 전부 6단 전체.

## 인용 형식

- 정리노트/강의노트: `(N주차 강의노트, p.Y)`, `(N주차 정리노트, p.Y)`.
- 교재: `(교재 N장, 책/<파일명>)` 또는 `(Nilsson Ch.N.M)`.
- STT: `(N주차 STT, "<영상명 키워드>")`.
- 일반 지식(강의 밖): `⚠ 강의 밖` 라벨.

## 저장 기능 (.md 자동 내보내기)

**기본 동작: 자동저장.** 새로 생성한 풀이는 별도 요청 없이 .md 로 저장한다. "저장하지마"·"저장 생략"이면 그 건만 건너뛴다. 사용자 풀이 검토·개념 질의·단순 채팅은 저장하지 않는다.

- **저장 위치**: `기말고사 대비/풀이/` (없으면 생성 — Write 가 부모 디렉터리를 만든다). 경로에 공백·한글이 섞여 있으므로 **Write 는 절대경로**로 호출한다(메모리 [[korean-path-build-constraint]] 유의). 첫 저장이 실패하면 한 줄로 알리고 사용자 지정 경로를 받는다.
- **파일명**: `<장2자리>_<번호>_풀이.md` — 예 `09_54_풀이.md`, `10_39_풀이.md`, `14_42_풀이.md`. 점(.)→밑줄(_), 장은 두 자리 zero-pad(정렬). 단일 교재라 교재 접두사 불필요.
  - ID 없음(스크린샷/붙여넣기): 주제 슬러그 `<주제>_<핵심수치>_풀이.md` — 소문자·밑줄, 예 `max_power_transfer_thevenin_풀이.md`. 모호하면 `_<YYYYMMDD>` 접미.
- **덮어쓰기**: 같은 `_풀이.md` 가 있으면 덮어쓴다(최신본 우선 — 같은 ID 가 rev 로 재등장해도 파일 1개). `_풀이.md` 가 아닌 이름과 충돌하면 `_2`·`_3` 보존.
- **파일 내용**(YAML frontmatter 없음):
  1. `# <ID 또는 주제> 풀이` 제목.
  2. `> 출처: 교재 <장>장, <PNG 경로 또는 "사용자 첨부 이미지">, 1순위 근거 <N주차 강의노트 등 또는 "교재/일반이론">, 풀이일 <YYYY-MM-DD>` 한 줄.
  3. **문제 원문** — 자체 완결을 위해 반드시 포함. 이미지 문제는 본문을 **텍스트로 전사**(이미지 임베드 아님).
  4. **6단 풀이 전체** — 채팅에 보인 그대로(verbatim): 인라인 유니코드 + 코드블록/독립 줄. `$...$`·`$$...$$` 로 복원하지 않음(수식 출력 계약).
- **저장 후 보고**: 한 줄, 클릭 가능한 상대경로 — 예 `저장: [기말고사 대비/풀이/10_39_풀이.md](기말고사 대비/풀이/10_39_풀이.md)`. 디렉터리 생성·이름 충돌 접미 적용 시 그 사실도 한 줄.

## 참고 예시 (형식 시연 — 표기 모방용)

아래 `---` 사이가 예시 출력이다. 인라인=유니코드 "안전" 식, 복잡식=펜스 코드블록/독립 줄 을 그대로 모방한다(수식 출력 계약).

---

### 1. 문제 정리
전압원 100∠0° V (rms), 직렬 임피던스 Z_Th = 3 + j4 Ω. 부하 Z_L 을 조절해 **최대 평균전력**을 전달하라. 구할 것: (a) Z_L, (b) 최대 평균전력 P_max.

### 2. 무엇을 묻고 왜 이 도구인가
최대전력전달 문제. 가변 부하가 흡수하는 평균전력을 최대화하려면 부하를 어떻게 잡아야 하는가가 핵심. ⚠ 강의 밖 — 10주차 lab(주파수응답)에 이 정리가 없어 교재 일반 이론으로 푼다.

### 3. 핵심 통찰
최대 평균전력 ⇔ 부하가 Thevenin 임피던스의 **켤레**일 때. 즉 Z_L = Z_Th* (리액턴스를 상쇄해 순저항 회로로 만든다).

### 4. 풀이
(a) Z_Th = 3 + j4 Ω 이므로

```
Z_L = Z_Th* = 3 − j4 Ω
```

(b) 정합 시 부하저항 R_L = 3 Ω 양단에 걸리는 전류(rms):

```
I_rms = V_rms/(Z_Th + Z_L) = 100∠0° / ((3+j4) + (3−j4)) = 100/6 = 16.67 A (rms)
```

V_rms 를 썼으므로 ½ 계수 없이

```
P_max = I_rms² · R_L = (16.67)² × 3 ≈ 833.3 W
```

### 5. 검산·직관
정합 시 표준 결과 P_max = V_rms²/(4 R_Th) = 100²/(4·3) ≈ 833.3 W ✓. 리액턴스가 +j4 와 −j4 로 상쇄되어 순저항 6 Ω 회로가 된 것도 일치.

### 6. 한 줄 요약
> 최대 평균전력은 "부하 = Thevenin 임피던스의 켤레"로 리액턴스를 상쇄한 뒤 P = V_rms²/(4R_Th) 로 떨어진다.
