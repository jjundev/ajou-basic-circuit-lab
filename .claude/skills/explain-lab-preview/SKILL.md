# explain-lab-preview — 실험 전 맞춤형 프리뷰 설명

실험실에 들어가기 **전에**, 그 주차 실험이 "무엇을 왜 하는지"를 학생(신현준)이 가장 잘 이해하는 방식으로 미리 풀어주는 **대화형** 스킬이다. 문서를 생성하는 스킬이 아니라 **대화 자체가 산출물**이다. 그 주차의 예비보고서·강의노트·교재를 읽어 추상적 이론이 아닌 **그 주차의 실제 수치·절차에 grounding** 한 설명을 한다.

이 스킬은 이 프로젝트(`C:\Users\Hyunjun\Desktop\현준대학\기전실`) 안에서만 동작한다. cwd 가 다른 프로젝트로 바뀌면 자동 트리거되지 않는다.

이 스킬은 **read-only 교육 전용**이다. 예비보고서·측정값 파일을 수정하지 않고, 새 보고서 수치를 계산해 산출하지 않으며, 측정값을 채우지 않는다. 기존 수치는 **인용**할 뿐 새로 만들지 않는다. (값 계산·측정 채우기·표지 생성은 각각 create-measurement-checklist / fill-lab-measurements / make-lab-report-cover 의 영역이다.)

## 0. 학생 학습 프로파일 (이 스킬의 교수법 근간)

이 학생이 실험 전 설명을 잘 이해하는 방식. 메모리 [[lab-learning-style]] 와 동일한 내용을 교수법으로 박제한 것이며, **잠정(provisional)** 프로파일이다 — 매 주차 관찰로 갱신·반증한다 (§7 참조).

| # | 패턴 | 적용 |
|---|---|---|
| P1 | **비유 먼저, 수식 나중** | 추상 정의 전에 일상/물리 비유로 직관을 먼저 잡아준다. |
| P2 | **동기→한계→핵심통찰→예시** | 정의를 던지지 않고 "왜 필요한가"부터 빌드업한다. |
| P3 | **정밀 디테일 확인 욕구** | "정확히는 X가 아니라 Y" 식 경계 확인을 섹션마다 1개 이상 넣는다. |
| P4 | **구조를 스스로 일반화** | 조건 비교를 "통제 실험: 변수 하나만 바꿈" 프레임으로 제시한다. |
| P5 | **표 비교 선호** | 비교·매핑은 산문 대신 표로 보여준다. |
| P6 | **대화형 페이싱** | 한 번에 다 쏟지 않고 덩어리마다 "다음 뭐 볼까" 메뉴로 끊는다. |
| P7 | **점진적 난이도 하강** | 앞서가서 막히면 수식을 걷어내고 일상 비유 단독으로 리셋한다. |

## 1. 입력 해석

`ARGUMENTS` 토큰을 해석한다.

- `N주차` 토큰 → 프로젝트 루트(cwd 에서 상위로 올라가며 `.claude\` 가진 가장 가까운 디렉토리) 아래의 `<N주차>` 폴더를 `WEEK_DIR` 로 사용. 폴더 부재면 거절.
- 디렉토리 경로 → 그 디렉토리를 `WEEK_DIR` 로 사용.
- `쉽게` 또는 `처음부터` 포함 → **난이도 하강 모드**로 시작 (비유 비중 ↑, 수식 최소화; P7 을 사전 옵션으로 노출).
- `저장` 포함 → 대화 종료 시 프리뷰 요약을 `<WEEK_DIR>\output\<N>주차_실험프리뷰.md` 로 옵션 저장 (§6).
- `pdf` 포함 → 프리뷰를 `<WEEK_DIR>\output\<N>주차_실험프리뷰.html` + `.pdf` 한 쌍으로 산출 (§8). `저장`과 독립·조합 가능.
  - **세션 스냅샷**: 대화가 진행된 뒤 `pdf` 요청 → 그때까지 다룬 내용을 캡처.
  - **일괄 생성**: 대화 없이 `/explain-lab-preview 14주차 pdf` → 소스에서 [1]~[5] 전 섹션을 구성해 한 번에 산출.
- 주차 토큰이 없으면 한 줄 안내 후 종료:
  > 어느 주차 실험을 미리 볼까요? 예: `/explain-lab-preview 14주차` (쉽게 / 저장 / pdf 옵션 추가 가능)

## 2. 소스 디스커버리 (grounding 의무)

`WEEK_DIR` 에서 다음을 순서대로 찾아 `SOURCES` 로 수집한다. 설명이 목적이므로 **예비보고서를 1순위로 적극 인용**한다.

| 우선순위 | 패턴 | 용도 |
|---|---|---|
| 1 | `<WEEK_DIR>\output\*예비보고서*.md` | 실제 수치·Table 구조·절차의 주 grounding 소스 |
| 2 | `<WEEK_DIR>\강의노트\*.pdf` 또는 `<WEEK_DIR>\*강의노트*.pdf` | 실험 목적·교수 강조점 |
| 3 | `<WEEK_DIR>\책\*.jpg`/`*.jpeg`/`*.png` | 교재 그림·절차 원문 |
| 4 | `<WEEK_DIR>\연습문제\`, `<WEEK_DIR>\STT\` | 보조 |

예비보고서 다중 매치 시: `ver\d+`/`v\d+` 최대 버전 → mtime 최신 → `(수정본)`/`_final`/`_최종` 우선.

명시 **제외** (검토 메타파일 — 읽지도 노출하지도 않음): `pre_review*.md`, `pre_review_theory*.md`, `result_review*.md`, `*결과보고서*.md`. 숫자는 예비보고서에서만 인용한다.

소스가 **하나도 없으면** 거절하지 말고 degrade: 개념 수준 프리뷰만 제공하되 첫 줄에 "이번 주차는 grounding 파일이 없어 일반 이론 위주입니다" 를 명시한다.

## 3. 설명 흐름 (페이싱 규칙)

**[1] 오프닝만 자동 출력한다.** [2]·[3]·[4] 는 **메뉴 선택으로만 진입**하며, 절대 자동으로 이어 쓰지 않는다. 각 덩어리 끝에서 멈추고 §5 메뉴를 제시한 뒤 학생의 선택을 기다린다 (P6).

### [1] 오프닝 — 큰 그림 + 비유 (항상 먼저, 약 1화면)

- 그 주차 실험을 **한 문장**으로 ("이번엔 직렬 공진 회로").
- **물리/일상 비유 1개**로 직관 제공 (P1). 비유 시드:

  | 도메인 | 비유 |
  |---|---|
  | 공진 (resonance) | 종 / 그네 — 잘 울리면 Q 큼 |
  | RC 과도응답 | 물통 채우기·배수 |
  | 커패시터 | 물탱크(전하 저장) |
  | 인덕터 | 회전바퀴·관성(전류 변화 저항) |
  | 필터 | 체(특정 주파수만 통과) |
  | 분압/분류 | 수도관 분기 |

  시드에 없으면 그 자리에서 적절한 비유를 생성한다.
- **비유 ↔ 회로 매핑 표** (P5).

### [2] 핵심 개념 빌드업 (메뉴 진입)

그 주차의 가장 중요한 개념 1~2개를 **이 스킬 안에서 직접** 다음 7단계 흐름으로 설명한다 (외부 스킬 호출/위임이 아니라 **인라인 재현** — concept-explain 과 동일한 철학이되 자립적으로 수행).

1. **왜 이 개념이 필요한가** (동기·문제 상황)
2. **단순 해법은 왜 안 통하나** (해당 시)
3. **핵심 통찰** (한 문장 Aha)
4. **왜 작동하나** (수식·직관)
5. **구체적 예시** (그 주차 실제 수치 사용)

규칙:
- 정의를 맨 앞에 던지지 않는다 (P2).
- **정밀 디테일 1개 이상 의무** (P3): "정확히는 X가 아니라 Y" 형태의 경계 확인.
- 비-elementary 용어는 그 자리에서 한 줄 정의.

### [3] 실험 구조 — "각 단계가 뭘 확인하나" (메뉴 진입)

예비보고서의 Table 순서대로, 각 Table 의 **목적**(무엇을 검증하려는가)을 한 줄씩. 측정 절차 나열이 아니라 "왜 이걸 측정하나" 중심.

### [4] 조건/Part 비교 — 통제 실험 프레임 (해당 시, 메뉴 진입)

여러 Part·조건이 있으면 "변수 하나만 바꾸는 통제 실험" 으로 프레이밍 (P4) 하고 비교 표 (P5):

| 구분 | 고정 변수 | 독립 변수(바뀐 것) | 종속 변수(따라 바뀐 것) |
|---|---|---|---|

## 4. 톤·렌더링 (대화/터미널 출력)

- 한국어, 친근한 존댓말. **이모지 금지**.
- **수식은 평문 표기** — 이 대화 출력은 GFM 터미널이라 LaTeX(`$...$`)가 렌더되지 않고 날 소스로 그대로 노출된다 (메모리 [[terminal-no-latex-render]]):
  - 인라인: 구분자 없이 평문. 아래첨자는 언더스코어(`X_C`, `f_p`, `Z_Tp`), 제곱은 유니코드 `²`, 그 외 위첨자는 `^n`.
  - 기호는 유니코드: `ω π μ Ω Γ λ ℓ √ ≈ ≤ ≥ ≠ ⇔ → · × ∞`. 허수단위 `j` 와 삼각함수 `sin cos tan cot` 등은 그대로.
  - 분수는 슬래시+괄호: `a/b`, `(R² + X_L²)/R`. 음수·뺄셈은 ASCII `-`.
  - 블록/전개 수식은 펜스 코드블록(` ``` `)에, 한국어 라벨이 섞인 동치 chain은 독립 프로즈 행에 `⇔` 로.
- 비교·매핑은 표. 단, **표 셀에는 짧은 표현만**(스칼라·부호·방향·단어) — 분수-합/다항식은 셀에 넣지 말고 표 밖 코드블록·독립 행으로.
- 짧은 문단, 섹션 헤더로 분리.
- 그 주차 실제 수치를 인용할 때는 출처가 예비보고서임이 드러나게 (단, "pre_review"·"STT" 같은 내부 파일명은 노출하지 않는다).
- **주의 — 평문 표기는 대화/터미널 출력에만 적용**한다. `pdf` 산출(§8)의 HTML 본문은 반대로 **LaTeX `$...$`/`$$...$$` 를 그대로** 쓴다 (MathJax 가 SVG 로 렌더). 두 경로의 수식 표기를 혼동하지 말 것: 대화=평문, PDF=LaTeX.

## 8. PDF 산출 (`pdf` 인자일 때만)

프리뷰를 미니멀 모노크롬 A4 **HTML + PDF 한 쌍**으로 산출한다. 디자인 톤은 make-lab-report-cover / create-measurement-checklist 와 통일한다. **이 스킬은 read-only 교육 전용** 원칙을 유지한다 — PDF 는 `output\` 에 새로 추가되는 학습 아티팩트일 뿐, 예비보고서 등 기존 소스/보고서 파일은 절대 수정하지 않는다.

### 8.1 파이프라인

```
프리뷰 내용 → {{CONTENT}} HTML 본문 작성 → template.html 치환
  → Write 로 <N>주차_실험프리뷰.html 저장 → Playwright 로 .pdf 변환
```

**Edge `--print-to-pdf` 를 쓰지 않는다.** Edge 헤드리스는 file:// 경로·페이지번호·날짜 머릿글을 억제 플래그를 무시하고 항상 박아 넣어 footer 와 충돌한다 (create-measurement-checklist SKILL.md 에서 검증됨). 반드시 **Playwright + Chromium** `_html_to_pdf.py` 를 쓴다 (`display_header_footer=False`).

### 8.2 템플릿 치환

`Read` 로 `C:\Users\Hyunjun\.claude\skills\explain-lab-preview\template.html` 를 읽고 5개 placeholder 를 모두 교체:

| placeholder | 값 |
|---|---|
| `{{TITLE}}` | `<N>주차 실험 프리뷰` |
| `{{DATE}}` | 오늘 날짜 `yyyy.MM.dd` (`Get-Date -Format 'yyyy.MM.dd'`) |
| `{{MATHJAX_SRC}}` | 로컬 번들 `…\explain-lab-preview\mathjax\tex-svg.js` 의 **file URI** (`.resolve().as_uri()`). 로컬 파일이 없을 때만 CDN `https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-svg.js` 로 폴백 |
| `{{FONT_SRC}}` | 로컬 번들 `…\explain-lab-preview\fonts\PretendardVariable.woff2` 의 **file URI** (`.resolve().as_uri()`). 이 가변 폰트가 있어야 디자인이 의도한 300/400/500/600 굵기가 렌더된다. 없으면 시스템이 Malgun Gothic(400·700만)으로 폴백해 600 굵기 강조·헤딩이 곧장 풀 볼드로 튀어 "글씨가 갑자기 두꺼워지는" 현상이 생긴다. 로컬 파일이 없을 때만 CDN `https://cdn.jsdelivr.net/npm/pretendard@1.3.9/dist/web/variable/woff2/PretendardVariable.woff2` 로 폴백 |
| `{{CONTENT}}` | 본문 HTML (아래 §8.3) |

수식은 본문에 LaTeX `$...$` / `$$...$$` 를 **그대로** 넣는다 — 이 PDF 경로는 §4 평문 표기 규칙의 **명시적 예외**다 (MathJax 렌더 대상이므로 LaTeX 가 맞고, 평문으로 바꾸면 수식 품질이 떨어진다). template 의 MathJax(SVG 출력, 폰트 불필요 단일 파일)가 렌더한다. 별도 markdown→HTML 라이브러리·콘텐츠 빌더는 쓰지 않는다 (본문은 직접 HTML 작성).

### 8.3 본문 구조 (스킬 흐름 미러링)

§3 흐름 순서로, **세션에서 실제 다룬 섹션만** `<h2>` 로 구성. 일괄 생성 모드면 [1]~[5] 전체. 구성요소:
- `<h2>` 섹션 제목, `<h3>` 하위, `<p>` 서술
- 비유·강조는 `<div class="callout">`, 한 줄 요약은 `<div class="summary">`
- 비교·매핑은 `<table>`
- 옴(Ω) 등 기호는 HTML 엔티티(`&#937;`) 또는 유니코드로
- 다루지 않은 메뉴 섹션이 있으면 말미에 "이번 프리뷰에서 다루지 않은 항목: …" 한 줄

### 8.5 오프라인

MathJax 는 로컬 `mathjax\tex-svg.js`(약 2 MB, SVG 출력이라 웹폰트 불필요) 를 우선 사용하므로 **네트워크 없이도 수식이 렌더**된다. 로컬 번들이 사라졌고 오프라인이면 CDN 폴백도 실패해 수식이 raw 로 보일 수 있음 — 이 경우 한 줄 안내.

본문 폰트도 같은 방식으로 로컬 `fonts\PretendardVariable.woff2`(약 2 MB, 가변 폰트 한 장으로 전 굵기 커버) 를 우선 사용해 **네트워크 없이도 의도한 굵기로 렌더**된다. `@font-face` 에 `local('Pretendard Variable')` 을 먼저 두므로 시스템에 Pretendard 가 설치돼 있으면 그것을, 없으면 번들 woff2 를, 둘 다 없고 오프라인이면 Malgun Gothic 으로 폴백한다(이 경우 600 굵기가 700 으로 뭉쳐 강조가 진해짐).
