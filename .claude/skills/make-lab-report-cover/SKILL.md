# make-lab-report-cover

기초전기실험 보고서의 첫 장에 들어가는 표지를 한 번의 요청으로 생성하는 스킬이다.
디자인은 미니멀 모노크롬 A4 한 장이고, 같은 폴더에 HTML과 PDF가 함께 떨어진다.

## 기본값 (사용자가 명시적으로 다른 값을 주지 않으면 그대로 사용)

| 필드 | 기본값 |
|---|---|
| 학부 (`DEPARTMENT`) | 전자공학과 |
| 과목명 (`COURSE`) | 기초전기실험 |
| 교수명 (`PROFESSOR`) | 권혁준 교수님 |
| 분반 (`CLASS_SECTION`) | C088-3 |
| 학번 (`STUDENT_IDS`) | 202128508, 202220953, 202320724 |
| 성명 (`STUDENT_NAMES`) | 최승민, 신현준, 염지성 |
| 제출일 (`SUBMIT_DATE`) | 오늘 날짜 (`YYYY.MM.DD`) |
| 제목 (`TITLE`) | 사용자 입력 (예: "10주차 예비보고서") |

## 실행 절차

1. **제목 추출.** 사용자 메시지에서 보고서 제목을 뽑는다 (예: "10주차 예비보고서", "5주차 결과보고서"). 못 찾으면 한 줄로 되묻고 중단.

2. **출력 폴더 결정.**
   - 사용자가 폴더를 명시하면 그 폴더.
   - 제목에 `N주차` 패턴이 있고 현재 작업 디렉토리에 `N주차/` 폴더가 존재하면 그 폴더.
   - 그 외에는 현재 작업 디렉토리.

3. **충돌 확인.** `<폴더>/<제목> 표지.pdf` 가 이미 존재하면 덮어쓸지 한 줄로 확인.

4. **오늘 날짜 획득** (사용자가 제출일을 명시한 경우 그 값 사용).
   ```powershell
   Get-Date -Format 'yyyy.MM.dd'
   ```

5. **템플릿 치환.** `Read` 로 `C:\Users\Hyunjun\.claude\skills\make-lab-report-cover\template.html` 을 읽고 아래 8개 placeholder를 모두 교체한다:
   - `{{TITLE}}`, `{{COURSE}}`, `{{CLASS_SECTION}}`, `{{DEPARTMENT}}`,
   - `{{SUBMIT_DATE}}`, `{{PROFESSOR}}`, `{{STUDENT_IDS}}`, `{{STUDENT_NAMES}}`

6. **HTML 저장.** `Write` 로 `<폴더>/<제목> 표지.html` 에 결과를 쓴다.

7. **PDF 변환.** Edge 헤드리스로 변환:
   ```powershell
   & "${env:ProgramFiles(x86)}\Microsoft\Edge\Application\msedge.exe" `
     --headless --disable-gpu --no-margins `
     --print-to-pdf="<폴더>\<제목> 표지.pdf" `
     "file:///<폴더>/<제목> 표지.html"
   ```
   실패하면 에러를 그대로 사용자에게 노출 (HTML 은 유지).

8. **결과 안내.** 생성된 HTML, PDF 두 파일의 markdown 링크를 한 줄로 출력하고 종료.

## 자연어 오버라이드 규칙

사용자가 "교수님 김철수로", "분반 D012-1", "제출일 2026.05.20" 등을 같이 말하면 해당 필드만 다른 값으로 치환한다. 별도 옵션 파싱 문법은 없다. 명시되지 않은 필드는 표의 기본값을 그대로 쓴다.

## 비-목표

- 결과보고서/예비보고서를 별도 템플릿으로 나누지 않는다 (제목 문자열만 다르고 디자인 동일).
- 다른 과목/학과 정보를 영속 저장하지 않는다 (자연어 오버라이드로 충분).
- PDF 시각 비교 자동화는 하지 않는다 (사용자가 미리보기로 확인).
