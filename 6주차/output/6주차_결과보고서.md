# 고찰

## 결과 분석

본 실험은 RC 회로의 DC 정상 상태 특성(Ch 15)과 과도 응답 특성(Ch 16)을 분석하는 것을 목적으로 한다.

Ch 15의 DC 정상 상태 실험에서는 전반적으로 매우 우수한 일치를 보였다. Table 15.1의 단순 RC 직렬 회로에서 이론적으로 전류가 0이고 저항 양단 전압이 0(V)인데, 실측에서 V₁ = 7.3(mV)의 미세한 잔류 전압이 관측되었다. 이는 커패시터의 완전한 충전 이후에도 미세한 누설 전류가 존재함을 의미한다. V₂는 10(V) 대비 10.041(V)로 0.41%의 차이를 보였으며, 이는 DC 파워 서플라이의 출력 정밀도에 기인한다. Table 15.2의 R₁-R₂-C 혼합 회로에서는 모든 항목이 1% 미만의 오차를 나타내었다. I₁은 0.32%, I₂는 0.76%, V₁은 0.69%의 차이를 보였고, V₂와 V₃는 각각 0.02%로 거의 완벽한 일치를 보였다. I₂(0.76%)가 I₁(0.32%)보다 다소 큰 오차를 보이는 것은, 전류 측정 시 멀티미터를 직렬로 삽입하는 위치에 따른 내부 저항 부하 효과의 미세한 차이로 해석된다. Table 15.4에서도 정상 상태의 이론적 예측이 잘 확인되었으며, V₃와 V₄는 각각 0.18%와 0.23%의 낮은 오차를 보였다. V₁과 V₂는 이론값이 0(V)이므로 절대오차로 표기하였으며, 각각 0.60(mV)와 1.37(mV)로 무시할 수 있는 수준이었다.

시정수 측정(Table 15.5)에서는 이론값 9.844(s) 대비 실측 10.13(s)로 2.91%의 차이가 나타났다. 이는 정상 상태 측정보다 상대적으로 큰 오차인데, 시정수를 수동으로 측정하는 과정에서 전압이 최종값의 63.2%에 도달하는 시점을 정확히 판별하기 어렵기 때문이다. Table 15.6에서 측정된 커패시턴스 값은 100(μF) 공칭에 대해 102.91(μF), 220(μF) 공칭에 대해 257.42(μF)로, 각각 2.91%와 17.01%의 편차를 보였다. 220(μF) 커패시터의 큰 편차는 전해 커패시터의 넓은 허용오차(일반적으로 ±20%)에 해당하는 범위 내에 있다.

Ch 16의 과도 응답 실험(Table 16.2)에서는 충전 초기 구간에서 오차가 크고 중간 이후 구간에서 오차가 감소하는 특징적 패턴이 관측되었다. t = 10(s)에서 8.55%, t = 20(s)에서 5.92%, t = 30(s)에서 5.12%로 초기 오차가 높았으나, t = 50(s)에서 0.38%, t = 60(s)에서 0.05%까지 감소하였다. 이후 t = 100(s) 이상에서는 1.6~2.3% 범위의 오차가 다시 나타났다. 초기 구간의 높은 오차는 충전 시작 시점의 전압 변화 속도가 빠르기 때문에 10초 간격의 이산적 측정으로는 지수 곡선의 급변 구간을 정확히 포착하기 어렵기 때문이다. 후반부의 오차 재증가는 커패시터 전압이 전원 전압에 근접하면서 측정 전압의 절대 변화량이 매우 작아져(0.1~0.3(V) 단위), 멀티미터 분해능의 상대적 영향이 커지기 때문으로 분석된다. Table 16.3의 국소 선형회귀 분석에서 1τ 시점의 측정값 7.76(V)은 최종값 12(V)의 64.7%로, 이론적 63.2%에 근접하였으며, 25(s) 시점에서 이론식 6.07(V)과 회귀 추정값 6.34(V)의 4.44% 차이는 측정값 기반 그래프 추정의 한계를 반영한다.

## 오차 원인

커패시터의 공칭값과 실측값의 차이가 주요 오차 원인이다. 100(μF) 공칭 커패시터의 실측값이 102.91(μF)로 2.91% 편차를 보였고, 220(μF) 공칭 커패시터는 257.42(μF)로 17.01%의 편차를 보였다. 전해 커패시터는 일반적으로 ±20%의 넓은 허용오차를 가지며, 이 편차가 시정수 τ = RC 계산에 직접 반영되어 과도 응답 곡선의 시간축 이동을 유발한다. Ch 16의 병렬 합성 커패시턴스 C_T = 360.33(μF)는 공칭 합산값 320(μF) 대비 12.6% 큰 값으로, Table 16.2의 충전 곡선 전체에 체계적 오차를 발생시켰다.

가변저항(R = 98.44(kΩ))의 설정 오차도 시정수에 영향을 미쳤다. 가변저항은 아날로그 다이얼 방식으로 미세 조정에 한계가 있으며, 100(kΩ) 목표값 대비 1.56%의 설정 오차가 존재하였다. 이 오차는 시정수 τ = RC에 선형적으로 반영되므로, 커패시터 오차와 결합하여 Table 15.5의 2.91% 오차에 기여하였다.

시정수의 수동 측정 과정에서 발생하는 판독 오차가 있다. 충전 전압이 최종값의 63.2%에 도달하는 시점을 멀티미터 디스플레이를 관찰하며 스톱워치로 기록하는 방식이므로, 인적 반응 시간(약 0.2~0.5초)이 포함된다. τ = 9.844(s) 기준으로 0.3초의 반응 지연은 약 3%의 오차에 해당하며, 이는 Table 15.5의 실측 오차 2.91%와 부합한다.

DC 파워 서플라이의 출력 정밀도 역시 오차 원인 중 하나이다. Table 15.1에서 V₂가 10.041(V)로 설정값 10(V) 대비 0.41%의 차이를 보였고, Table 15.4에서도 V₃ = 10.018(V), V₄ = 10.023(V)로 0.18~0.23%의 편차가 관측되었다. 파워 서플라이의 출력 분해능이 약 0.01(V) 수준이므로 정밀 설정에 한계가 있으며, 이 전원 전압 편차가 모든 전압·전류 측정의 기준값에 영향을 준다.

멀티미터의 측정 정밀도와 내부 저항 부하 효과도 기여하였다. 전류 측정 시 멀티미터를 직렬로 삽입하면 수 Ω의 내부 저항이 추가되어 회로의 총 저항이 미세하게 증가한다. Table 15.2에서 I₂(0.76%)가 I₁(0.32%)보다 큰 오차를 보인 것은 멀티미터 삽입 위치에 따른 부하 효과 차이로 설명된다. 또한 Table 15.1과 15.4에서 이론값이 0인 항목의 잔류 전압(7.3(mV), 0.60(mV), 1.37(mV))은 멀티미터의 영점 오프셋과 커패시터 누설 전류의 복합 효과이다.

## 개선 방안

커패시터 실측값 편차를 줄이기 위해, 실험 전에 LCR 미터로 커패시턴스를 정밀 측정하여 이론 계산에 반영하는 것이 바람직하다. 특히 전해 커패시터(220(μF))처럼 허용오차가 큰 소자는 여러 개 중 공칭값에 가장 근접한 것을 선별하여 사용하면 체계적 오차를 줄일 수 있다.

가변저항의 설정 정밀도를 높이기 위해, 저항값을 설정한 후 멀티미터로 실측 확인하는 과정을 반복하여 목표값에 최대한 근접시키는 것이 좋다. 다이얼 조정 후 안정화 시간을 충분히 확보하고, 접촉 불량 여부도 확인해야 한다.

시정수 수동 측정의 판독 오차를 개선하기 위해, 오실로스코프를 활용하여 충전 곡선을 실시간으로 기록하고 커서 기능으로 63.2% 도달 시점을 정밀하게 결정하는 방법을 적용할 수 있다. 이를 통해 인적 반응 시간에 의한 오차를 제거할 수 있다.

DC 파워 서플라이 출력 편차를 보정하기 위해, 실험 시작 전 멀티미터로 실제 출력 전압을 측정하여 기록하고, 이 값을 이론 계산의 전원 전압으로 사용해야 한다. 이를 통해 전원 전압 기준의 체계적 오차를 제거할 수 있다.

멀티미터 내부 저항에 의한 부하 효과를 최소화하기 위해, 내부 저항이 충분히 낮은(수 mΩ 급) 정밀 전류 측정기를 사용하거나, 멀티미터의 내부 저항값을 사전에 실측하여 회로 총 저항에 보정값으로 반영하는 방법을 적용할 수 있다. Table 15.2에서 I₂(0.76%)가 I₁(0.32%)보다 큰 오차를 보인 것은 멀티미터 삽입 위치에 따른 내부 저항 부가 효과의 차이에 기인하므로, 측정 후 내부 저항분을 차감 보정하면 오차를 줄일 수 있다.

과도 응답 측정의 시간 분해능을 향상시키기 위해, 충전 초기 구간(0~30(s))에서는 5초 간격으로 측정하고, 변화가 완만한 후반 구간(100(s) 이후)에서는 20초 간격으로 측정하는 가변 간격 방식을 적용하면, 급변 구간의 포착 정확도를 높이면서 측정 효율도 유지할 수 있다.

## 결론

본 실험에서 DC 정상 상태 분석(Ch 15)의 오차율은 대부분 1% 미만으로 매우 우수하였으며, 최대 오차는 Table 15.2의 I₂에서 0.76%였다. 시정수 측정은 2.91%의 오차를 보였으나, 이는 수동 측정의 한계를 고려하면 합리적인 수준이다. 과도 응답 분석(Ch 16)에서는 충전 초기 구간 최대 8.55%(t = 10(s))에서 중간 구간 최소 0.05%(t = 60(s))까지 시간에 따라 오차가 변동하였으며, 전체적으로 0.02~8.55% 범위의 오차율을 보였다. 커패시터가 정상 상태에서 개방 회로로 동작하는 특성과, 충전 과정에서 지수 함수적 전압 변화를 따르는 과도 응답 특성이 실험적으로 확인되었다. 특히 1τ 시점에서 최종값의 64.7%(이론 63.2%)에 도달하고, 5τ 시점에서 97.6%(이론 99.3%)에 도달하는 결과는 RC 회로의 시정수 개념이 실험적으로 유효함을 입증한다. 전반적으로 DC 정상 상태 해석과 RC 과도 응답 이론이 실험 결과와 잘 일치하며, 실험 목적을 충분히 달성하였다.
