# 실험 목적

## Ch 13 Series Resonant Circuits (직렬 공진 회로)

- 직렬로 R-L-C가 연결된 회로에서 주파수 변화에 따른 각 소자의 전압 및 회로 전류를 이론적으로 계산하고, 실험을 통해 확인한다.
- 공진 주파수(resonant frequency) f_s = 1/(2π√(LC))를 이론적으로 계산하고, 실측 V_R 피크 위치와 비교하여 확인한다.
- 공진 주파수에서 직렬 RLC 회로의 임피던스 Z_i가 R(최소)이 되고 전류 I가 최대가 됨을 확인한다.
- Quality factor Q와 대역폭 BW의 관계(BW = f_s / Q)를 확인하고, R 값을 바꾸어 Q를 증가시켰을 때 선택도(selectivity)가 어떻게 변하는지 비교한다.
- **Part 1 (Low-Q, R = 220 Ω)**: 비교적 낮은 Q를 가지는 회로에서 V_C, V_L, V_R, I, Z_i의 주파수 응답을 측정하여 Table 13.2를 완성하고, Graph 13.1에 Z_i 곡선을 그린다.
- **Part 2 (High-Q, R = 33 Ω)**: 동일한 L, C 값에 대해 직렬 저항을 33 Ω으로 낮춰 Q가 증가했을 때 공진 곡선의 첨예도가 어떻게 변하는지를 Part 1과 비교하여 확인하고, Table 13.7을 완성한다.

# 실험 이론

## 직렬 RLC 회로의 임피던스와 공진 조건

- **개념**
    - 직렬 R-L-C 회로의 전체 임피던스:
        - Z_T = R + j(ωL − 1/ωC) = R + jX
        - 여기서 X = ωL − 1/ωC (리액턴스 성분)
    - 공진 조건: 허수부 X = 0, 즉 ωL = 1/(ωC)
        - ω² = 1/(LC) → ω_s = 1/√(LC) → f_s = ω_s/(2π) = 1/(2π√(LC))
    - 공진 시 Z_T = R (순 저항, 최소값), 전류 I = E/R (최대값), 입력 전압과 전류가 동상.

- **적용 방법**
    - Part 1·Part 2 공통: L = 10 mH = 1.0 × 10⁻² H, C = 0.1 μF = 1.0 × 10⁻⁷ F
        - LC = 1.0 × 10⁻⁹, √(LC) = 3.162 × 10⁻⁵ s
        - ω_s = 1/√(LC) = 1/(3.162 × 10⁻⁵) ≈ 31,623 rad/s
        - f_s = ω_s/(2π) ≈ 31,623 / 6.283 ≈ 5,033 Hz
    - 공진점에서 X_L = ω_s L = 31,623 × 0.01 ≈ 316.23 Ω, X_C = 1/(ω_s C) = 1/(31,623 × 1×10⁻⁷) ≈ 316.23 Ω.
    - 검산: X_L − X_C ≈ 316.23 − 316.23 = 0 Ω → Z_T(f_s) = R + j·0 = R ✓ (허수부 소거로 공진 조건 닫힘).

## 유도성·용량성 부하와 위상 관계

- **개념**
    - f < f_s: 1/(ωC) > ωL → X < 0 → 회로가 **용량성(capacitive)** → 전류가 전압보다 위상 앞섬.
    - f > f_s: ωL > 1/(ωC) → X > 0 → 회로가 **유도성(inductive)** → 전류가 전압보다 위상 뒤짐.
    - f = f_s: X = 0 → 순 저항성, 전류·전압 동상.
    - canonical 부호: ∠Z = ∠V − ∠I, E를 기준(∠V_E = 0)으로 두면 ∠I = −∠Z. 유도성에서 ∠Z > 0 → ∠I < 0 (뒤짐), 용량성에서 ∠Z < 0 → ∠I > 0 (앞섬).

- **적용 방법**
    - Part 1, f = 1,000 Hz일 때:
        - X_L = 2π·1000·0.01 = 62.83 Ω
        - X_C = 1/(2π·1000·1×10⁻⁷) = 1/6.283×10⁻⁴ ≈ 1,591.5 Ω
        - X = X_L − X_C = 62.83 − 1591.5 = −1528.7 Ω → 용량성 (전류가 전압보다 앞섬).
        - 검산: |Z| = √(R² + X²) = √(220² + (−1528.7)²) ≈ √(48,400 + 2,336,924) ≈ 1,544 Ω → I = E/|Z|로 매우 작아짐. f → f_s일수록 |Z| → R로 줄어들어 I가 증가하는 경향과 일치.
    - 교재 Part 1 (m) 절차에서 R을 C 위치에 옮긴 뒤 E와 V_R을 dual-trace로 동시에 보고 동상이 되는 주파수를 찾으면 그 주파수가 공진 주파수 f_s임을 시각적으로 확인할 수 있다 (V_R ∝ I 이므로 V_R의 위상 = I의 위상).

## 공진 곡선: V_R, V_L, V_C의 주파수 응답

- **개념**
    - 직렬 회로이므로 I는 모든 소자에 공통, V_R = I·R 이므로 V_R은 I와 같은 형태 (공진점에서 피크).
    - V_C = I/(ωC), V_L = I·ωL.
    - 공진점에서 V_L = V_C (X_L = X_C 이고 같은 전류이므로 크기 동일).
    - 그러나 V_C와 V_L의 *피크 위치*는 f_s와 살짝 어긋남: V_C는 f_s 약간 *이전*(f < f_s 부근, 분모 ωC 작아져 V_C 커짐과 I 변화의 곱이 극값), V_L은 f_s 약간 *이후*(f > f_s 부근)에서 피크 (교재 Fig 13.2 참조).
    - 공진 시 전압 확대 효과: V_C(f_s) = V_L(f_s) = Q · E_input (Q에 따라 입력 전압의 수 배 이상으로 커질 수 있음).

- **적용 방법**
    - Part 1 (R = 220 Ω, 이상적 인덕터 가정 R_l ≈ 0), 공진점 f_s ≈ 5,033 Hz에서:
        - I_p-p(max) = E_S / R = 4 / 220 ≈ 18.18 × 10⁻³ A ≈ 18.18 mA_p-p
        - V_R(p-p) = I·R = 18.18 mA × 220 Ω = 4.00 V_p-p (= E_S, 회로 전체가 R뿐이므로)
        - V_L(p-p) = I·X_L = 18.18 × 10⁻³ × 316.23 ≈ 5.75 V_p-p
        - V_C(p-p) = I·X_C = 18.18 × 10⁻³ × 316.23 ≈ 5.75 V_p-p
        - 검산 (KVL, 페이저 합): √(V_R² + (V_L − V_C)²) = √(4.00² + 0²) = 4.00 V_p-p = E_S ✓ (V_L과 V_C가 위상 180° 차로 상쇄되어 V_R만 남음).

## Quality Factor Q와 전압 확대

- **개념**
    - 직렬 공진 회로의 Q (양호도):
        - Q = ω_s L / R = 1/(ω_s C R) = (1/R)·√(L/C)
        - 유도: Q_L = V_L/V_AC = (IωL)/(IR) = ωL/R, Q_C = V_C/V_AC = (I/ωC)/(IR) = 1/(ωCR), Q = √(Q_L · Q_C) = (1/R)·√(L/C).
    - Q는 공진 회로의 선택도(selectivity) 척도. Q가 클수록 공진점이 첨예하고 좁은 주파수 대역만 통과.
    - 공진 시 V_C = V_L = Q · E_input (R이 작을수록 Q가 커지고 전압 확대 비율 증가).

- **적용 방법**
    - L = 10 mH, C = 0.1 μF → √(L/C) = √(0.01/10⁻⁷) = √(10⁵) ≈ 316.23 Ω.
    - Part 1 (R = 220 Ω):
        - Q_1 = (1/R)·√(L/C) = 316.23 / 220 ≈ 1.437
        - V_C(f_s) = Q_1 · E_S = 1.437 × 4 ≈ 5.75 V_p-p
        - 검산: 위 "공진 곡선" 적용 방법에서 I·X_C로 구한 5.75 V_p-p와 일치 ✓
    - Part 2 (R = 33 Ω):
        - Q_2 = 316.23 / 33 ≈ 9.583
        - V_C(f_s) = Q_2 · E_S = 9.583 × 4 ≈ 38.3 V_p-p
        - 검산: I_p-p(max) = 4 / 33 ≈ 121.2 mA → V_C = 0.1212 × 316.23 ≈ 38.3 V_p-p ✓
    - Q_2 / Q_1 ≈ 9.583 / 1.437 ≈ 6.67 배 → R을 220 Ω → 33 Ω으로 줄이면 Q가 약 6.7배 커지고 공진 곡선이 그만큼 더 첨예해진다.

## 반전력 대역폭(Half-Power Bandwidth)

- **개념**
    - 전력이득 A_P = 10 log(P_o/P_i) = −3 dB가 되는 점, 즉 전력이 ½이 되는 두 주파수를 f_1(낮은 쪽), f_2(높은 쪽)로 정의. P = I²R 이므로 −3 dB는 전류 비율 I_o/I_i = 1/√2 ≈ 0.707에 해당.
    - 대역폭: BW = f_2 − f_1 = f_s / Q.
    - 대역 안에서 I ≥ 0.707·I_max, 대역 끝점에서 정확히 0.707·I_max.
    - BW가 좁을수록 회로가 더 선택적(selective) — 작은 R, 큰 Q.

- **적용 방법**
    - Part 1 (Q_1 ≈ 1.437):
        - BW_1 = f_s / Q_1 = 5,033 / 1.437 ≈ 3,502 Hz
        - 0.707·I_max(p-p) = 0.707 × 18.18 mA ≈ 12.85 mA → 이 전류에 도달하는 두 주파수 사이의 폭이 약 3.5 kHz.
        - 검산: BW = f_s/Q 와 BW·Q = f_s 관계로 3,502 × 1.437 ≈ 5,033 Hz = f_s ✓
    - Part 2 (Q_2 ≈ 9.583):
        - BW_2 = 5,033 / 9.583 ≈ 525 Hz
        - 0.707·I_max(p-p) = 0.707 × 121.2 mA ≈ 85.7 mA → 더 좁은 약 525 Hz 폭 안에서만 이 전류 이상 유지.
        - 검산: BW · Q = 525 × 9.583 ≈ 5,033 Hz = f_s ✓
    - BW_1 / BW_2 ≈ 3,502 / 525 ≈ 6.67 배 → Q가 6.67배 커진 만큼 BW는 같은 비율로 좁아진다 (BW · Q = f_s 일정).

## 코일 내부 저항 R_l 의 영향

- **개념**
    - 실제 인덕터는 권선 저항 R_l을 가지므로 회로의 실제 총 저항은 R_T = R + R_l.
    - 공진 시 Z_min = R_T = R + R_l (R만이 아님).
    - 따라서 실제 측정 시 I_max = E / R_T 가 되어 이상적 가정 I = E/R보다 약간 작게 나옴.
    - Q_actual = ω_s L / R_T < ω_s L / R (이상적 Q).

- **적용 방법**
    - 본 예비보고서의 이론 예측치는 이상적 인덕터(R_l ≈ 0) 가정으로 계산한다.
    - 실험 시 학생은 DMM으로 R_l을 측정하여 Table 13.1의 R_l measured 칸 및 Part 2 Table 13.6에 기록하고, 결과보고서에서 R_T = R + R_l을 사용해 측정값과의 차이를 분석한다.
    - 본 예비보고서 본문의 Z_i, I_max, Q, V_L, V_C 등의 예측치는 R_l = 0 가정 하의 값이므로 결과보고서에서 R_l 영향을 보정한 후 비교할 것.
