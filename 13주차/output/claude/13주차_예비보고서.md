# 실험 목적

## AC Ch 10 Series-Parallel Sinusoidal Circuits
- 직렬 및 병렬로 연결된 R-L, R-C, R-L-C 회로에 교류 전원을 가할 때, Kirchhoff's voltage law(KVL)와 Kirchhoff's current law(KCL)가 페이저(phasor) 합 의미에서 성립함을 확인한다.
- 각 소자(R₁, R₂, L, C)에 걸리는 전압과 회로에 흐르는 전류 I_s, I₁, I₂를 측정하고, 전원 전압 E를 기준으로 각 전류의 위상차를 구한다.
- Fig 10.5의 R-L-C 직렬-병렬 회로에서 명판값으로부터 입력 임피던스 Z_T를 계산하고, 측정값(V_R₁, V_R₂로부터 Ohm의 법칙으로 환산한 I_s)과 비교한다.
- 페이저 다이어그램을 작도하여 KCL(I_s = I₁ + I₂의 페이저 합)을 시각적으로 검증한다.

## AC Ch 12 Thevenin's Theorem and Maximum Power Transfer
- 실험을 통하여 AC 회로에서도 Thevenin's theorem이 성립함을 확인한다 — 즉 원회로(Fig 12.4)와 Thevenin 등가회로(Fig 12.5)가 임의의 부하 R_L(1 kΩ, 6.8 kΩ)에 대해 동일한 V_RL을 만들어 내는지 검증한다.
- Thevenin's theorem이 DC 회로와 AC 회로에 적용되는 경우의 차이를 알아낸다 — DC에서 Z_Th가 순저항(스칼라)이었던 반면 AC에서는 복소 임피던스(크기와 위상각)임을 이해한다.
- Z_Th를 두 가지 방법(① 명판값/측정 저항값을 이용한 직접 해석, ② Eq. (12.1) |Z_Th| = E_pp/I_pp와 sensing 저항 R_s를 이용한 실험적 결정)으로 구하고 두 결과를 비교한다.
- 최대 전력이 부하에 전달되는 조건 |Z_L| = |Z_Th|, θ_L = -θ_Th를 이해하고, Fig 12.7에서 R_L 고정·C 가변(Part 3) 및 C 고정·R_L 가변(Part 4) 두 절차로 Maximum power가 전달되는 부하 값(X_C 또는 R_L)을 계산해 보고, 실험을 통하여 확인한다.

# 실험 이론

## 정현파 정상상태 임피던스와 Ohm의 법칙(페이저)

- **개념**
    - 각 소자의 페이저 임피던스
        - Z_R = R (실수)
        - Z_L = jωL = jX_L,  X_L = 2πfL (양의 허수)
        - Z_C = 1/(jωC) = -jX_C,  X_C = 1/(2πfC) (음의 허수)
    - 직렬 결합: Z_series = Z_1 + Z_2 + … + Z_n
    - 병렬 결합: 1/Z_parallel = 1/Z_1 + 1/Z_2 + … + 1/Z_n,  두 임피던스만 있을 때 Z_parallel = Z_1·Z_2/(Z_1+Z_2)
    - 페이저 Ohm 법칙: I = V/Z (모두 페이저)
    - 유도(인덕터 임피던스): v_L(t) = L di/dt에 i(t) = I_m sin(ωt) 대입 시 v_L = LωI_m cos(ωt) = LωI_m sin(ωt + 90°) → 페이저비 V_L/I = jωL → X_L = ωL = 2πfL.
    - 유도(커패시터 임피던스): i_C(t) = C dv/dt에 v(t) = V_m sin(ωt) 대입 시 i_C = ωCV_m cos(ωt) = ωCV_m sin(ωt + 90°) → 페이저비 I/V_C = jωC → Z_C = V_C/I = 1/(jωC) = -j/(ωC) → X_C = 1/(ωC) = 1/(2πfC) (V_C가 I보다 90° 뒤짐).

- **적용 방법**
    - 본 실험의 모든 회로(Fig 10.5, 12.4, 12.6, 12.7)에서 f = 10 kHz이므로 ω = 2π × 10⁴ ≈ 62 831.85 rad/s.
    - 인덕터 L = 10 mH: X_L = 2π × 10⁴ × 10⁻² = 628.32 Ω → Z_L = j628.32 Ω.
    - 커패시터 C = 0.02 μF: X_C = 1/(2π × 10⁴ × 2×10⁻⁸) = 795.77 Ω → Z_C = -j795.77 Ω.
    - Fig 10.5 R-L 가지의 임피던스 예시: Z₁ = R₁ + jX_L = 1000 + j628.32 = 1181.01 ∠32.14° Ω (직각 → 극좌표 변환: |Z| = √(R² + X²), θ = tan⁻¹(X/R)).
    - 검산: |Z₁|² = R² + X_L² → 1181.01² = 1 394 785, R² + X_L² = 10⁶ + 394 786 = 1 394 786, √오차 < 0.001% (소수점 절사 오차) ✓.

## Kirchhoff의 법칙(KVL·KCL)의 페이저 형태

- **개념**
    - KVL: 임의의 폐회로(loop)를 따라 페이저 전압의 대수합은 0 — 즉 E = V_1 + V_2 + … (모두 페이저 합, 단순 산술합이 아님).
    - KCL: 임의의 노드에서 들어오는 페이저 전류의 합 = 나가는 페이저 전류의 합 — 즉 I_s = I_1 + I_2 + … (페이저 합).
    - 두 페이저 V₁, V₂ 가 직교(예: 저항 전압 V_R과 리액턴스 전압 V_X)일 때 크기 관계: |E|² = |V_R|² + |V_X|² (Pythagoras).

- **적용 방법**
    - Fig 10.5의 상단 노드(전원 + 단자가 분기되는 점)에서 KCL: I_s = I_1 + I_2 (페이저 합). 페이저 다이어그램(Part 3(j))에서 I_s 벡터를 I_1과 I_2 벡터합으로 작도하여 검증.
    - Fig 10.5의 R-L 가지 KVL: E = V_R₁ + V_L (페이저 합). R-L 직렬에서 V_R₁ ⊥ V_L (90°)이므로 |E|² = V_R₁² + V_L².
    - 수치 예시 (Fig 10.5, E = 4 V_pp): R₁ = 1 kΩ, X_L = 628.32 Ω → |Z₁| = 1181.01 Ω, |I_1(p-p)| = 4/1181.01 = 3.387 mA_pp, V_R₁(p-p) = I_1 × R₁ = 3.387 V_pp, V_L(p-p) = I_1 × X_L = 2.128 V_pp.
    - 검산: √(V_R₁² + V_L²) = √(3.387² + 2.128²) = √(11.472 + 4.528) = √16.000 = 4.000 V_pp ≈ E = 4 V_pp (KVL ✓).

## Thevenin's Theorem (AC)

- **개념**
    - 임의의 선형 양단(two-terminal) AC 네트워크는 등가 전압원 E_Th와 직렬 등가 임피던스 Z_Th로 대체할 수 있다.
    - 절차 (Résumé of Theory, 교재 p400 7단계):
        1. 부하 R_L을 제거한다 (open-circuit).
        2. 전압원은 단락, 전류원은 개방으로 치환한다.
        3. Z_Th = 부하 단자에서 본 등가 임피던스 (위상 포함).
        4. 모든 전원을 복원한다.
        5. E_Th = 부하 단자 사이의 open-circuit 전압 (위상 포함).
        6. Thevenin 등가회로 (E_Th in series with Z_Th)를 그리고 R_L을 복원.
        7. 부하의 전류/전압을 I = E_Th/(Z_Th + Z_RL) 등으로 구한다.
    - 핵심 공식 (lecture note p4-5): E_Th = E · Z_2/(Z_1 + Z_2),  Z_Th = Z_1 ∥ Z_2.
    - 유도(E_Th): 부하 개방 시 회로 = E + Z_1 + Z_2 직렬, 부하 단자 양단의 페이저 전압 = Z_2 양단 전압 = E · Z_2/(Z_1+Z_2) (페이저 전압 분배 법칙).

- **적용 방법**
    - Fig 12.4의 R_L 단자에서 본 Thevenin 변환:
        - Z₁_source-side = R₁ = 1.2 kΩ (전원과 노드 A 사이 직렬 저항).
        - Z₂_source-side = R₂ = 3.3 kΩ (노드 A에서 GND로 연결되는 병렬 저항).
        - 부하 가지에 Z_L_series = jX_L (L = 10 mH)이 R_L과 직렬로 더 들어 있음. 이 jX_L 부분은 R_L과 함께 부하 측으로 또는 Z_Th에 흡수할 수 있는데, Fig 12.5에서 Thevenin 등가가 Z_Th 안에 L을 포함하는 형태로 그려졌으므로 jX_L도 Z_Th에 포함.
        - Z_Th = (R₁ ∥ R₂) + jX_L  (R_L 제거 후, 전원 단락 시 노드 A에서 본 임피던스 (R₁∥R₂) + 그 위에 직렬로 jX_L).
    - 수치 예시 (Fig 12.4, 명판값, E = 4 V_pp, f = 10 kHz):
        - R₁ ∥ R₂ = (1.2 × 3.3)/(1.2 + 3.3) = 3.96/4.5 = 0.880 kΩ = 880 Ω.
        - X_L = 2π × 10⁴ × 10⁻² = 628.32 Ω.
        - Z_Th = 880 + j628.32 = 1081.29 ∠35.53° Ω.
        - E_Th = E · R₂/(R₁ + R₂) = 4 · 3.3/4.5 = 2.933 V_pp (R₁, R₂가 순저항이므로 위상각 0°).
        - 부하 R_L = 1 kΩ 연결 시: I = E_Th/(Z_Th + R_L) = 2.933/((880+1000) + j628.32) = 2.933/(1880 + j628.32) = 2.933/(1982.22 ∠18.49°) = 1.480 ∠-18.49° mA_pp. V_RL(p-p) = I × R_L = 1.480 V_pp.
    - 검산 (KVL): V_ZTh = I · Z_Th = 1.480 ∠-18.49° × 1081.29 ∠35.53° = 1.600 ∠17.04° V_pp. V_RL = 1.480 ∠-18.49° V_pp. 페이저 합 V_ZTh + V_RL의 실수부 = 1.600 cos17.04° + 1.480 cos(-18.49°) = 1.530 + 1.404 = 2.934; 허수부 = 1.600 sin17.04° + 1.480 sin(-18.49°) = 0.469 − 0.469 ≈ 0. |합| ≈ 2.934 V_pp ≈ E_Th = 2.933 V_pp (KVL ✓, 소수점 절사 오차 < 0.1%).

## Z_Th 실험적 결정 (Sensing 저항법)

- **개념**
    - 원회로의 전원을 단락으로 치환하는 대신, 부하 단자에서 새로운 전원을 가하고 sensing 저항 R_s로 흘러 들어가는 전류를 측정하면 Z_Th의 크기를 Eq. (12.1)로 결정할 수 있다.
        |Z_Th| = E_pp / I_pp,  I_pp = V_Rs(p-p) / R_s_measured.
    - Z_Th의 위상각은 E와 V_Rs(전류 I와 같은 위상)의 위상차로부터 구한다 — 오실로스코프의 듀얼 트레이스로 dt를 읽고 θ = 360° × dt/T (T = 1/f).
    - 유도(Eq. 12.1): 부하 단자에 E_pp가 인가될 때 sensing 저항 R_s 양단에 V_Rs가 측정됨. I_pp = V_Rs/R_s가 회로 전체에 흐르는 전류이고, Z_Th = E/I = E_pp/I_pp.

- **적용 방법**
    - Fig 12.6에서 R_s = 10 Ω를 부하 단자에 직렬 삽입한 뒤 E = 4 V_pp(10 kHz)를 인가하고 V_Rs(p-p)와 위상차 θ를 측정.
    - Part 1 해석으로 구한 Z_Th(= 880 + j628.32 Ω, |Z_Th| ≈ 1081.29 Ω, θ_Th ≈ 35.53°)와 비교하여 Thevenin 등가 임피던스가 실험적으로도 같은 값을 보임을 검증.
    - 수치 예시: |Z_Th| = 1081.29 Ω → I_pp = E_pp/|Z_Th| = 4/1081.29 = 3.699 mA_pp → V_Rs(p-p) = I_pp × R_s = 3.699 × 10 = 36.99 mV_pp.
    - 검산: V_Rs = I × R_s이고 I = E/(Z_Th + R_s) 이지만 R_s(10 Ω) ≪ |Z_Th|(1081 Ω)이므로 (Z_Th + R_s) ≈ Z_Th. 이 근사로 인한 오차는 R_s/|Z_Th| × 100% ≈ 0.92%로 무시 가능 ✓.

## Maximum Power Transfer Theorem (AC)

- **개념**
    - AC 회로에서 부하 임피던스가 Thevenin 임피던스의 켤레복소수와 같을 때, 즉 Z_L = |Z_Th| ∠ -θ_Th  =  R_Th − jX_Th 일 때 부하에 전달되는 전력 P_L이 최대가 된다.
    - 결과적으로 두 조건이 동시에 만족: ① R_L = R_Th (저항 성분 일치), ② X_L_load = -X_Th (리액턴스 부호 반대·크기 같음 — 인덕성 source면 용량성 load).
    - 부하에 전달되는 전력:
        P_L = V_ab(rms)² / R_L = ((1/√2)(V_ab(p-p)/2))² / R_L = V_ab(p-p)² / (8 R_L)  (Eq. (12.2)).
    - 유도(P_L): V_ab(rms) = V_ab(p-p)/(2√2), P = V²/R 이므로 P_L = (V_ab(p-p))²/((2√2)² R_L) = V_ab(p-p)²/(8 R_L).

- **적용 방법**
    - Fig 12.7은 직렬 R-L-C-R_L 회로 (전원 → R(470 Ω) → L(10 mH) → C(가변) → R_L(가변 potentiometer) → GND).
    - 소스/부하 경계 분해 (Thevenin의 정리 관점): R과 L이 source 측, C와 R_L이 부하 측 — 따라서
        - Z_Th = R + jX_L  (소스측 Thevenin 등가 임피던스, 인덕성).
        - Z_L = R_L − jX_C  (부하측 임피던스, 용량성).
    - 최대 전력 전달 조건 Z_L = Z_Th*  →  ① R_L = R, ② X_C = X_L (즉 Z_L = R − jX_L 이 Z_Th = R + jX_L 의 복소켤레).
    - Part 3: R_L = R_measured (≈470 Ω 고정 = R) 이미 ① 조건 만족된 상태에서 C를 7가지 (0.0047, 0.01, 0.0147, 0.0247, 0.047, 0.1, 1 μF)로 변경하여 ② 조건(X_C = X_L)을 만족하는 C를 탐색. X_C = X_L에서 Z_L + Z_Th = (R + R_L) + j(X_L − X_C) = 2R + 0 (순저항)이 되어 회로 전체가 공진하고 R_L에 최대 전력 전달.
    - 공진(X_C = X_L) 조건의 C: C = 1/(ω² L) = 1/((2π×10⁴)² × 10⁻²) = 1/(3.948×10⁹ × 10⁻²) = 1/(3.948×10⁷) ≈ 25.33 nF = 0.02533 μF (Table 12.3의 0.0247 μF에 매우 근접).
    - 수치 예시 (공진 조건, R_L = 470 Ω, R = 470 Ω, X_L = X_C = 628.32 Ω, E = 4 V_pp):
        - Z_Th = 470 + j628.32 Ω, Z_L = 470 − j628.32 Ω → Z_Th + Z_L = 940 + j0 Ω (순저항).
        - I_pp = E_pp/|Z_Th + Z_L| = 4/940 = 4.255 mA_pp (공진으로 허수 상쇄).
        - V_ab(p-p) = I_pp × R_L = 4.255 × 10⁻³ × 470 ≈ 2.00 V_pp (V_ab는 R_L 양단의 페이저 전압 — 교재 Fig 12.7 / Table 12.3 정의).
        - P_L = V_ab(p-p)² / (8 R_L) = (2.00)² / (8 × 470) = 4.00 / 3760 ≈ 1.064 mW (= I_pp² R_L / 8). R_L이 순저항이고 V_ab는 R_L 양단 전압이므로 V_ab²/(8R_L) 공식이 직접 적용 가능하며, peak-to-peak → rms 환산에서 1/(2√2)² = 1/8 인자가 들어간다.
    - 검산 (최대 전력 조건 Z_L = Z_Th*): Z_Th = 470 + j628.32 = 783.49 ∠53.21° Ω, Z_Th* = 470 − j628.32 = 783.49 ∠-53.21° Ω. 공진 C에서 Z_L = R_L − jX_C = 470 − j628.32 = 783.49 ∠-53.21° Ω → Z_L = Z_Th* (✓ 크기·위상 부호 모두 일치).
    - Part 4: C = C_max-power = 0.0247 μF로 고정(X_C ≈ X_L 으로 ② 조건 근사 만족)한 뒤 R_L을 100·300·400·500·600·800·1000 Ω로 가변하여 ① 조건(R_L = R)을 탐색. X_C ≈ X_L 근사 하에서는 Z_Th + Z_L ≈ (R + R_L) + j0 이 되어 회로 전류 I_pp ≈ E_pp/(R + R_L) 이고 부하에서 소비되는 평균 전력은
        - P_L = I_pp² R_L / 8 = E_pp² R_L / [8 (R + R_L)²]  (peak-to-peak → rms 환산의 1/8 인자 포함)
    - 수치 예시 (R_L = 470 Ω = R, E = 4 V_pp, X_C = X_L 가정): I_pp = 4/940 = 4.255 mA_pp, V_ab(p-p) = I_pp × R_L = 4.255 × 10⁻³ × 470 ≈ 2.00 V_pp, P_L = (4.255×10⁻³)² × 470 / 8 = 8.51×10⁻³ / 8 ≈ 1.064 mW (평균 전력). 동일하게 V_ab²/(8 R_L) = (2.00)²/(8 × 470) ≈ 1.064 mW 로 일치.
    - 검산 (∂P_L/∂R_L = 0): P_L(R_L) = E_pp² R_L/(R + R_L)², ∂P_L/∂R_L = E_pp²[(R + R_L)² − 2R_L(R + R_L)] /(R + R_L)⁴ = E_pp²(R − R_L)/(R + R_L)³ = 0 ↔ R_L = R. 양 극단 R_L → 0 또는 ∞에서 P_L → 0이므로 R_L = R = 470 Ω이 극대점 ✓.

## 페이저 분배 법칙(전압·전류)

- **개념**
    - 전압 분배 (직렬): V_i = E × Z_i / Σ_k Z_k.
    - 전류 분배 (병렬, 두 임피던스): I_i = I_total × Z_other/(Z_1 + Z_2) (Z_other는 같은 노드의 다른 가지 임피던스).
    - 두 법칙 모두 페이저 형식 — 크기와 위상 모두 보존.

- **적용 방법**
    - Fig 10.5에서 E를 Z₁(=R₁+jX_L), Z₂(=R₂-jX_C)로 분배하는 데는 직접 적용 불가 (Z₁과 Z₂는 병렬, E는 두 가지 양단에 동일 인가). 대신 각 가지의 전류는 Ohm 법칙으로 직접 구함: I_1 = E/Z_1, I_2 = E/Z_2.
    - 수치 예시 (Fig 10.5의 Z₂ 가지 내부 페이저 전압 분배, R₂ = 470 Ω, X_C = 795.77 Ω, E = 4 V_pp): |Z_2| = √(470² + 795.77²) = √854150 ≈ 924.20 Ω, θ_2 = tan⁻¹(-795.77/470) = -59.43°. V_R₂ = E × R₂/Z_2 = 4 × 470/(924.20 ∠-59.43°) = 4 × 0.5085 ∠59.43° = 2.034 ∠59.43° V_pp. V_C = E × (-jX_C)/Z_2 = 4 × (795.77 ∠-90°)/(924.20 ∠-59.43°) = 4 × 0.8610 ∠-30.57° = 3.444 ∠-30.57° V_pp.
    - 검산 (KVL, 페이저 합): V_R₂ + V_C → 실수부 = 2.034 cos59.43° + 3.444 cos(-30.57°) = 1.034 + 2.965 = 3.999; 허수부 = 2.034 sin59.43° + 3.444 sin(-30.57°) = 1.751 − 1.751 = 0. |V_R₂ + V_C| = 3.999 ≈ E = 4.000 V_pp ✓ (소수점 절사 오차 < 0.03%).
    - Fig 12.4에서 R_L 개방 시 E_Th = E × R₂/(R₁+R₂) — 페이저 전압 분배 직접 적용. R_L이 개방되면 L-R_L 가지에 전류가 흐르지 않아 V_L = 0이 되므로 R₁-R₂ 직렬 분배가 정확히 성립한다 (R₁·R₂가 순저항이므로 E_Th의 위상각 0°).
    - 수치 예시 (Fig 12.4, E = 4 V_pp, R₁ = 1.2 kΩ, R₂ = 3.3 kΩ): E_Th = 4 × 3.3/(1.2 + 3.3) = 4 × 3.3/4.5 = 4 × 0.7333 = 2.933 V_pp ∠0°.
    - 검산 (R_L 개방 시 KVL): I_open = E/(R₁+R₂) = 4/(1200+3300) = 4/4500 = 0.8889 mA_pp (L에 전류 없음). V_R₁ = I_open × R₁ = 0.8889 × 1200 = 1.067 V_pp, V_R₂ = I_open × R₂ = 0.8889 × 3300 = 2.933 V_pp. KVL: V_R₁ + V_R₂ = 1.067 + 2.933 = 4.000 = E ✓, 따라서 E_Th = V_R₂ = 2.933 V_pp.

## 커패시터 병렬 결합

- **개념**
    - 병렬로 결합된 커패시터의 등가 용량: C_T = C₁ + C₂ + … + C_n (lecture note p6).
    - 유도: 동일 전압 V가 각 C에 걸리므로 총 저장 전하 Q_T = ΣC_i × V = (ΣC_i) × V → C_T = ΣC_i.

- **적용 방법**
    - Table 12.3의 C* 열 — Part 3에서 0.0147 μF는 0.01 μF + 0.0047 μF 병렬, 0.0247 μF는 교재 Part 3(g) Note의 명시 구성에 따라 0.02 μF + 0.0047 μF 병렬로 형성 (준비물 섹션의 0.02 μF·0.0047 μF 항목과 일치).
    - 수치 예시: 0.0247 μF에서 X_C = 1/(2π × 10⁴ × 2.47×10⁻⁸) = 1/(1.5519×10⁻³) = 644.36 Ω. 검산: X_L = 628.32 Ω 와 매우 근접 (X_C/X_L = 1.026), 따라서 max power 조건에 가장 근접 ✓.
