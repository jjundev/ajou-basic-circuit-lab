## 결과 분석

- Table 10.5의 R-L ∥ R-C 병렬 네트워크 측정 결과는 위상은 잘 일치하나 전류·임피던스 크기에서 큰 편차가 나타났다. 임피던스 Z_T는 Calculated 737.79 Ω 대비 Measured 1030.37 Ω로 크기 기준 차이 39.66%, 소스 전류 I_s는 Calculated 5.42 mA_pp 대비 Measured 3.88 mA_pp로 28.40%, 가지 전류는 I_1이 33.18%(3.44 → 2.30 mA_pp), I_2가 25.93%(4.34 → 3.22 mA_pp) 차이로 모두 측정값이 이론값보다 작게 나타났다. 두 가지 전류가 모두 일관되게 감소한 점, 즉 한 쪽 가지만 어긋난 것이 아니라 양쪽 가지가 같은 방향으로 감소한 점은 단순 산발적 측정 오차가 아니라 회로 전체의 직렬 임피던스가 이론치보다 크게 형성되었음을 시사한다. R_1, R_2는 실측값(0.98 kΩ, 463 Ω)을 이미 Calculated에 반영했으므로 이 편차의 가장 유력한 원인은 명판값 R_l ≈ 0으로 가정한 인덕터의 권선저항이 실제로는 무시할 수 없는 크기였다는 점이다. 본 보고서에서는 Table 10.6의 측정 위상각(−32.40°, +59.76°)을 그대로 적용해 페이저 합 일관성을 확보했고, 이에 따라 Measured 열의 Z_T 위상(−23.53°)이 Calculated 위상(−20.52°)과 3.01° 차이로 정량 비교가 가능해졌다.

- Table 10.6의 위상측정은 매우 정확하다. E−I_1은 측정 −32.40° 대 이론 −32.67°, E−I_2는 측정 +59.76° 대 이론 +59.81°로 모두 절댓값 차이 0.3° 미만이다. 이는 오실로스코프 dual-trace 시간차 측정(D_2/D_1) 분해능이 5 div 한 주기 기준으로 매우 안정적임을 보여준다. 한편 R-L 가지의 경우 atan(X_L/R)이 R 변화에 둔감하므로(예: atan(628.32/980) = 32.67°에서 R이 1100 Ω으로 증가해도 atan(628.32/1100) = 29.74°로 약 3° 변화에 그침) 가지 위상은 안정적으로 측정되는 반면 크기 측정에서는 큰 편차가 발생하는 이중성이 자연스럽게 설명된다. Exercise 3의 이론 θ(I_1, I_2) = 92.48°와 Table 10.6 측정 위상 합산 92.16°가 0.32° 차이에서 일치한 점도 위상 측정 절차의 타당성을 뒷받침한다.

## 오차 원인

- 인덕터 권선저항(R_l)의 무시: 본 실험은 명판 L = 10 mH에 대해 R_l ≈ 0으로 가정했으나 일반적인 mH급 공심·페라이트 인덕터의 직류 권선저항은 수십~수백 Ω에 이른다. R_l이 100 Ω 수준만 되어도 Table 10.5의 Z_1 크기는 √(1080² + 628.32²) = 1249 Ω가 되어 이론 1164 Ω 대비 약 7% 증가하고 I_1은 같은 비율로 감소한다. 실제 33% 감소를 설명하려면 R_l이 더 크거나 두 가지 모두에 추가 직렬 임피던스가 작용해야 하며, Table 12.2의 실험적 R = 1059.87 Ω이 이론 (R_1 ∥ R_2) = 869.89 Ω보다 약 190 Ω 큰 점이 이 가설을 정량적으로 뒷받침한다.

- 저항 공칭값과 실측값의 차이(허용오차 ±5%): 명판 1 kΩ가 0.98 kΩ로, 명판 470 Ω가 463 Ω로, 명판 1.2 kΩ가 1.18 kΩ로, 명판 3.3 kΩ가 3.31 kΩ로, 명판 6.8 kΩ가 6.68 kΩ로, 명판 10 Ω가 9.39 Ω로 측정되어 모든 값이 명판 대비 0.3~6.1% 편차를 가진다. Calculated 열에는 실측 저항값을 사용해 이 편차를 제거했으나 가변저항(Table 12.6)의 경우 목표 1000 Ω가 985.7 Ω로 측정되는 등 최대치 부근에서 1.4% 정도 미달되어 P_L 곡선 끝단의 정밀도에 영향을 준다.

- 오실로스코프 측정 자릿수 한계와 작은 신호 민감도: V_pp는 0.01 V_pp 단위, V_ab는 미세 신호 영역에서 mV 자릿수에서 절단되어 P_L = V_ab²/(8R_L) 계산 시 제곱 연산으로 상대오차가 증폭된다. 예컨대 V_ab = 0.372 V_pp의 ±0.005 V_pp 측정 분해능은 P_L에 약 ±2.7% 오차를 유발한다. 또한 Table 12.2의 V_Rs = 29.3 mV_pp처럼 작은 신호는 ±3 mV_pp 판독 차이가 I = V_Rs/R_s 계산에 약 10.2% 변화로 직결되고, 이를 분모로 사용하는 Z_Th = E/I에는 같은 비율의 오차가 그대로 전이된다.

- 브레드보드 접촉 저항과 케이블 임피던스: 점퍼선·소켓 접점에서 발생하는 수십 mΩ~수 Ω의 직렬 저항은 단일 소자 단위에서는 무시 가능하나, Table 10.5처럼 가지 임피던스 1 kΩ 수준의 회로에서는 합산되어 1% 이내 영향, Table 12.2의 R_s = 9.39 Ω 직렬 회로에서는 R_s 자체에 대해 10%대 영향이 가능해 I 도출 기준이 흔들릴 수 있다.

- 가변저항 설정 오차와 R_Th 결정의 간접성: Fig 12.5의 R_Th 설정용 가변저항을 869.89 Ω로 맞추는 작업이 멀티미터 측정과 미세 회전 조정에 의존하며 회전 분해능 한계와 접점 노이즈로 설정값이 흔들린다. 또한 Table 12.2의 실험적 |Z_Th| = E/I 측정은 R_s = 9.39 Ω 양단 전압 29.3 mV_pp 정확도(±0.5 mV_pp ≈ ±1.7%)에 의존해 |Z_Th|에 ±1.7% 오차가 직접 전이된다.

- 콘덴서 명판 허용오차와 X_C = 1/(ωC)의 비선형성: 콘덴서는 일반적으로 ±10~±20% 허용오차를 가지며 X_C는 C에 반비례하므로 같은 비율의 X_C 오차로 직접 전달된다. Table 12.3에서 X_C = X_L 공진점이 이론 0.02533 μF에서 실험 0.0247 μF로 약 2.5% 어긋난 것은 이 허용오차 범위 안에 있고, 손실 성분 ESR도 P_L 봉우리 위치 미세 이동에 기여한다.

## 개선 방안

- 인덕터 권선저항 직접 측정 및 모델에 반영: 실험 시작 전 인덕터의 DC 권선저항(R_l)을 멀티미터로 측정하고 가능하면 임피던스 분석기 또는 V·I 측정으로 동작 주파수에서의 ESR을 함께 구해 Z_L = R_l + jX_L로 모델링한다. 이 한 가지 조치만으로 Table 10.5의 33~40% 편차, Table 12.2의 19.46% Z_Th 크기 격차, Table 12.5의 R_L(P_max) 73% 격차가 모두 정량적으로 설명 가능하다.

- 정밀저항 사용과 측정값의 일관된 반영: 1% 또는 0.1% 정밀도 저항을 사용하면 명판 대비 편차가 ±5%에서 ±1% 이하로 줄어들고, Calculated에 실측 저항을 사용하는 절차의 가치가 더 부각된다. 가변저항은 최대치 부근에서 1~2% 미달되는 경향이 있으므로 R_L 스위프 시 1000 Ω 이상은 별도 정밀저항으로 대체하면 P_L 곡선 끝단 정밀도가 향상된다.

- 오실로스코프 평균화 모드와 더 작은 V/div 사용: V_ab 측정 시 averaging 16~64회 적용으로 노이즈를 줄이고 V/div를 신호 크기에 맞춰 최대로 작게 설정해 자릿수 분해능을 높인다. 디지털 오실로스코프의 cursor 측정 대신 measure 메뉴의 자동 V_pp·Phase 측정을 사용하면 0.001 V_pp, 0.01° 단위 분해능을 활용할 수 있다.

- 브레드보드 접점 청결과 케이블 임피던스 관리: 실험 전 점퍼선과 소켓 접점을 알코올로 세척하고 신호 경로의 케이블 길이를 가능한 짧게 유지한다. R_s = 9.39 Ω 등 작은 직렬 저항을 사용할 때는 4-단자 측정(Kelvin) 방식을 적용해 케이블·접점 저항이 측정값에 포함되지 않도록 한다.

- 4채널 오실로스코프를 활용한 가지 간 위상 직접 측정: 본 보고서에서는 Table 10.6 측정 위상각을 Table 10.5 페이저 합에 일관 적용해 방법론적 일관성을 확보했으나, 더 나아가 4채널 오실로스코프로 V_R_1과 V_R_2를 동시에 측정해 두 가지 전류 사이 위상차를 직접 얻으면 Exercise 3의 이론값 θ(I_1, I_2) = 92.48°를 단일 화면에서 검증할 수 있다.

- 가변저항 설정 절차 개선과 최대점 주변 측정 간격 보강: Fig 12.5의 R_Th 설정용 가변저항을 다회전 정밀 포텐셔미터로 교체하고 설정 후 in-circuit 멀티미터 측정으로 869.89 Ω 정확 도달을 확인한다. Table 12.2의 |Z_Th| = E/I 측정 시 R_s 양단 전압이 너무 작은 문제는 더 큰 R_s(예 100 Ω)를 사용하거나 전류 프로브로 직접 I를 측정하면 완화된다. 또한 Table 12.6의 R_L 스위프에서 최대점 주변 450 Ω, 550 Ω, 650 Ω, 750 Ω, 850 Ω을 추가 측정하고 인접점 보간으로 P_L-R_L 곡선의 꼭짓점을 추정하면 봉우리 위치 판정이 안정된다.

- 콘덴서 정밀도와 공진점 추적: ±1% 또는 ±5% 정밀 콘덴서를 사용하면 X_C 허용오차가 줄어들고 X_C = X_L 공진점이 더 좁은 C 간격으로 정의된다. Table 12.3의 C* 스위프 간격을 공진점 부근(0.02~0.03 μF)에서 더 촘촘히 잡으면 P_max 발생 C 값을 더 정확히 판독할 수 있다.

## 결론

- 본 실험은 페이저 해석에 기반한 병렬 R-L ∥ R-C 회로의 임피던스·전류 측정, AC 회로에서의 테브난 정리 동치성 검증, 최대전력전달 정리에서의 X_C = X_L 조건 및 R_L = R_Th 조건 확인이라는 세 가지 목표를 종합적으로 수행했다. 위상 측정은 모든 Table에서 0.3° 이내 정확도로 이론값과 일치(Table 10.6 −32.40° vs −32.67°, +59.76° vs +59.81°; Table 12.2 θ_Th +34.23° vs +35.84°)했으나, 크기 측정에서는 Table 10.5의 Z_T 39.66%, Table 12.5의 R_L(P_max) 73.02% 등 큰 편차가 관찰되었다.

- 크기 측정의 대규모 편차는 명판 L = 10 mH 인덕터의 권선저항 R_l을 0으로 가정한 모델링 한계로 일관되게 설명된다. Table 12.2의 실험적 Z_Th 직각 변환에서 R 성분이 이론 (R_1 ∥ R_2) = 869.89 Ω보다 약 190 Ω 큰 점이 R_l ≈ 100~200 Ω의 정량적 근거를 제공하며, 이 R_l 값이 R-L 가지 전류 감소(33.18%), R_L(P_max) 우상향 이동(73%), R_L = 1 kΩ 조건의 Original-Thevenin 격차(12.90%)를 모두 정합적으로 설명한다.

- 정성적으로는 모든 실험 목적이 달성되었다. 페이저 합 KCL이 위상 측면에서 92.48° 가지 간 위상차를 통해 잘 확인되었고, 테브난 정리는 R_L이 큰 영역(6.8 kΩ)에서 0.42%의 우수한 동치성으로 검증되었으며, 최대전력전달 정리는 X_C = X_L 조건이 측정 X_C(P_max) 644.35 Ω 대 이론 X_L 628.32 Ω로 2.55% 일치하여 정확히 성립했다. R_L = R_Th 조건만이 R_l 효과로 크게 어긋났는데 이는 실험 한계가 아니라 이상 모델과 실제 소자의 차이를 드러낸 의미 있는 결과로 해석된다. 향후 인덕터 R_l을 직접 측정해 모델에 반영하고 정밀저항·정밀콘덴서·평균화 측정·4채널 위상 직접 측정을 적용하면 크기 측정 정밀도가 크게 향상될 것으로 기대된다.
