- I_1 = E / Z_1 이므로 I_1의 위상은 -32.67°이다.

③ I_2 위상 계산

- Z_2 = R_2 - jX_C = 463 - j795.77 Ω
- θ_2 = tan^-1(-795.77 / 463) = -59.81°
- I_2 = E / Z_2 이므로 I_2의 위상은 +59.81°이다.

④ I_1과 I_2 사이 위상각 계산

- θ_between = 59.81° - (-32.67°) = 92.48°

**정답**

| 구분 | Calculated | Experimental |
|---|---|---|
| θ_I1_I2 | 92.48° | 실험 측정값 |

계산상 I_2는 I_1보다 약 92.48° 앞선다. part 3(j)의 측정값은 실험 측정값 칸에 수동으로 비교한다.

# 고찰

## 결과 분석

Ch 10의 Series-Parallel Sinusoidal Circuits에서는 실측 소자값 R_1 = 0.98 kΩ, R_2 = 463 Ω, L = 10 mH, C = 0.02 μF를 사용하여 계산한 결과와 오실로스코프 전압 측정값에서 역산한 결과를 비교하였다. Table 10.5에서 Z_T는 계산값 737.79 Ω ∠-20.52°에 대해 측정 기반 산출값이 1030.37 Ω ∠-23.53°로 나타나 크기 기준 %(Difference)가 39.66%였다. I_s는 5.42 mA_pp ∠+20.52°에서 3.88 mA_pp ∠+23.53°로 28.40%, I_1은 3.44 mA_pp ∠-32.67°에서 2.30 mA_pp ∠-32.40°로 33.18%, I_2는 4.34 mA_pp ∠+59.81°에서 3.22 mA_pp ∠+59.76°로 25.93%의 차이를 보였다. 위상은 I_1에서 0.27°, I_2에서 0.05°만 차이가 나므로 회로의 유도성 가지와 용량성 가지의 위상 관계는 잘 관측되었지만, 전류 크기는 V_R1 = 2.25 V_pp와 V_R2 = 1.49 V_pp에서 직접 역산되기 때문에 저항 양단 전압 측정 또는 전원 4 V_pp 기준 설정의 영향이 크게 반영되었다.

Table 10.6에서는 한 주기 D_1 = 5.0 div에 대해 E and I_1의 D_2 = 0.45 div, E and I_2의 D_2 = 0.83 div가 측정되어 각각 32.40° lag와 59.76° lead로 환산되었다. 이 값은 Table 10.5의 계산 위상 -32.67° 및 +59.81°와 거의 일치한다. 따라서 Ch 10의 주된 불일치는 위상 판독보다 전압 진폭 판독에서 발생한 것으로 해석된다. Exercise 3의 실측 소자값 기반 계산에서도 I_1과 I_2 사이 위상각이 92.48°로 산출되며, Table 10.6의 두 위상 측정값을 합산하면 92.16°가 되어 차이는 0.32°에 불과하다.

Ch 12의 Thevenin 실험에서는 Table 12.1에서 개방전압 E_Th가 원회로 측정값 2.77 V_pp, 실측 저항 기반 계산값 2.95 V_pp로 정리되어 두 값의 차이는 0.18 V_pp, %(Difference)는 6.10%이다. Z_Th는 실측 소자값 기반 계산값 1073.08 Ω ∠+35.84°에 대해 Table 12.2의 측정 기반 산출값이 1281.91 Ω ∠+34.23°로 나타나 크기 기준 차이는 19.46%이고 위상 차이는 1.61°이다. 직각형 성분으로 보면 저항 성분은 869.89 Ω에서 1059.87 Ω으로 21.84%, 리액턴스 성분은 628.32 Ω에서 721.10 Ω으로 14.77% 증가한 형태이다. Table 12.1의 R_L = 6.8 kΩ 조건에서는 Original의 V_RL = 2.37 V_pp와 Thevenin Equivalent의 V_RL = 2.38 V_pp가 0.42% 차이로 매우 잘 일치하였다. R_L = 1 kΩ 조건에서도 Fig 12.5 Thevenin 등가회로의 V_RL을 1.40 V_pp로 정정하면 Original의 1.24 V_pp와 차이는 0.16 V_pp, %(Difference)는 12.90%이다. 따라서 두 부하 조건 모두에서 Thevenin 등가회로의 부하 전압 예측이 확인되었으며, 기존 2.77 V_pp 기록은 부하 전압이 아니라 Thevenin 전원 설정값이 V_RL 항목에 잘못 반영된 사례로 해석된다.

Table 12.2의 Z_Th 측정은 R_s = 9.39 Ω에 걸린 V_Rs = 29.3 mV_pp에서 I = 3.12 mA_pp를 구하고, E = 4 V_pp를 이 전류로 나누어 1281.91 Ω을 산출한 방식이다. 이 방법은 작은 전압 29.3 mV_pp를 기준으로 전체 임피던스를 역산하므로 오실로스코프 판독 오차가 크게 증폭된다. 예를 들어 V_Rs가 3 mV_pp만 달라져도 전류가 약 10.2% 변하고, E/I로 계산되는 Z_Th도 같은 비율로 변한다. 따라서 Table 12.2의 Z_Th 크기 차이 19.46%는 이론식 오류라기보다 소신호 측정과 R_s 직렬 삽입에 따른 민감도 증가가 반영된 결과로 보는 것이 타당하다.

Table 12.3과 Graph 12.1에서는 C를 변화시켰을 때 C = 0.0247 μF, X_C = 644.35 Ω에서 P_L = 0.537 mW로 최대가 되었다. 이론 공진 기준은 X_C = X_L = 628.32 Ω, C = 0.02533 μF이므로 측정 기반 최대점의 X_C 차이는 16.03 Ω, 2.55%이고 C 차이는 0.00063 μF, 2.49%이다. 이 결과는 그래프 판독값과 이론 기준값이 거의 같은 위치에 있음을 보여준다. 특히 X_C = 1082.69 Ω과 338.63 Ω에서 P_L이 모두 0.507 mW로 같은 수준이고, 공진점 근처인 644.35 Ω에서 0.537 mW로 증가하므로 커패시터 값에 따른 최대 전력 전달 경향은 명확하게 확인된다.

Table 12.5와 Table 12.6에서는 C = 0.0247 μF로 고정한 뒤 R_L을 변화시켰을 때 측정 기반 최대 전력점이 R_L = 801.1 Ω, P_L = 0.569 mW로 나타났다. 이론 기준인 R_Th = 463 Ω와 비교하면 R_L은 338.1 Ω, 73.02% 크게 나타났다. 그러나 R_L = R_Th인 463 Ω에서도 P_L = 0.5216 mW로 최대값 0.569 mW보다 0.0476 mW 낮을 뿐이며, 최대값 대비 차이는 8.37%이다. 따라서 최대점의 위치는 이론 기준과 크게 이동했지만, 전력 크기 자체는 463 Ω부터 985.7 Ω까지 완만하게 변했고, 측정점 간 간격과 전압 판독 오차가 최대점 위치 판정에 크게 작용한 것으로 해석된다.

## 오차 원인

첫 번째 오차 원인은 실측 저항값과 공칭값의 차이이다. Ch 10의 R_2는 공칭 470 Ω에 대해 실측 463 Ω으로 1.49% 낮고, R_1은 공칭 1 kΩ에 대해 실측 0.98 kΩ으로 2.00% 낮다. Ch 12의 R_1은 공칭 1.2 kΩ에 대해 1.18 kΩ으로 1.67% 낮고, R_2는 공칭 3.3 kΩ에 대해 3.31 kΩ으로 0.30% 높다. 이러한 저항 오차 자체는 Table 10.5의 25.93%에서 39.66% 수준의 전류 크기 차이를 단독으로 만들기에는 부족하지만, 가지 전류를 V_R/R로 역산하는 과정에서는 전압 판독 오차와 결합되어 최종 전류 및 Z_T 산출값에 직접 반영된다.

두 번째 오차 원인은 오실로스코프의 작은 전압 판독에서 발생하는 상대오차 확대이다. Table 12.2의 V_Rs = 29.3 mV_pp는 매우 작은 신호이므로 커서 또는 눈금 판독이 몇 mV만 달라도 I = V_Rs/R_s 계산값이 크게 변한다. 29.3 mV_pp 기준에서 3 mV_pp의 판독 차이는 약 10.2%이고, 이 전류를 분모로 사용하는 Z_Th = E/I에는 반대 방향으로 같은 비율의 오차가 전달된다. 이 때문에 Table 12.2의 Z_Th 크기 오차 19.46%와 저항 성분 21.84% 증가는 소신호 측정 민감도와 잘 연결된다.

세 번째 오차 원인은 전원 진폭 설정과 측정 기준의 불일치이다. Ch 10과 Ch 12 모두 강의노트 조건에 따라 E = 4 V_pp를 사용했지만, Table 10.5에서는 V_R1과 V_R2에서 역산한 전류가 계산값보다 각각 33.18%, 25.93% 낮았다. Table 12.1에서도 기존 측정값 기록에는 Thevenin Equivalent의 R_L = 1 kΩ 행에 실제 전원 설정값 2.77 V_pp가 부하 전압처럼 들어갔지만, Fig 12.5 Thevenin 등가회로의 부하 전압을 1.40 V_pp로 정정하면 Original의 1.24 V_pp와 차이는 12.90%로 줄어든다. 이는 회로 동작 자체의 실패라기보다 전원 설정값, 개방전압, 부하 양단 전압을 기록하는 단계가 혼재되었을 가능성이 큰 사례이다.

네 번째 오차 원인은 가변저항 조정과 그래프 판독의 제한이다. Table 12.6에서는 이론상 최대 전력 조건이 R_L = R_Th = 463 Ω인데, 측정 기반 최대점은 801.1 Ω으로 기록되어 73.02% 차이가 났다. 하지만 P_L은 463 Ω에서 0.5216 mW, 598.0 Ω에서 0.5284 mW, 801.1 Ω에서 0.5692 mW, 985.7 Ω에서 0.5646 mW로 완만하게 변한다. 최대점 주변의 차이가 수십 μW 수준이므로 가변저항 미세 조정, 접촉 저항, 각 측정 시 V_ab 판독 차이가 최대점 위치를 높은 R_L 쪽으로 이동시켰을 수 있다.

다섯 번째 오차 원인은 인덕터와 커패시터의 비이상성이다. 계산에서는 L = 10 mH와 C 명판값을 이상 소자로 두고 X_L = 628.32 Ω, X_C = 644.35 Ω 등을 사용했지만, 실제 인덕터에는 권선저항과 주파수 의존 손실이 있고 커패시터에는 허용오차와 ESR이 존재한다. Table 12.3에서 측정 기반 최대점 X_C = 644.35 Ω은 이론 공진 기준 X_L = 628.32 Ω보다 2.55% 높았으며, 이는 부품 허용오차와 손실 성분을 포함한 실제 임피던스 조건에서 최대 전력점이 약간 이동한 결과로 볼 수 있다.

## 개선 방안

저항값으로 인한 오차를 줄이기 위해서는 모든 계산에서 이미 수행한 것처럼 실측 저항값을 사용하되, 실험 직전과 실험 후에 같은 소자를 다시 측정해 접촉 상태나 가변저항 설정 변화가 있었는지 확인해야 한다. 특히 Table 12.6의 R_L sweep에서는 각 전압 측정 직후 R_L을 다시 DMM으로 확인하면 463 Ω, 598.0 Ω, 801.1 Ω처럼 최대점 판정에 중요한 행의 실제 저항값 신뢰도를 높일 수 있다.

소신호 판독 오차를 줄이기 위해서는 Table 12.2의 V_Rs처럼 수십 mV_pp 범위의 신호를 측정할 때 오실로스코프 수직 감도를 높이고 평균화 기능 또는 측정 자동화 기능을 사용해야 한다. 또한 R_s를 너무 작게 잡으면 V_Rs가 작아져 상대오차가 커지므로, 회로에 미치는 부하 효과가 허용되는 범위 안에서 sense 저항을 키워 V_Rs를 더 크게 만든 뒤 Z_Th를 역산하는 것이 좋다.

전원 진폭과 전압 기록 항목의 혼동을 줄이기 위해서는 각 표를 작성할 때 E_s, E_Th, V_RL, V_ab를 별도 체크 항목으로 나누어 기록해야 한다. Table 12.1의 R_L = 1 kΩ Thevenin Equivalent 행처럼 전원 설정값이 부하 전압 칸에 들어갈 수 있는 항목은 측정 직후 회로 연결 상태와 측정 노드를 사진이나 간단한 메모로 남기고, 개방 상태와 부하 연결 상태를 명확히 분리해 기록하는 절차가 필요하다.

가변저항과 그래프 판독에 따른 최대점 위치 오차를 줄이기 위해서는 최대점 주변에서 측정 간격을 더 촘촘하게 잡아야 한다. Table 12.6에서는 463 Ω과 801.1 Ω 사이의 전력 변화가 완만하므로 450 Ω, 550 Ω, 650 Ω, 750 Ω, 850 Ω 부근을 추가로 측정하고, 단순히 가장 큰 측정점 하나를 선택하기보다 인접점 보간으로 P_L-R_L 곡선의 꼭짓점을 추정하면 최대점 판정이 안정된다.

비이상 소자에 따른 오차를 줄이기 위해서는 LCR 미터로 10 kHz에서의 인덕터 등가 직렬저항과 커패시터 실제 용량을 측정한 뒤, X_L과 X_C뿐 아니라 손실 저항까지 포함한 복소 임피던스로 계산해야 한다. Table 12.3의 공진점이 이론 C = 0.02533 μF가 아니라 실험 조합 C = 0.0247 μF에서 나타난 것은 차이가 2.49%로 작으므로, 실제 주파수 조건에서의 C 값과 ESR을 반영하면 이 차이를 더 정밀하게 설명할 수 있다.

## 결론

이번 실험에서는 Ch 10의 병렬 R-L-C 회로에서 전류 위상 관계는 매우 잘 확인되었지만 전류 크기와 등가 임피던스 크기에서는 Z_T 39.66%, I_s 28.40%, I_1 33.18%, I_2 25.93%의 큰 차이가 나타났다. 반면 Table 10.6의 위상 측정은 계산값과 0.32° 수준으로 일치하여 위상 측정 절차의 타당성은 확인되었다.

Ch 12의 Thevenin 실험에서는 E_Th의 이론값과 측정값 차이가 6.10%, Z_Th 크기 차이가 19.46%였고, R_L = 1 kΩ 조건의 Original과 Thevenin Equivalent 부하 전압 차이는 12.90%, R_L = 6.8 kΩ 조건의 차이는 0.42%였다. 따라서 Thevenin 등가회로가 부하 전압 예측에 유효하다는 점은 두 부하 조건에서 모두 확인되었으며, 기존 2.77 V_pp 기록 오류는 전원 설정값과 부하 전압 기록 항목을 분리해야 함을 보여준다.

최대 전력 전달 실험에서는 C sweep에서 측정 기반 최대점 X_C = 644.35 Ω이 이론 기준 X_L = 628.32 Ω과 2.55% 차이로 일치하여 리액턴스 정합 조건을 잘 만족하였다. R_L sweep에서는 최대점 위치가 이론 R_Th = 463 Ω에서 측정 기반 801.1 Ω으로 73.02% 이동했지만, 전력 크기는 R_L = R_Th에서 최대값보다 8.37% 낮은 정도였다. 종합하면 이번 실험은 위상 해석, Thevenin 등가, 리액턴스 정합에 의한 최대 전력 전달의 핵심 경향을 확인했으며, 가장 큰 개선 대상은 전압 진폭 기록의 일관성, 소신호 측정 정밀도, 최대점 주변의 추가 측정이다.
