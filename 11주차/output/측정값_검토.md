## 추천 예상값 근거

- **D_2 백캘큘레이션 (Tables 7.1, 7.4, 8.1×2, 8.3×2, 9.2×2)**: 학생이 오실로스코프 dual-trace 에서 θ 를 직접 읽고 `(D_2 를 역산하라)` 노트를 남겼다. 식: `D_2 = (θ/360°) · D_1`. D_1 = 5 div 고정. 부호는 θ 부호를 그대로 따른다 (V_C lag 의 경우 음수). θ 자체가 측정값이므로 신뢰도 高.
- **Table 7.8 θ_1 (3 rows)**: Lissajous 측정값 y_o, y_m 으로부터 `θ = sin⁻¹(y_o / y_m)`. 이미지 픽셀로 측정한 y_o/y_m 비율이 보존되므로 절대값(div) 의 절대 스케일은 무관. 값 자체는 측정값 → 신뢰도 高.
- **Table 8.5 I(p-p)**: `I = V_R / R_mes = 2.65 V / 970 Ω ≈ 2.732 mA p-p`. R 은 R.0 측정값(970Ω, 1kΩ 명목) 사용. V_R 은 직접 측정. 식과 입력이 모두 측정값이므로 高.
- **Table 8.5 Z_T**: `Z_T = E(p-p) / I(p-p) = 4 V / 2.732 mA ≈ 1464 Ω`. E 는 고정조건 4 Vpp, I 는 위 도출값. 신뢰도 高 (하지만 I 자체가 도출값이라는 점은 보고서에 명시 권장).
- **Table 9.4 I_s (diagram)**: `√(I_R² + I_L²) = √(3.128² + 5.139²) = √(9.78 + 26.41) = 6.016 mA`. I_R, I_L 모두 9.1 의 DMM→p-p 환산값. 高.
- **Table 9.4 I_s (measured)**: V_Rs(for I_s) / R_s = 75 mV / 10 Ω = 7.5 mA. 입력이 모두 측정값. 高.
- **Table 9.4 θ_s**: `tan⁻¹(I_L/I_R) = tan⁻¹(5.139/3.128) = tan⁻¹(1.643) ≈ 58.66°`. 高.
- **Table 9.4 θ_L**: 페이저 다이어그램 정의(I_s와 I_L 사이 각) → `90° − θ_s = 31.34°`. 高. ⚠️ Table 9.2 의 θ_L (E와 I_L 사이 각, 90°에 가까움) 과 다른 양임을 보고서에 분명히 분리 기술할 것.
