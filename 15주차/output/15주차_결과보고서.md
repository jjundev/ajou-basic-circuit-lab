- 이 표는 명판값(L, C)과 실측 저항값을 사용해 병렬 공진 파라미터를 다시 계산한 **실측 소자값 기반 이론 재계산** 결과다. 교재 지시(part c~e)에 따라 코일 내부저항을 포함한 전체 직렬저항 R = R_1 + R_l 을 R_l 자리에 대입한다.
- 실측 소자값
  - R_1 = 4.38(Ω) (명판 4.7 Ω)
  - R_l (10 mH 코일) = 24.73(Ω)
  - R = R_1 + R_l = 4.38 + 24.73 = 29.11(Ω)
  - L = 10 mH (명판), C = 0.1 μF (명판)
- 공진 주파수 (Eq. 14.4 근사식)
  - f_p = 1/(2π√(LC)) = 1/(2π√(10×10⁻³ × 0.1×10⁻⁶)) = 1/(2π√(1×10⁻⁹)) = 5032.9(Hz)
- 공진 주파수 (Eq. 14.3 정식)
  - R²C/L = (29.11² × 0.1×10⁻⁶)/(10×10⁻³) = 8.474×10⁻³
  - √(1 − 8.474×10⁻³) = 0.99575
  - f_p = 5032.9 × 0.99575 = 5011.5(Hz)
- 공진 임피던스
  - Z_p = L/(R·C) = 0.01/(29.11 × 0.1×10⁻⁶) = 3435.2(Ω) ≈ 3.44(kΩ)
- 선택도
  - X_L = 2π × 5032.9 × 0.01 = 316.23(Ω)
  - Q_l = X_L/R = 316.23/29.11 = 10.86
  - Q_l = 10.86 ≥ 10 이므로 Q_p ≈ Q_l = 10.86 (Eq. 14.4 근사가 성립하나 여유가 작다)
- 검증: 실측 R_l = 24.73 Ω 이 명판 가정(R_l ≈ 0)보다 훨씬 커서 R = 29.11 Ω 이 되었고, 그 결과 Z_p(3.44 kΩ)와 Q_l(10.86)이 예비보고서 예상값(21.28 kΩ, 67.28)보다 크게 낮아졌다. 두 f_p 값의 상대차는 (5032.9 − 5011.5)/5032.9 = 0.43% 로 Q_l 이 10 근처임을 반영한다.

## AC Ch 14 Parallel Resonant Circuits

### Exercise 1

**조건**

- Fig. 14.2 의 병렬 공진 회로에서 전류원은 전원에 직렬로 연결된 R_s = 100 kΩ 으로 구현되며, R_s >> Z_p 일 때만 부하(공진 탱크) 임피던스 변화와 무관하게 거의 일정한 전류를 공급하는 "좋은 전류원"으로 동작한다.
- 기존 소자값: L = 10 mH, R = R_1 + R_l = 29.11 Ω(실측 기반), C = 0.1 μF → Z_p = L/(R·C) = 3.44 kΩ, f_p ≈ 5033 Hz.
- 변경 조건: C 를 0.1 μF 에서 0.01 μF 로 1/10 로 감소시킨다.

**계산**

① 변경 후 공진 주파수

- f_p = 1/(2π√(LC)) = 1/(2π√(10×10⁻³ × 0.01×10⁻⁶)) = 1/(2π√(1×10⁻¹⁰)) = 1/(2π × 1×10⁻⁵) = 15915.5 Hz

② 변경 후 공진 임피던스

- Z_p = L/(R·C) = 0.01/(29.11 × 0.01×10⁻⁶) = 0.01/(2.911×10⁻⁷) = 34353 Ω ≈ 34.35 kΩ
- C 가 1/10 이 되면 Z_p 는 10 배로 증가하여 3.44 kΩ → 34.35 kΩ 이 된다.

③ 전류원 양호도 판정 (R_s 대 Z_p 비)

- 기존: R_s/Z_p = 100 kΩ / 3.44 kΩ = 29.1 (≥ 10, 충분히 큼)
- 변경 후: R_s/Z_p = 100 kΩ / 34.35 kΩ = 2.91 (< 10, 부족함)

**결론**

- C 를 0.01 μF 로 줄이면 공진 임피던스가 Z_p ≈ 34.35 kΩ 로 10 배 커져 직렬 R_s = 100 kΩ 과의 비가 2.91 까지 떨어지므로, 공진 주파수 부근에서 회로에 흐르는 전류 I_s 가 더 이상 일정하게 유지되지 못한다. 따라서 변경된 주파수 범위에서 이 100 kΩ 직렬저항은 좋은 전류원 설계가 아니다.
- 좋은 전류원을 유지하려면 R_s 를 최소 10·Z_p ≈ 344 kΩ 이상으로 키우거나, Z_p 를 낮추도록 코일 직렬저항 R 을 키우는(또는 C 를 원래대로 두는) 보정이 필요하다.

**조건**

- θ = −arctan(0/124.73) = 0°

- θ = −arctan(−474.4/124.73) = −arctan(−3.803) = +75.27°

④ f = 2f_s = 10065.8 Hz

- X_L = 316.23 × 2 = 632.5 Ω, X_C = 316.23/2 = 158.1 Ω → X_L − X_C = +474.4 Ω
- θ = −arctan(+474.4/124.73) = −arctan(+3.803) = −75.27°

## 결과 분석

- Ch 14 병렬 공진 회로(Table 14.1)에서 명판값(L = 10 mH, C = 0.1 μF)과 실측 저항을 사용해 재계산한 결과, 코일 내부저항 R_l = 24.73 Ω 이 명판 R_1(4.38 Ω)보다 압도적으로 커서 전체 직렬저항이 R = 29.11 Ω 까지 올라갔고, 이로 인해 공진 임피던스 Z_p 가 3.44 kΩ, 선택도 Q_l 이 10.86 으로 산출되었다. 이는 코일 내부저항을 무시(R_l ≈ 0)했던 예비보고서 예상값(Z_p = 21.28 kΩ, Q_l = 67.28)에 비해 Z_p 는 약 1/6, Q_l 은 약 1/6 수준으로 크게 낮아진 것으로, 실험 결과 분석에서 코일 내부저항을 반드시 포함해야 함을 정량적으로 보여 준다. 한편 Eq. 14.4 근사식 f_p(5032.9 Hz)와 Eq. 14.3 정식 f_p(5011.5 Hz)의 상대차는 (5032.9 − 5011.5)/5032.9 = 0.43% 에 불과하여, Q_l 이 10 근처일 때도 두 공진식이 잘 수렴함을 확인하였다.
- 측정 기반 산출 결과인 Table 14.2 에서는 직렬 R_s = 100.6 kΩ 이 정전류원으로 동작하여 모든 주파수에서 I_s = 5.00 V / 100.6 kΩ = 0.0497 mA 로 거의 고정되었고, 이에 따라 측정된 Z_p 곡선은 5000~5100 Hz 에서 약 2.31 kΩ 의 봉우리를 갖는 전형적 공진 응답을 그렸다. 다만 측정상 최댓값 Z_p ≈ 2.31 kΩ 은 이론 Z_p = 3.44 kΩ 보다 약 (3.44 − 2.31)/3.44 = 32.8% 낮은데, 이는 (at peak) f_p ≈ 5033 Hz 의 진짜 공진점을 측정하지 못한 채 인접한 5000 Hz·5100 Hz 값만 확보했기 때문이며, 측정 분해능 한계로 인한 과소평가이지 단순 계산 오류가 아니다.
- Ch 15 고역통과필터(Table 15.1)에서는 실측 R = 985.6 Ω 기반 이론 차단주파수 f_c = 1614.8 Hz, 진폭 그래프 판독 f_c = 1600 Hz, 위상 그래프(θ = 45°) 판독 f_c = 1550 Hz 가 모두 1.6 kHz 부근으로 수렴하였다. 이론값과 진폭 그래프값의 상대차는 (1614.8 − 1600)/1614.8 = 0.92%, 이론값과 위상 그래프값의 상대차는 (1614.8 − 1550)/1614.8 = 4.01% 로, R = X_C 조건과 θ = 45° 조건이 정의상 동일한 차단점을 가리킴을 정량적으로 입증하였다. 2 kHz 전압비 또한 이론 0.778, 측정 0.78 로 상대차 0.28% 에 그쳐 거의 완전히 일치하였다.
- Ch 15 직렬 대역통과필터(Table 15.4)에서는 코일 내부저항 R_l = 24.73 Ω 을 포함한 이론 통과대역 전압비 V_o/V_i = R/(R + R_l) = 0.785 가 측정 최댓값 A_v_max = 0.784 와 상대차 0.13% 로 거의 완벽히 일치하였다. 이는 이상적 가정(A_v = 1.0)을 썼다면 약 27.5% 의 큰 오차가 났을 값을, 실측 R_l 을 포함함으로써 0.13% 까지 줄인 사례로 실측 소자값 재계산의 유효성을 보여 준다. 반면 대역폭은 이론 BW(f_s/Q_s) = 1832 Hz, 그래프 판독 BW = 1920 Hz 로 상대차 (1920 − 1832)/1832 = 4.80% 였는데, 이는 0.707·A_v(max) 교점 f_1, f_2 를 인접 측정점 보간(4.0~4.30 kHz, 6.0~8.0 kHz)으로 구한 데서 비롯된 판독 오차로 해석된다.
- Ch 15 대역저지(노치)필터(Table 15.6)에서는 이론 노치 전압비 V_o/V_i = 0.083 과 측정 최소 V_o/V_i = 0.168 사이에 큰 차이가 나타났다. 이는 단순 계산 오류가 아니라, 진짜 공진점 f_p = 11254.6 Hz 를 측정하지 못하고(주파수 분해능 한계) 가장 가까운 12.0 kHz 의 노치 외곽 값(0.84 V)만 확보했기 때문이며, f_p 에서 더 깊은 노치가 형성됨에도 측정점이 골 바닥을 놓쳐 과대평가된 것이다. 한편 이론 BW(Calc) = 796 Hz 와 그래프 BW = 8700 Hz 의 차이는 정의 자체가 다른 두 기준값을 비교한 결과로 보아야 한다. 이론 BW 는 탱크 자체의 코일 선택도 Q_l = 14.14(R_l = 5 Ω 기준)로 구한 값인 반면, 측정 BW 는 직렬 R = 90.4 Ω 이 추가되어 회로 전체의 실효 Q 가 크게 낮아진 상태의 −3 dB 폭이므로, 두 값을 동일 기준으로 직접 비교하는 것은 부적절하다. 실제로 측정 차단주파수의 기하평균 √(7600 × 16300) ≈ 11.13 kHz 가 이론 노치 중심 f_p = 11.25 kHz 와 상대차 1.07% 로 근접하여, 노치 중심 위치 자체는 이론과 측정이 잘 일치함을 확인하였다.

## 오차 원인

- 소자 공칭값과 실측값의 차이가 1차 원인이다. 저항은 명판 4.7 Ω → 실측 4.38 Ω(−6.8%), 명판 100 Ω → 실측 90.4 Ω(−9.6%), 명판 1 kΩ → 실측 985.6 Ω(−1.4%) 로 ±5~10% 의 허용오차 범위 편차를 보였고, 특히 코일 내부저항 R_l(10 mH 코일 24.73 Ω, 1 mH 코일 5 Ω)은 명판에 표기되지 않은 값으로서 Z_p, Q_l, 노치 깊이 계산에 결정적 영향을 주었다. 이를 무시했던 예비보고서 예상값(Q_l = 67.28)과 실측 기반 재계산값(Q_l = 10.86)의 차이가 이 원인의 크기를 단적으로 보여 준다.
- 오실로스코프(함수발생기)의 주파수 분해능이 100 Hz 단위로만 조절 가능했던 점이 공진·차단 특성 측정의 핵심 오차 원인이다. 그 결과 Ch 14 의 공진점 f_p ≈ 5033 Hz, Ch 15 대역통과의 f_s = 5033 Hz, 대역저지의 f_1 = 7957 Hz·f_p = 11255 Hz·f_2 = 15916 Hz 등 핵심 주파수에서 직접 측정이 불가능하여 인접 정수 주파수 값으로 대체할 수밖에 없었고, 이것이 Table 14.2 의 Z_p 봉우리 과소평가(2.31 kΩ vs 3.44 kΩ, −32.8%)와 Table 15.6 의 노치 깊이 과대평가(0.168 vs 0.083)를 직접 유발하였다.
- 소신호 측정 시의 상대오차 확대도 오차 원인이다. Table 14.2 의 V_C 는 공진점 부근을 제외하면 6.0~46.0 mV 의 매우 작은 값이어서, mV 단위 분해능의 한계와 잡음이 그대로 상대오차로 확대되었다. 작은 신호일수록 동일한 절대 측정 불확실도가 더 큰 백분율 오차로 나타나, 저주파 영역 Z_p 산출값의 신뢰도를 떨어뜨렸다.
- 그래프 판독 및 보간 오차가 차단주파수·대역폭 산출에 누적되었다. f_c, f_1, f_2 는 모두 0.707 또는 0.707·A_v(max) 교점을 인접한 두 측정점 사이의 선형 보간으로 구했는데(예: Table 15.4 의 f_1 은 4.0 kHz(0.458)~4.30 kHz(0.586) 보간, f_2 는 6.0 kHz(0.576)~8.0 kHz(0.284) 보간), 측정점 간격이 넓고 곡선이 비선형이어서 보간값에 오차가 실려 BW 그래프값(1920 Hz)이 이론값(1832 Hz)과 4.80% 차이를 보였다.
- 브레드보드 접촉 저항과 케이블·프로브 임피던스가 미소 직렬저항으로 더해져, 특히 수십 Ω 단위의 작은 저항(R = 90.4 Ω, R_l = 5 Ω)이 지배하는 회로에서 상대적 영향이 커졌다. 이는 통과대역 전압비와 노치 깊이를 이론값에서 미세하게 벗어나게 만드는 계통오차로 작용한다.
- 코일과 커패시터의 비이상성(코일의 주파수 의존 내부저항·표유 커패시턴스, 커패시터의 유전손실·누설)이 고주파 대역에서 실효 Q 를 낮추는 방향으로 작용하여, 측정 공진 봉우리와 노치가 이론보다 완만해지는 데 기여하였다.

## 개선 방안

- 소자 공칭값과 실측값 차이에 대해서는, 본 실험에서 적용한 것처럼 모든 저항과 코일 내부저항 R_l 을 정밀 LCR 미터로 측정하여 명판값 대신 실측값으로 계산하는 방식을 일관되게 적용하고, 측정 전 LCR 미터를 영점·표준 보정하여 R_l 측정 자체의 정확도를 높여야 한다. 이는 이론 A_v_max(0.785)를 측정값(0.784)에 0.13% 까지 맞춘 효과를 다른 항목에도 확대 적용하는 방안이다.
- 주파수 분해능 한계에 대해서는, 1 Hz 이하 미세 스텝이 가능한 고분해능 함수발생기를 사용하고 공진점·차단점 부근(예: 5000~5100 Hz, 11.2~11.3 kHz)을 10 Hz 이하 간격으로 세밀 스캔하여 f_p, f_s, f_1, f_2 의 실제 봉우리·골 바닥을 직접 포착함으로써 Z_p 봉우리 과소평가와 노치 깊이 과대평가를 제거한다.
- 소신호 측정의 상대오차에 대해서는, 오실로스코프 수직 감도를 측정 신호 크기에 맞춰 최소 레인지로 설정하고 평균화(averaging) 기능과 대역제한 필터로 잡음을 억제하며, 필요 시 차동 프로브나 록인 측정으로 mV 급 신호의 분해능을 높인다.
- 그래프 판독·보간 오차에 대해서는, 차단점·교점 부근의 측정점 밀도를 높여 보간 구간을 좁히고, 세미로그 축에서의 곡선 형상을 반영한 비선형 보간 또는 회귀를 사용하여 f_c, f_1, f_2 판독 정확도를 향상시킨다.
- 브레드보드 접촉 저항과 케이블·프로브 임피던스에 대해서는, 접점을 세척하고 산화된 점퍼선을 교체하며 케이블 길이를 최소화하고, 정밀이 요구되는 회로는 납땜 기판이나 BNC 직결로 구성하여 계통적 직렬저항을 줄인다.
- 소자 비이상성에 대해서는, 저손실(고 Q) 코일과 필름 커패시터 등 손실 탄젠트가 작은 부품을 선정하고, 측정 중 온도 변화를 줄여 소자값 드리프트를 억제함으로써 고주파 대역에서 실효 Q 저하를 완화한다.

## 결론

- 본 실험에서 명판값과 실측 소자값을 함께 사용해 병렬 공진 회로와 수동 필터(고역통과·대역통과·대역저지)의 특성을 분석한 결과, 코일 내부저항 R_l 을 포함한 이론 재계산값이 측정값과 매우 잘 일치하였다. 특히 고역통과필터의 차단주파수는 이론·진폭그래프·위상그래프가 1.6 kHz 부근으로 0.92~4.01% 이내에서 수렴하였고, 2 kHz 전압비는 0.28%, 대역통과필터의 통과대역 전압비는 0.13% 의 우수한 일치를 보였으며, 대역폭 판독 오차는 최대 4.80% 수준이었다. 공진 봉우리 과소평가(−32.8%)와 노치 깊이 과대평가(0.083 vs 0.168)는 주파수 분해능 한계로 진짜 공진·노치 주파수를 측정하지 못한 데 따른 것으로, 측정 차단주파수의 기하평균이 이론 노치 중심과 1.07% 로 일치한 점에서 특성 곡선의 위치 자체는 정확히 재현되었음을 확인하였다.
- 종합하면, 코일 내부저항을 무시한 이상화 가정으로는 큰 오차(예상 Q_l = 67.28)가 발생하지만 실측 R_l 을 포함한 재계산(Q_l = 10.86)은 측정과 잘 부합하므로, 수동 공진·필터 회로 해석에서는 실측 소자값과 코일 내부저항의 반영이 정확도 확보의 핵심임을 정량적으로 검증하였으며, 고분해능 주파수 스캔과 측정 환경 개선을 병행하면 잔여 오차를 더욱 줄일 수 있어 실험의 목적을 충분히 달성하였다고 판단한다.
