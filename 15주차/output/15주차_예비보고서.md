# 15주차 예비보고서

# 실험 목적

## Ch 14 Parallel Resonant Circuits (병렬 공진 회로)

- 병렬로 R-L-C가 연결되어 있을 때 주파수 변화에 따른 전압 및 전류를 이론적으로 계산해 보고, 실험을 통해 확인한다.
- 병렬 공진 주파수(resonant frequency) f_p 를 이론적으로 계산하고, 실험을 통해 확인한다.
    - 명판값 기반 식 f_p = (1/2π√LC)·√(1 − R_l²C/L) (Eq. 14.3) 와, Q_coil ≥ 10 일 때 적용되는 근사식 f_p = 1/(2π√LC) (Eq. 14.4) 의 두 결과를 비교한다.
- 주파수 변화에 따른 입력 임피던스(input impedance) Z_p 를 측정하고, 공진에서 Z_p 가 최대(순저항성)가 됨을 확인한다.
- 코일의 선택도 Quality factor (Q_l, Q_p)와 대역폭(bandwidth, BW = f_p/Q)의 관계를 확인한다.
- 100 kΩ 직렬저항을 이용해 입력 전류 I_s 가 주파수에 거의 무관한 정전류원처럼 동작함을 확인한다.

## Ch 15 Passive Filters (수동 필터)

- R-C를 이용한 high-pass filter (고역통과필터, Part 1)를 제작하고, 차단 주파수 f_c 와 전압비 A_v = V_o/V_i, 위상 응답을 실험으로 확인한다.
- R-L-C를 이용한 band-pass filter (대역통과필터, Part 2)를 제작하고, 공진(통과 대역 중심) 주파수와 대역폭을 실험으로 확인한다.
- (교재 Procedure Part 3 보충) R-L-C를 이용한 band-stop filter (대역저지필터, Part 3)를 제작하고, 저지 대역과 대역폭을 실험으로 확인한다.
- 차단 주파수가 출력이 최댓값의 0.707배로 떨어지고 R = X_C 가 되는 지점임을 확인하고, 필터 회로의 전달 방정식과 결과를 비교·검증한다.
- 주파수 응답을 세미로그(semi-log) 그래프에 도시하는 방법을 익힌다.

# 실험 이론

## 리액턴스 (Reactance)

- **개념**
    - 커패시터 임피던스 Z_C = 1/(jωC) 의 크기에서 용량성 리액턴스 X_C = 1/(ωC) = 1/(2πfC) 가 유도된다. 주파수가 높을수록 X_C 가 작아져 커패시터는 단락에 가까워진다.
    - 인덕터 임피던스 Z_L = jωL 의 크기에서 유도성 리액턴스 X_L = ωL = 2πfL 가 유도된다. 주파수가 높을수록 X_L 이 커져 인덕터는 개방에 가까워진다.

- **적용 방법**
    - Ch 15 Part 1 (HPF, C = 0.1 μF): f = 2 kHz 에서 X_C = 1/(2π × 2000 × 0.1×10⁻⁶) ≈ 795.8 Ω.
    - Ch 14 (L = 10 mH): f_p ≈ 5033 Hz 에서 X_L = 2π × 5033 × 0.01 ≈ 316.2 Ω.
    - 검산: 동일 f_p 에서 X_C = 1/(2π × 5033 × 0.1×10⁻⁶) ≈ 316.2 Ω → X_L ≈ X_C 로 공진 조건과 일치(✓).

## 병렬 공진 회로 (Parallel Resonant Circuit, Ch 14)

- **개념**
    - Fig 14.1 처럼 (R_l + L) 가지와 C 가지가 전류원 I 에 병렬로 연결된 회로. 어드미턴스는
      Y = 1/(R_l + jX_L) + 1/(−jX_C) = R_l/(R_l² + X_L²) + j[ 1/X_C − X_L/(R_l² + X_L²) ].
    - 공진은 임피던스가 순저항이 되는 지점, 즉 서셉턴스(허수부) = 0 인 조건이다. 따라서 1/X_C = X_L/(R_l² + X_L²) (Eq. 14.1).
    - 이 조건을 ω 에 대해 풀면 f_p = (1/2π√LC)·√(1 − R_l²C/L) (Eq. 14.3). 코일의 Q_coil = X_L/R_l ≥ 10 이면 R_l²C/L ≪ 1 이 되어 f_p ≈ 1/(2π√LC) (Eq. 14.4)로 단순화된다.
    - 공진 시 임피던스는 어드미턴스의 역수로 Z_Tp = (R_l² + X_L²)/R_l = L/(R_l C) (Eq. 14.2), 이때 V_C 가 최대가 된다.
    - 선택도 Q_l = X_L/R, 대역폭 BW = f₂ − f₁ = f_p/Q (Eq. 14.5).

- **적용 방법**
    - Ch 14 Part 1: L = 10 mH, C = 0.1 μF, R = R_1 + R_l (이상적 인덕터 R_l ≈ 0 가정 시 R ≈ 4.7 Ω).
    - f_p ≈ 1/(2π√(10×10⁻³ × 0.1×10⁻⁶)) = 1/(2π√(1×10⁻⁹)) ≈ 5033 Hz.
    - Q_coil = X_L/R = 316.2/4.7 ≈ 67.3 ≥ 10 → Eq. 14.4 근사 사용이 정당함.
    - Z_Tp = L/(R C) = 0.01/(4.7 × 0.1×10⁻⁶) ≈ 21.3 kΩ, BW = f_p/Q ≈ 5033/67.3 ≈ 74.8 Hz.
    - 검산: 공진에서 Y = R_l/(R_l² + X_L²) 로 허수부가 0 → Z_Tp 가 순저항(실수)임을 확인. 또한 Z_p ≈ 21.3 kΩ ≪ 100 kΩ 이므로 입력 정전류 근사 I_s ≈ E/100 kΩ 성립(✓).

## 수동 필터 개요 (Passive Filters)

- **개념**
    - 필터는 특정 주파수 대역의 신호는 통과시키고 나머지는 감쇠시키는 회로다. 저항·커패시터·인덕터만으로 구성되면 수동(passive) 필터, 연산증폭기 등 능동소자를 포함하면 능동(active) 필터다.
    - 차단 주파수(cutoff frequency) f_c 는 출력 전압비 A_v = V_o/V_i 가 최댓값의 0.707배(= 1/√2, 전력 기준 절반)로 떨어지는 주파수로 정의되며, 이 지점에서 저항과 리액턴스가 같다(R = X_C 또는 R = X_L).
    - 통과 대역과 저지 대역의 폭을 대역폭 BW = f₂ − f₁ 로 정의한다.

- **적용 방법**
    - R-C 필터의 차단 조건 R = X_C 에서 R = 1/(2πf_c C) → f_c = 1/(2πRC).
    - Ch 15 Part 1: R = 1 kΩ, C = 0.1 μF → f_c = 1/(2π × 1000 × 0.1×10⁻⁶) ≈ 1591.5 Hz.
    - 검산: f = f_c 에서 X_C = R 이므로 A_v = R/√(R² + X_C²) = 1/√2 ≈ 0.707 → 0.707 정의와 일치(✓).

## 고역통과필터 (High-Pass Filter, Ch 15 Part 1)

- **개념**
    - Fig 15.4 의 R-C HPF는 입력 → 직렬 C → 출력 저항 R(접지) 구조로, V_o 를 R 양단에서 취한다.
    - 저주파에서 X_C 가 커 커패시터가 개방처럼 동작 → V_o 작음(저지). 고주파에서 X_C 가 작아 단락처럼 동작 → V_o ≈ V_i (통과).
    - 전달비 V_o/V_i = R/(R − jX_C), 크기 |A_v| = R/√(R² + X_C²), 위상 θ = arctan(X_C/R) 로 V_o 가 V_i 보다 앞선다(leading network).

- **적용 방법**
    - R = 1 kΩ, C = 0.1 μF, f_c ≈ 1591.5 Hz (앞 절).
    - f = 2 kHz 에서 X_C ≈ 795.8 Ω → |A_v| = 1000/√(1000² + 795.8²) ≈ 0.782, θ = arctan(795.8/1000) ≈ 38.5° (V_o 가 V_i 를 앞섬).
    - 검산: f = f_c 에서 X_C = R → θ = arctan(1) = 45° → 교재 Procedure (i)의 "θ = 45° 인 주파수 = f_c" 와 일치(✓).

## 대역통과필터 (Band-Pass Filter, Ch 15 Part 2)

- **개념**
    - Fig 15.5 는 (R_l + L) 와 C 가 직렬로 연결된 직렬 공진 회로의 출력을 저항 R 양단에서 취하는 구조다.
    - 직렬 공진(X_L = X_C)에서 LC 직렬 임피던스가 최소(이상적으로 0)가 되어 전류와 V_o 가 최대 → 통과 대역 중심. 공진에서 벗어나면 LC 임피던스가 커져 V_o 가 감소 → 양쪽이 저지.
    - 직렬 공진 주파수 f_s = 1/(2π√LC), 선택도 Q_s = X_L/R_total, 대역폭 BW = f_s/Q_s = f₂ − f₁.

- **적용 방법**
    - L = 10 mH, C = 0.1 μF, R = 100 Ω (R_l ≈ 0 가정).
    - f_s = 1/(2π√(10×10⁻³ × 0.1×10⁻⁶)) ≈ 5033 Hz.
    - X_L = 2π × 5033 × 0.01 ≈ 316.2 Ω → Q_s = X_L/R = 316.2/100 ≈ 3.16, BW ≈ 5033/3.16 ≈ 1593 Hz.
    - 검산: f_s 에서 X_L ≈ X_C ≈ 316.2 Ω → 직렬 LC 임피던스 ≈ 0 → A_v(max) = R/(R + R_l) ≈ 1 (통과 대역 최대)(✓).

## 대역저지필터 (Band-Stop Filter, Ch 15 Part 3)

- **개념**
    - Fig 15.6 은 (R_l + L) 와 C 로 이루어진 병렬 공진 탱크가 신호 경로에 직렬로 놓이고, 출력 저항 R 이 접지측에 연결된 구조다(Band-Reject Filter, BRF 라고도 함).
    - 병렬 공진(X_L = X_C)에서 탱크 임피던스 Z_Tp = L/(R_l C) 가 최대가 되어 신호를 가로막아 V_o 가 최소 → 해당 대역 저지. 공진에서 벗어나면 탱크 임피던스가 작아져 V_o 가 회복 → 통과.
    - 공진 주파수 f_p = 1/(2π√LC) (Q_coil ≥ 10 근사), 대역폭 BW = f_p/Q.

- **적용 방법**
    - L = 1 mH, C = 0.2 μF, R = 100 Ω (R_l ≈ 0 가정).
    - f_p = 1/(2π√(1×10⁻³ × 0.2×10⁻⁶)) = 1/(2π√(2×10⁻¹⁰)) ≈ 11254 Hz ≈ 11.25 kHz.
    - X_L = 2π × 11254 × 1×10⁻³ ≈ 70.7 Ω, X_C = 1/(2π × 11254 × 0.2×10⁻⁶) ≈ 70.7 Ω.
    - 검산: f_p 에서 X_L ≈ X_C ≈ 70.7 Ω → 병렬 탱크 임피던스 최대 → V_o = V_i · R/(R + Z_Tp) 최소(저지 중심)(✓).

## 세미로그 주파수 응답 그래프

- **개념**
    - 필터 응답은 수 백 Hz~100 kHz 의 넓은 대역을 다루므로, 주파수 축을 로그(log) 스케일로 잡은 세미로그 그래프(가로=log f, 세로=A_v 또는 θ)에 도시한다.
    - 0.707 수평선과 응답 곡선의 교점에서 차단 주파수(f_c, f₁, f₂)를 읽는다.

- **적용 방법**
