### 실험 이론
- 판정: PASS

**항목별 확인**:

1. **DC 정상상태에서의 커패시터와 인덕터 동작**
   - 커패시터 개방(i_C = C·dv_C/dt = 0), 인덕터 단락(v_L = L·di_L/dt = 0) 개념 정확 ✓
   - Fig 17.4 회로에의 적용(C 개방 → V_C = V₂, L → R_l 직렬 등가) 올바름 ✓
   - 이상적 인덕터 가정 시 I = E/(R₁+R₂) 단순화 언급 ✓

2. **에너지 저장**
   - W_C = ½CV_C², W_L = ½LI² 공식 정확 ✓
   - 단위 변환(μF→F, mH→H) 주의사항 명시 ✓

3. **정현파 신호의 특성값**
   - v(t) = V_m sin(2πft+θ) 및 강의노트 표준식 v(t) = A cos(2πf_c t+θ) 병기 ✓
   - V_pp = 2V_m (강의노트: V_p-p = 2A) ✓
   - V_rms = V_m/√2 = V_pp/(2√2) ≈ 0.707×V_m, RMS 유도 과정 포함 ✓
   - 강의노트 RMS 공식 v_rms = A/√2 = V_p-p/(2√2) 와 일치 ✓

4. **오실로스코프 파형 해석**
   - 수직 감도(V/div), 수평 감도(time/div) 읽기법 ✓
   - GND·AC·DC 커플링 모드 동작 원리 정확 ✓
   - Part 3·4·5 적용 예시 수치 검증:
     - 500 Hz, 0.5 ms/div → 1주기 = 2 ms = 4 divisions ✓
     - v = 0.4 sin 62,832t → f = 62,832/(2π) ≈ 10,000 Hz ✓
     - v = 5 sin 377t → f ≈ 60 Hz ✓

5. **임피던스와 리액턴스**
   - X_C = 1/(2πfC), X_L = 2πfL 공식 정확 ✓
   - |Z| = √(R² + (X_L − X_C)²) ✓
   - 강의노트 공식 Z = R + jX_L − jX_C, X_L = 2πfL, X_C = 1/(2πfC) 와 일치 ✓
   - 수치 계산 검증:
     - X_C(1 μF, 100 Hz) = 1/(2π×100×10⁻⁶) ≈ 1,591.5 Ω ✓
     - C_T(1+0.47=1.47 μF) → X_CT ≈ 1,082.7 Ω ✓
     - X_L(10 mH, 2 kHz) = 2π×2000×0.01 ≈ 125.7 Ω ✓
     - X_LT(20 mH, 2 kHz) ≈ 251.3 Ω ✓

6. **센싱 저항을 이용한 전류 측정**
   - I(p-p) = V_Rs(p-p)/R_s, DMM rms → p-p 변환(×2√2) ✓
   - R_s = 100 Ω 선택 근거(측정 소자에 비해 충분히 작음) ✓
