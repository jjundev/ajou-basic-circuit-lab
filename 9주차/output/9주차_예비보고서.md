# 실험 목적

## DC Ch 17 R-L and R-L-C Circuits with a dc Source Voltage (Part 3)
- DC 정상상태에서 R-L-C 직병렬 회로의 동작 특성을 이해한다.
- DC 정상상태 시 커패시터가 **개방 회로(Open Circuit)**, 인덕터가 **단락 회로(Short Circuit)**로 동작함을 실험적으로 확인한다.
- 커패시터가 병렬로 연결된 R-L-C 회로에서 각 소자의 전압(V₁, V_C)과 전류(I, I₂)를 계산하고 측정값과 비교한다.
- 커패시터와 인덕터에 저장되는 에너지(W_C, W_L)를 계산한다.

## AC Ch 2 The Oscilloscope (Parts 3, 4, 5)
- 오실로스코프의 전반적인 사용 방법을 숙지한다.
- 함수 발생기(Function Generator)를 이용하여 정현파의 **진폭(amplitude)**을 설정하고 오실로스코프로 확인하는 방법을 익힌다.
- 오실로스코프의 **수직 감도(Vertical Sensitivity, V/div)**와 **수평 감도(Horizontal Sensitivity, time/div)**를 조절하여 파형을 적절히 표시하는 방법을 학습한다.
- DMM의 AC rms 측정 모드를 이용하여 정현파 신호의 실효값(V_eff)을 설정하고, 이를 오실로스코프의 피크-피크 값과 비교하여 V_rms와 V_pp의 관계를 확인한다.
- 오실로스코프를 활용하여 함수 발생기의 출력 **주파수(frequency)**를 미세 조정하는 방법을 익힌다.
- 정현파 신호에 **DC 레벨(DC offset)**을 더했을 때 파형의 변화를 관찰하고, DC/AC/GND 커플링 모드 전환에 따른 차이를 이해한다.

## AC Ch 3 R-L-C Components (Parts 1, 2, 3)
- 교류 전원이 인가된 상태에서 **저항(R)**, **커패시터(C)**, **인덕터(L)** 각 소자의 특성을 개별적으로 측정한다.
- 센싱 저항(R_s = 100 Ω)을 이용하여 교류 회로의 전류를 간접 측정하는 방법을 익힌다.
- **용량성 리액턴스(X_C = 1/(2πfC))**를 실험적으로 측정하고, 이론 계산값과 비교한다.
- **유도성 리액턴스(X_L = 2πfL)**를 실험적으로 측정하고, 이론 계산값과 비교한다.
- 커패시터 병렬 연결 시 합성 리액턴스와 등가 커패시턴스를, 인덕터 직렬 연결 시 합성 리액턴스와 등가 인덕턴스를 실험적으로 확인한다.

# 실험 이론

## DC 정상상태에서의 커패시터와 인덕터 동작

- **개념**
  - DC 전원이 인가된 회로에서 **충분한 시간이 경과**하여 과도 상태가 끝나면 회로는 **DC 정상상태(steady state)**에 도달한다.
  - DC 정상상태에서 커패시터는 완전히 충전되어 더 이상 전류가 흐르지 않으므로 **개방 회로(Open Circuit)**로 동작한다. 즉 커패시터를 통과하는 전류 i_C = C(dv_C/dt) = 0 이다 (전압이 일정하므로 dv_C/dt = 0).
  - DC 정상상태에서 인덕터는 전류 변화가 없으므로 양단 전압이 0이 되어 **단락 회로(Short Circuit)**로 동작한다. 즉 v_L = L(di_L/dt) = 0 이다 (전류가 일정하므로 di_L/dt = 0).

- **적용 방법**
  - DC Ch 17 Part 3의 Fig 17.4 회로에서:
    - 인덕터 L = 10 mH → **단락(Short)**: 도선으로 대체. 단, 인덕터의 내부 저항 R_l은 남는다.
    - 커패시터 C = 1 μF → **개방(Open)**: 커패시터 분기로 전류가 흐르지 않음.
    - 결과적으로 R₂와 C의 병렬 조합에서 C가 개방되므로, 커패시터 양단 전압 V_C = R₂에 걸리는 전압 V₂와 같아진다.
    - 전체 전류 I는 R₁ → R_l(인덕터 내부저항) → R₂의 직렬 경로를 통해서만 흐른다.
    - I₂(R₂를 통해 흐르는 전류) = I (커패시터 분기가 개방이므로 분류 없음).
    - 이상적인 인덕터(R_l ≈ 0)를 가정하면 I = E / (R₁ + R₂) 로 단순화된다.

## 에너지 저장

- **개념**
  - 커패시터에 저장되는 에너지: W_C = ½CV_C²
  - 인덕터에 저장되는 에너지: W_L = ½LI²
  - DC 정상상태에서 커패시터는 V_C 전압으로 충전되어 에너지를 저장하고, 인덕터는 전류 I가 흐르며 에너지를 저장한다.

- **적용 방법**
  - DC Ch 17 Part 3에서 계산된 V_C와 I 값을 이용하여 W_C, W_L을 각각 계산한다.
  - 단위에 주의: C는 μF → F로 변환 (1 μF = 1×10⁻⁶ F), L은 mH → H로 변환 (10 mH = 10×10⁻³ H).

## 정현파 신호의 특성값

- **개념**
  - 정현파 신호: v(t) = V_m sin(2πft + θ) 또는 v(t) = A cos(2πf_c t + θ)
  - **최대값(Peak value, V_m)**: 파형의 최대 진폭
  - **피크-피크값(Peak-to-peak value, V_pp)**: V_pp = 2V_m (양의 최대값에서 음의 최대값까지의 차이)
  - **주기(Period, T)**: T = 1/f (한 사이클 완료에 걸리는 시간)
  - **주파수(Frequency, f)**: 단위 시간(1초)당 사이클 수, 단위 Hz
  - **실효값(RMS value, V_rms)**: 정현파의 경우 V_rms = V_m / √2 = V_pp / (2√2) ≈ 0.707 × V_m
    - RMS값은 동일한 전력을 소비하는 DC 전압에 해당하는 등가 값이다.
    - 유도: V_rms = √(1/T × ∫₀ᵀ v²(t) dt)이고, v(t) = V_m sin(2πft)을 대입하면
    - = √(1/T × ∫₀ᵀ V_m² sin²(2πft) dt) = √(V_m²/2) = V_m / √2

- **적용 방법**
  - AC Ch 2 Part 3에서 v = V_m sin 2π500t 신호를 생성할 때:
    - V_m = 3 V이면 V_pp = 6 V, V_eff = 0.707 × 3 = 2.121 V
    - DMM의 AC rms 모드로 V_eff를 설정하면 해당하는 피크-피크 파형을 오실로스코프에서 확인할 수 있다.
  - AC Ch 2 Part 3(i)에서 v = 0.5 sin 2π500t이면:
    - V_eff = 0.707 × 0.5 = 0.354 V, V_pp = 1 V

## 오실로스코프 파형 해석

- **개념**
  - 오실로스코프 화면에서 파형의 물리량을 읽으려면 **감도(sensitivity)** 설정을 이용한다.
  - **수직 감도(Vertical Sensitivity)**: 화면 1눈금(division)당 전압값 (V/div)
    - 전압 = (수직 눈금 수) × (수직 감도)
    - 예: 3 divisions × 2 V/div = 6 V(p-p)
  - **수평 감도(Horizontal Sensitivity)**: 화면 1눈금당 시간 (time/div, ms/div 또는 μs/div)
    - 주기 T = (1주기의 수평 눈금 수) × (수평 감도)
    - 주파수 f = 1/T
  - **DC/AC/GND 커플링 모드**:
    - **GND 모드**: 입력을 차단하고 0 V 기준선을 설정. 어떤 신호가 연결되어 있어도 수평 직선만 표시.
    - **AC 모드**: DC 성분을 차단하고 AC 성분만 표시 (DC 오프셋 제거). 커플링 커패시터를 통해 DC를 차단.
    - **DC 모드**: DC + AC 성분을 모두 표시. DC 오프셋이 포함된 파형이 그대로 나타남.

- **적용 방법**
  - AC Ch 2 Part 3: 수직 감도 1 V/div, 수평 감도 0.5 ms/div에서 500 Hz 정현파를 표시하면 한 주기가 4 divisions(= 2 ms = 1/500 Hz)에 해당한다.
  - AC Ch 2 Part 4: 주어진 v = V_m sin ωt에서 ω = 2πf로부터 주파수를 계산하고, 적절한 수직/수평 감도를 설정한다.
    - 예: v = 0.4 sin 62,832t → f = 62,832/(2π) ≈ 10,000 Hz, T = 100 μs
    - 예: v = 5 sin 377t → f = 377/(2π) ≈ 60 Hz, T ≈ 16.67 ms
  - AC Ch 2 Part 5: DC 레벨이 더해진 정현파를 DC 모드에서 관찰하면 파형이 DC 전압만큼 수직 이동(shift)하며, AC 모드로 전환하면 DC 성분이 차단되어 0 V 중심으로 표시된다. GND 모드에서는 입력이 완전히 차단되어 기준선(0 V)만 나타난다.

## 임피던스와 리액턴스

- **개념**
  - **저항(Resistance, R)**: 주파수에 무관하게 일정한 값을 가지며, 전압과 전류가 동위상이다.
    - R = V_R(p-p) / I_R(p-p)
  - **용량성 리액턴스(Capacitive Reactance, X_C)**: 커패시터가 교류 전류의 흐름에 대해 나타내는 저항 성분
    - X_C = 1 / (2πfC)
    - 주파수가 높을수록, 커패시턴스가 클수록 X_C는 감소한다.
    - X_C = V_C(p-p) / I_C(p-p) 로 실험적으로 측정 가능
  - **유도성 리액턴스(Inductive Reactance, X_L)**: 인덕터가 교류 전류의 흐름에 대해 나타내는 저항 성분
    - X_L = 2πfL
    - 주파수가 높을수록, 인덕턴스가 클수록 X_L은 증가한다.
    - X_L = V_L(p-p) / I_L(p-p) 로 실험적으로 측정 가능
  - **총 임피던스(Total Impedance, Z)**:
    - Z = R + jX_L - jX_C
    - |Z| = √(R² + (X_L - X_C)²)

- **적용 방법**
  - AC Ch 3 Part 1: R = 3.3 kΩ 단독 회로(Fig 3.1)와 R₁ + R₂ 직렬 회로(Fig 3.2)에서 전류 I를 센싱 저항으로 측정하고, R = V_R(p-p) / I(p-p) 로 저항값을 계산하여 DMM 실측값과 비교한다.
  - AC Ch 3 Part 2: C = 1 μF, f = 100 Hz일 때 X_C(calc) = 1/(2π × 100 × 1×10⁻⁶) ≈ 1,591.5 Ω. 센싱 저항으로 전류를 측정한 뒤 X_C(meas) = V_C(p-p) / I(p-p) 와 비교한다. 0.47 μF 병렬 추가 시 C_T = 1 + 0.47 = 1.47 μF → X_CT = 1/(2π × 100 × 1.47×10⁻⁶) ≈ 1,082.7 Ω 으로 감소를 확인한다.
  - AC Ch 3 Part 3: L = 10 mH, f = 2 kHz일 때 X_L(calc) = 2π × 2000 × 10×10⁻³ ≈ 125.7 Ω. 센싱 저항으로 전류를 측정한 뒤 X_L(meas) = V_L(p-p) / I(p-p) 와 비교한다. 두 번째 10 mH 직렬 추가 시 L_T = 20 mH → X_LT = 2π × 2000 × 20×10⁻³ ≈ 251.3 Ω 으로 증가를 확인한다.

## 센싱 저항을 이용한 전류 측정

- **개념**
  - 교류 회로에서 전류를 직접 측정하기 어려울 때, 회로에 작은 값의 **센싱 저항(R_s)**을 직렬로 삽입하여 양단 전압을 측정하고 옴의 법칙으로 전류를 계산한다.
  - I(p-p) = V_Rs(p-p) / R_s
  - 센싱 저항은 회로에 미치는 영향을 최소화하기 위해 측정 대상 소자에 비해 충분히 작은 값(100 Ω)을 사용한다.
  - DMM으로 V_Rs의 rms값을 측정한 경우, V_Rs(peak) = V_Rs(rms) × √2, V_Rs(p-p) = 2 × V_Rs(peak) = 2√2 × V_Rs(rms) 으로 변환한다.

- **적용 방법**
  - AC Ch 3의 모든 파트(Fig 3.1~3.4)에서 R_s = 100 Ω이 회로에 직렬로 삽입되어 있다.
  - DMM AC V 모드로 V_Rs(rms)를 측정 → V_Rs(p-p) = 2√2 × V_Rs(rms) → I(p-p) = V_Rs(p-p) / R_s
  - 센싱 저항이 충분히 작기 때문에 (100 Ω << 3.3 kΩ 또는 X_C, X_L) 회로 동작에 미치는 영향이 최소화된다.

## R-L-C 소자의 직렬/병렬 합성

- **개념**
  - **저항 직렬 합성**: R_T = R₁ + R₂ + ... + R_N
  - **저항 병렬 합성**: 1/R_T = 1/R₁ + 1/R₂ + ... + 1/R_N
  - **인덕터 직렬 합성**: L_T = L₁ + L₂ + ... + L_N (저항과 동일한 형태)
  - **인덕터 병렬 합성**: 1/L_T = 1/L₁ + 1/L₂ + ... + 1/L_N
  - **커패시터 직렬 합성**: 1/C_T = 1/C₁ + 1/C₂ + ... + 1/C_N (저항의 병렬과 동일한 형태)
  - **커패시터 병렬 합성**: C_T = C₁ + C₂ + ... + C_N (저항의 직렬과 동일한 형태)

- **적용 방법**
  - AC Ch 3 Part 1: R₁(1.2 kΩ)과 R₂(3.3 kΩ) 직렬 → R_T = 1.2 + 3.3 = 4.5 kΩ
  - AC Ch 3 Part 2: C₁(1 μF)과 C₂(0.47 μF) 병렬 → C_T = 1 + 0.47 = 1.47 μF
  - AC Ch 3 Part 3: L₁(10 mH)과 L₂(10 mH) 직렬 → L_T = 10 + 10 = 20 mH
