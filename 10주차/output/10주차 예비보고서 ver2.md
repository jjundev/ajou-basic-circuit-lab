# 실험 목적

## Ch 4 Frequency Response of R, L, and C Components

- 교류 전원이 인가된 상황에서 주파수가 변화할 때 저항(R), 인덕터(L), 커패시터(C) 각 소자의 임피던스(리액턴스) 변화를 측정하고 이론값과 비교한다.
- 저항의 저항값이 주파수에 무관하게 일정한지 확인한다 (Part 1).
- 인덕터의 유도 리액턴스 X_L = 2πfL이 주파수에 비례하여 선형적으로 증가하는지 확인한다 (Part 2).
- 커패시터의 용량 리액턴스 X_C = 1/(2πfC)가 주파수에 반비례하여 비선형적으로 감소하는지 확인한다 (Part 3).
- 감지 저항(R_s)을 이용하여 회로 전류를 간접적으로 측정하는 방법을 익힌다.
- X_L vs f 및 X_C vs f 그래프로부터 인덕턴스(L)와 커패시턴스(C)의 명판값(nameplate value)을 역산하여 비교한다.

## Ch 5 Frequency Response of the Series R-L Network

- 직렬 R-L 네트워크에서 주파수 변화에 따른 V_L, V_R, I의 변화를 측정한다.
- 주파수가 증가함에 따라 인덕터 양단 전압 V_L이 증가하고 저항 양단 전압 V_R이 감소하는 경향을 확인한다.
- 주파수 변화에 따른 R과 X_L의 임피던스를 구하고, X_L = R이 성립하는 주파수를 확인한다.
- AC 회로에서 전압의 벡터 합산(피타고라스 정리)을 확인한다: E_(p-p) = √(V_L(p-p)² + V_R(p-p)²).
- 측정된 데이터로부터 위상각 θ = tan⁻¹(X_L / R) = tan⁻¹(V_L / V_R)을 계산하여 주파수에 따른 전압과 전류의 위상차 변화를 확인한다.
- 저주파에서 인덕터가 단락(short-circuit)에 가깝고, 고주파에서 개방(open-circuit)에 가까워지는 극한 동작을 검증한다.

## Ch 6 Frequency Response of the Series R-C Network

- 직렬 R-C 네트워크에서 주파수 변화에 따른 V_C, V_R, I의 변화를 측정한다.
- 주파수가 증가함에 따라 커패시터 양단 전압 V_C가 감소하고 저항 양단 전압 V_R이 증가하는 경향을 확인한다.
- 주파수 변화에 따른 R과 X_C의 임피던스를 구하고, X_C = R이 성립하는 주파수를 확인한다.
- AC 회로에서 전압의 벡터 합산(피타고라스 정리)을 확인한다: E_(p-p) = √(V_C(p-p)² + V_R(p-p)²).
- 측정된 데이터로부터 위상각 θ = -tan⁻¹(X_C / R) = -tan⁻¹(V_C / V_R)을 계산하여 주파수에 따른 전압과 전류의 위상차 변화를 확인한다.
- 저주파에서 커패시터가 개방(open-circuit)에 가깝고, 고주파에서 단락(short-circuit)에 가까워지는 극한 동작을 검증한다.

# 실험 준비물

- **디지털 멀티미터 (DMM)**
    - 저항 측정(Ω 모드), AC 전류 측정(A 모드), AC 전압 측정(V 모드)에 사용
    - AC 전류 측정 시 반드시 AC 모드로 전환할 것 (DC 모드 시 0 표시)
    - 상용 DMM의 전류 측정은 대부분 1 kHz 이하 주파수로 제한되므로, 고주파 실험에서는 감지 저항을 통한 간접 측정법 사용

- **오실로스코프 (Oscilloscope)**
    - 회로에 인가되는 전압 파형 및 peak-to-peak 전압 관측에 사용
    - Horizontal 노브로 time/div(수평 스케일) 조정, Vertical 노브로 volt/div(수직 스케일) 조정
    - Meas 버튼으로 주파수, peak-to-peak 값 등을 화면에 표시
    - 채널 입력 단자(ch1, ch2)를 회로의 측정 지점에 연결
    - 주의: 오실로스코프와 전원의 그라운드가 공통이므로, 회로 소자 배치 시 그라운드 단자가 올바르게 연결되어야 함 (잘못 연결 시 소자 단락 위험)

- **함수 발생기 (Audio Oscillator / Function Generator)**
    - 오실로스코프 내장 파형 발생기(Wave Gen) 사용
    - 사인파(Sine Wave) 출력, 주파수 범위: 100 mHz ~ 20 MHz
    - 진폭 범위: 20 mVpp ~ 5 Vpp (개방 회로 기준)
    - DC offset: ±2.5 V (Hi-Z)
    - 실험별 E_s 설정: Ch 4 Part 1은 V_R = 4 V(p-p), Ch 4 Part 2·3 및 Ch 5·6은 E_s = 2 V(p-p) (강의노트 기준)

- **주파수 카운터 (Frequency Counter)**
    - 인가 주파수의 정확한 값을 확인하는 데 사용 (가용 시)

- **탄소 저항 1 kΩ × 1개**
    - Ch 4 Part 1: 주파수 변화에 따른 저항값 불변 확인용

    - Ch 5 Part 1: 직렬 R-L 네트워크의 저항 소자
    - 감지 저항은 측정 대상 소자의 리액턴스보다 충분히 작아야 전류 측정에 영향을 주지 않음

# 실험 이론

## 1. 임피던스(Impedance)의 개념

- **개념**
    - AC 회로에서 전류의 흐름을 방해하는 총체적 크기를 임피던스(Z)라 하며, 저항(R)과 리액턴스(X)의 복소수 합으로 표현된다.
    - 총 임피던스: **Z = R + jX_L - jX_C**
    - 여기서 j는 허수 단위(j² = -1), X_L은 유도 리액턴스, X_C는 용량 리액턴스이다.
    - 임피던스의 크기: |Z| = √(R² + (X_L - X_C)²)
    - 단위: Ω (옴)

- **적용 방법**
    - 직렬 회로에서는 각 소자의 임피던스를 복소수로 더하여 총 임피던스를 구한다.
    - 전류는 I = E / Z_T 로 구하며, 각 소자의 전압은 V = I × Z_소자 로 구한다.
    - 임피던스의 실수부가 저항, 허수부가 리액턴스이다.

## 2. 저항(R)의 주파수 응답

- **개념**
    - 탄소 저항의 저항값은 인가되는 주파수에 무관하게 일정하다 (극단적으로 높은 주파수 제외).
    - 직렬/병렬 합성 저항도 마찬가지로 주파수에 독립적이다.
    - 직렬 합성: R_T = R₁ + R₂ + R₃
    - 병렬 합성: 1/R_T = 1/R₁ + 1/R₂ + 1/R₃

- **적용 방법**
    - Ch 4 Part 1에서 V_R(p-p) = 4 V로 고정하고 주파수를 변화시키며 전류를 측정한다.
    - 각 주파수에서 R = V_R(rms) / I_rms를 계산하여 값이 일정한지 확인한다.
    - RMS 변환: V_rms = 0.707 × (V_(p-p) / 2) = V_(p-p) / (2√2)

## 3. 유도 리액턴스(X_L)와 인덕터의 주파수 응답

- **개념**
    - 인덕터의 리액턴스는 주파수에 정비례한다: **X_L = 2πfL = ωL**
    - 주파수를 두 배로 하면 리액턴스도 두 배가 된다 (선형 관계).
    - 극한 동작:
        - 저주파(f → 0): X_L = 2π(0)L = 0 Ω → **단락 회로(Short Circuit)** 등가
        - 고주파(f → ∞): X_L → ∞ Ω → **개방 회로(Open Circuit)** 등가
    - 직렬 합성: L_T = L₁ + L₂ + ··· + L_N
    - 병렬 합성: 1/L_T = 1/L₁ + 1/L₂ + ··· + 1/L_N

- **적용 방법**
    - Ch 4 Part 2에서 V_L(p-p) = 2 V(p-p)로 고정하고 주파수를 변화시키며 감지 저항 R_s 양단 전압을 측정한다.
    - 전류: I_(p-p) = V_Rs(p-p) / R_s(measured)
    - 측정 리액턴스: X_L(measured) = V_L(p-p) / I_(p-p)
    - 계산 리액턴스: X_L(calculated) = 2πfL (명판값 L = 10 mH 사용)
    - X_L vs f 그래프는 원점을 지나는 직선이 되어야 한다.
    - 그래프에서 특정 주파수의 X_L을 읽고 L = X_L / (2πf)로 인덕턴스를 역산한다.

## 4. 용량 리액턴스(X_C)와 커패시터의 주파수 응답

- **개념**
    - 커패시터의 리액턴스는 주파수에 반비례한다: **X_C = 1/(2πfC) = 1/(ωC)**
    - 주파수가 증가하면 리액턴스는 비선형적으로 감소한다 (쌍곡선 형태).
    - 극한 동작:
        - 저주파(f → 0): X_C → ∞ Ω → **개방 회로(Open Circuit)** 등가
        - 고주파(f → ∞): X_C = 0 Ω → **단락 회로(Short Circuit)** 등가
    - 직렬 합성: 1/C_T = 1/C₁ + 1/C₂ + ··· + 1/C_N
    - 병렬 합성: C_T = C₁ + C₂ + ··· + C_N

- **적용 방법**
    - Ch 4 Part 3에서 V_C(p-p)를 고정하고 주파수를 변화시키며 감지 저항 양단 전압을 측정한다.
    - 측정 리액턴스: X_C(measured) = V_C(p-p) / I_(p-p)
    - 계산 리액턴스: X_C(calculated) = 1/(2πfC) (명판값 C = 0.1 μF 사용)
    - X_C vs f 그래프는 비선형 감소 곡선(쌍곡선)이 되어야 한다.
    - X_L vs f (직선)와 X_C vs f (쌍곡선) 그래프의 형태를 비교한다.
    - 그래프에서 특정 주파수의 X_C를 읽고 C = 1/(2πfX_C)로 커패시턴스를 역산한다.

## 5. 직렬 R-L 회로의 주파수 응답

- **개념**
    - 직렬 R-L 회로의 임피던스: **Z = R + jωL = Z_T∠θ**
    - 임피던스 크기: **Z_T = √(R² + (ωL)²) = √(R² + X_L²)**
    - 위상각: **θ = tan⁻¹(ωL / R) = tan⁻¹(X_L / R)**
    - θ > 0이므로 전류가 전압보다 뒤진다 (전압이 전류를 앞선다, lagging).
    - 전압의 관계 (AC KVL, 벡터 합산):
        - 직렬 AC 회로에서 각 소자 양단 전압은 위상이 다르므로 단순 산술 합이 아닌 벡터 합으로 더해진다.
        - **E_(p-p) = √(V_L(p-p)² + V_R(p-p)²)** (피타고라스 정리)
        - 따라서 V_L(p-p) + V_R(p-p) ≠ E_(p-p) (산술 합은 전원 전압보다 크게 나타남)
    - 주파수에 따른 동작:
        - 저주파: X_L ≈ 0 → Z ≈ R → V_R ≈ E, V_L ≈ 0, θ ≈ 0° (주로 저항성)
        - 고주파: X_L >> R → Z ≈ X_L → V_L ≈ E, V_R ≈ 0, θ ≈ 90° (주로 유도성)
        - X_L = R일 때: θ = 45°, V_L = V_R

- **적용 방법**
    - Ch 5 Part 1에서 E_s = 2 V(p-p)로 고정하고 주파수를 1 kHz ~ 10 kHz 범위에서 변화시킨다.
    - 각 주파수에서 V_L(p-p)과 V_R(p-p)을 측정한다.
    - 주의: V_R 측정 시 R과 L의 위치를 교환하여 오실로스코프 그라운드 단락 문제를 방지한다.
    - I_(p-p) = V_R(p-p) / R_measured로 전류를 계산한다.
    - V_L(p-p) vs f 및 V_R(p-p) vs f 곡선을 그려 교차점(V_L = V_R, 즉 X_L = R)을 확인한다.
    - I_(p-p) vs f 곡선은 V_R(p-p) vs f 곡선과 같은 형태(주파수 증가 시 감소)를 보인다.
    - 피타고라스 정리로 V_L(p-p) = √(E_(p-p)² - V_R(p-p)²)를 계산하여 측정값과 비교한다.
    - 위상각: θ = tan⁻¹(V_L(p-p) / V_R(p-p))로 주파수별 위상차를 계산한다.

## 6. 직렬 R-C 회로의 주파수 응답

- **개념**
    - 직렬 R-C 회로의 임피던스: **Z = R + 1/(jωC) = R - j/(ωC) = Z_T∠θ**
    - 임피던스 크기: **Z_T = √(R² + (1/(ωC))²) = √(R² + X_C²)**
    - 위상각: **θ = -tan⁻¹(1/(ωCR)) = -tan⁻¹(X_C / R)**
    - θ < 0이므로 전류가 전압보다 앞선다 (전압이 전류를 뒤진다, leading).
    - 전압의 관계 (AC KVL, 벡터 합산):
        - **E_(p-p) = √(V_C(p-p)² + V_R(p-p)²)** (피타고라스 정리)
        - 따라서 V_C(p-p) + V_R(p-p) ≠ E_(p-p)
    - 주파수에 따른 동작:
        - 저주파: X_C >> R → Z ≈ X_C → V_C ≈ E, V_R ≈ 0, θ ≈ -90° (주로 용량성)
        - 고주파: X_C ≈ 0 → Z ≈ R → V_R ≈ E, V_C ≈ 0, θ ≈ 0° (주로 저항성)
        - X_C = R일 때: θ = -45°, V_C = V_R

- **적용 방법**
    - Ch 6 Part 1에서 E_s = 2 V(p-p)로 고정하고 주파수를 1 kHz ~ 10 kHz 범위에서 변화시킨다.
    - 각 주파수에서 V_C(p-p)과 V_R(p-p)을 측정한다.
    - 주의: V_R 측정 시 R과 C의 위치를 교환하여 오실로스코프 그라운드 단락 문제를 방지한다.
    - I_(p-p) = V_R(p-p) / R_measured로 전류를 계산한다.
    - V_C(p-p) vs f 및 V_R(p-p) vs f 곡선을 그려 교차점(V_C = V_R, 즉 X_C = R)을 확인한다.
    - I_(p-p) vs f 곡선은 V_R(p-p) vs f 곡선과 같은 형태(주파수 증가 시 증가)를 보인다.
    - 피타고라스 정리로 V_C(p-p) = √(E_(p-p)² - V_R(p-p)²)를 계산하여 측정값과 비교한다.
    - 위상각: θ = -tan⁻¹(V_C(p-p) / V_R(p-p))로 주파수별 위상차를 계산한다.

## 7. Peak-to-Peak 값과 RMS 값의 변환

- **개념**
    - 사인파 전압에서 peak-to-peak 값과 RMS 값의 관계:
        - V_peak = V_(p-p) / 2
        - **V_rms = V_peak / √2 = 0.707 × V_peak = V_(p-p) / (2√2)**
        - 또는: V_rms = 0.707 × (V_(p-p) / 2)
    - 전류에 대해서도 동일한 관계가 성립한다.

- **적용 방법**
    - Ch 4 Part 1의 Table 4.1에서 V_R(p-p) = 4 V를 V_R(rms)로 변환: V_R(rms) = 0.707 × (4/2) = 1.414 V
    - DMM으로 측정한 I_rms와 계산된 V_R(rms)로 R = V_R(rms) / I_rms를 구한다.
    - Peak-to-peak 전압/전류 값은 오실로스코프로, RMS 값은 DMM으로 측정하므로 변환이 필요하다.

## 8. 감지 저항(Sensing Resistor)을 이용한 전류 간접 측정

- **개념**
    - 상용 DMM의 AC 전류 측정은 대부분 1 kHz 이하 주파수에서만 유효하다.
    - 고주파 영역에서는 회로에 작은 값의 감지 저항(R_s)을 직렬로 삽입하고, R_s 양단 전압(V_Rs)을 측정하여 전류를 간접적으로 구한다.
    - **I = V_Rs / R_s** (옴의 법칙)
    - 감지 저항은 측정 대상 리액턴스(X_L 또는 X_C)에 비해 충분히 작아야 회로 동작에 영향을 최소화한다.

- **적용 방법**
    - Ch 4 Part 2, Part 3: R_s = 100 Ω (또는 강의노트 기준 별도 저항)을 감지 저항으로 사용한다.
    - Ch 5, Ch 6: R = 100 Ω (Ch 5) 또는 R = 1 kΩ (Ch 6)이 회로의 저항 소자이자 전류 측정에 활용된다.
    - V_Rs(p-p) 측정 후 I_(p-p) = V_Rs(p-p) / R_s(measured)로 peak-to-peak 전류를 계산한다.

## 9. AC 회로의 KVL과 벡터 합산 (피타고라스 정리)

- **개념**
    - AC 직렬 회로에서 키르히호프 전압 법칙(KVL)은 여전히 성립하지만, 각 소자 양단 전압이 서로 다른 위상을 가지므로 **벡터(페이저) 합산**으로 적용해야 한다.
    - R-L 회로: V_R은 전류와 동위상, V_L은 전류보다 90° 앞선다 → 두 전압은 90° 위상차
    - R-C 회로: V_R은 전류와 동위상, V_C는 전류보다 90° 뒤진다 → 두 전압은 90° 위상차
    - 따라서 전원 전압: **E = √(V_R² + V_L²)** 또는 **E = √(V_R² + V_C²)**
    - 산술적 합 V_R + V_L (또는 V_R + V_C)은 E보다 항상 크게 나타난다.

- **적용 방법**
    - Ch 5 Table 5.3: 임의 주파수에서 V_L(p-p)와 V_R(p-p)를 읽고 산술 합을 구해 E_(p-p)와 비교한다.
    - Ch 5 Table 5.5: V_L(p-p) = √(E_(p-p)² - V_R(p-p)²)로 계산값과 측정값을 비교한다.
    - Ch 6 Table 6.3: 임의 주파수에서 V_C(p-p)와 V_R(p-p)를 읽고 산술 합을 구해 E_(p-p)와 비교한다.
    - Ch 6 Table 6.5: V_C(p-p) = √(E_(p-p)² - V_R(p-p)²)로 계산값과 측정값을 비교한다.
