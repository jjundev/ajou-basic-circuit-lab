## 수정 권고사항

### 오류 1 — Table 4.4 V_C 값 수정 (HIGH)

STT 파일(4-3)에서 강사가 V_C = **1 V**(p-p)로 실험을 진행함을 명시함.
보고서의 V_C = 2 V를 1 V로 수정하면 X_C 계산값은 변하지 않으나(X_C는 V_C 고정값에 무관),
V_Rs = V_C × R_s / X_C 계산이 모두 절반으로 변경됨.

```
수정 전: V_C(p-p) = 2 V (고정, 강의노트 기준)
수정 후: V_C(p-p) = 1 V (고정, STT 기준)
```

### 오류 2 — Table 4.4 C_T = 0.57 μF 추가 계산 (MEDIUM)

STT에서 0.1 μF + 0.47 μF 병렬(C_T = 0.57 μF) 추가 실험이 확인됨.
해당 커패시턴스에 대한 X_C 계산 열(column)을 Table 4.4에 추가할 것.

```
C_T = 0.1 + 0.47 = 0.57 μF
X_C(C_T) = 1 / (2πf × 0.57×10⁻⁶)
```

### 오류 3 — Table 6.1 (f=1 kHz) 중간 계산 정정 (LOW)

```
수정 전: 1591.55² = 2,532,040
수정 후: 1591.55² = 2,533,032
         Z_T = √(1,000,000 + 2,533,032) = √3,533,032 = 1879.63 Ω
```
최종 V_R = 1.06 V, V_C = 1.69 V 값은 변경 없음.
