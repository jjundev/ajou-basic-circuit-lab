# 14.1 풀이

> 출처: 교재 14장, 사용자 첨부 이미지, 1순위 근거 14주차 강의노트(-3dB 정의) + ⚠ 강의 밖(RL 필터 전달함수 — 교재/일반 회로이론 보강), 풀이일 2026-06-14

## 문제 원문

**14.1**
a) Find the cutoff frequency in hertz for the RL filter shown in Fig. P14.1.
b) Calculate H(jω) at ω_c, 0.125ω_c, and 8ω_c.
c) If v_i = 20 cos ωt V, write the steady-state expression for v_o when ω = ω_c, ω = 0.125ω_c, and ω = 8ω_c.

**Fig. P14.1 회로:** 직렬 50 mH 인덕터 → 병렬 1.2 kΩ 저항. v_o는 1.2 kΩ 양단 전압.

---

### 1. 문제 정리

| 항목 | 값 |
|---|---|
| 회로 | 직렬 L = 50 mH → 병렬 R = 1.2 kΩ, v_o는 R 양단 |
| 입력 v_i | peak 진폭 표기 |
| (a) 구할 것 | 차단주파수 f_c [Hz] |
| (b) 구할 것 | H(jω) at ω_c, 0.125ω_c, 8ω_c |
| (c) 구할 것 | v_i = 20 cos ωt V → 정상상태 v_o |

**규약:** 진폭 = peak 기준, 각도 = °(도), 인덕터 임피던스 = +jωL, ½ 계수 불필요(peak로 phasor 진행).

---

### 2. 무엇을 묻고 왜 이 도구인가

L이 직렬, R이 shunt(병렬 출력)인 구조. 정현파 정상상태이므로 **phasor + 임피던스 전압분배**가 자연스러운 접근이다.

- Z_L = jωL → 주파수가 높아질수록 임피던스 증가 → 전압이 L에 집중 → V_o 감소
- 따라서 이 회로는 **저역통과(low-pass) RL 필터**

(14주차 강의노트) -3 dB 차단 정의: "전력이 1/2가 되는 주파수에서 I_o = 0.707·I_i" — 이것이 |H(jω_c)| = 1/√2 조건의 근거.
RL 필터 전달함수 유도는 ⚠ 강의 밖 — 교재 Ch.14 일반 회로이론으로 보강.

---

### 3. 핵심 통찰

H(jω) = 1/(1 + j·(ω/ω_c)) 형태이며, ω_c = R/L에서 |H| = 1/√2 (-3 dB)가 된다. 차단주파수는 소자비 R/L로 결정된다.

---

### 4. 풀이

**(a) 차단주파수**

임피던스 전압분배:

```
H(jω) = V_o/V_i = R / (R + jωL)
       = 1 / (1 + j·ω·(L/R))
```

ω_c = R/L 로 정의하면:

```
H(jω) = 1 / (1 + j·(ω/ω_c))
```

|H(jω_c)| = 1/√(1²+1²) = 1/√2 → -3 dB 조건 (14주차 강의노트)

```
ω_c = R/L = 1200 / (50×10⁻³) = 24,000 rad/s

f_c = ω_c / (2π) = 24,000 / (2π) = 12,000/π ≈ 3819.7 Hz ≈ 3.82 kHz
```

---

**(b) H(jω) 계산**

① ω = ω_c (ω/ω_c = 1):

```
H(jω_c) = 1/(1 + j)
|H|  = 1/√(1²+1²) = 1/√2 ≈ 0.7071
∠H   = -arctan(1) = -45°

→ H(jω_c) = 0.7071∠-45°
```

② ω = 0.125ω_c (ω/ω_c = 1/8):

```
H = 1/(1 + j·(1/8))
|H| = 1/√(1 + 1/64) = 1/√(65/64) = 8/√65 ≈ 0.9923
∠H = -arctan(1/8) ≈ -7.13°

→ H(j·0.125ω_c) ≈ 0.9923∠-7.13°
```

③ ω = 8ω_c (ω/ω_c = 8):

```
H = 1/(1 + j·8)
|H| = 1/√(1 + 64) = 1/√65 ≈ 0.1240
∠H = -arctan(8) ≈ -82.87°

→ H(j·8ω_c) ≈ 0.1240∠-82.87°
```

---

**(c) 정상상태 v_o**

v_i = 20 cos ωt V → phasor V_i = 20∠0° V (peak 기준)

```
V_o = H(jω) · V_i
v_o(t) = |H|·20 · cos(ωt + ∠H) V
```

**ω = ω_c = 24,000 rad/s:**

```
v_o ≈ 20×(1/√2) · cos(24000t - 45°)
    = 10√2 · cos(24000t - 45°)
    ≈ 14.14 cos(24000t - 45°) V
```

**ω = 0.125ω_c = 3,000 rad/s:**

```
v_o ≈ 20×(8/√65) · cos(3000t - 7.13°)
    = (160/√65) · cos(3000t - 7.13°)
    ≈ 19.85 cos(3000t - 7.13°) V
```

**ω = 8ω_c = 192,000 rad/s:**

```
v_o ≈ 20×(1/√65) · cos(192000t - 82.87°)
    = (20/√65) · cos(192000t - 82.87°)
    ≈ 2.48 cos(192000t - 82.87°) V
```

---

### 5. 검산·직관

**극한 케이스:**
- ω → 0: Z_L = jωL → 0 (단락), H → 1 ✓ (DC 그대로 출력, 저역통과)
- ω → ∞: Z_L → ∞ (개방), H → 0 ✓ (고주파 차단)
- ω = ω_c: |H| = 1/√2 = 0.707 ✓ (정의와 일치)

**대칭성:** 0.125ω_c × 8ω_c = ω_c² → 두 주파수는 ω_c를 중심으로 로그 대칭.
|H| 값도 8/√65 과 1/√65 — 분자가 서로 역수 관계 ✓

**위상 부호:** 세 경우 모두 ∠H < 0° → 출력이 입력 대비 위상 지연 ✓ (유도성 리액턴스 특성)

**저역 확인:** 0.125ω_c(=3 kHz)에서 |H| = 0.992 ≈ 1 (거의 감쇠 없음, 차단주파수 훨씬 아래 ✓)

**고역 확인:** 8ω_c(=192 kHz)에서 |H| = 0.124 ≈ 1/8 (큰 감쇠, 차단주파수 8배 위 ✓)

---

### 6. 한 줄 요약

> RL 저역통과 필터의 차단주파수는 ω_c = R/L이며, 이 주파수에서 출력은 입력의 1/√2(-3 dB)로 -45° 위상 지연된다.
