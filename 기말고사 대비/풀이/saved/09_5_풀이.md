# 9.5 풀이

> 출처: 교재 9장, 사용자 첨부 이미지, 1순위 근거 9주차 책 p.268 + ⚠ 강의 밖(일반 회로이론 Nilsson Ch.9), 풀이일 2026-06-09

## 문제 원문

At t = 5 ms, a sinusoidal current is known to be zero and going negative. The current is next zero at t = 25 ms. It is also known that the current is 50 mA at t = 0.

a) What is the frequency of i in hertz?  
b) What is the expression for i?

---

## 1. 문제 정리

| | 내용 |
|---|---|
| **주어진 것** | t = 5 ms: i = 0, 음으로 감소 중 |
| | t = 25 ms: 다음 영점(next zero) |
| | t = 0: i = 50 mA |
| **구할 것** | (a) 주파수 f [Hz] |
| | (b) i(t) 표현식 |

---

## 2. 무엇을 묻고 왜 이 도구인가

정현파의 **영점 통과 조건 + 부호 조건으로 ω, φ, I_m 을 역산**하는 문제다.

표준형: i(t) = I_m · cos(ωt + φ) (peak 진폭, 각도 rad / ° 병기, I_m > 0)

AC 정상상태이므로 phasor·임피던스 접근이 자연스럽고, 여기서는 그 전 단계인 정현파 파라미터 추출이 핵심.

⚠ 강의 밖 — 9주차 강의노트 PDF 가 열리지 않아 일반 회로이론(Nilsson Ch.9 정현파 정의)으로 풀이한다. T = 1/f 관계는 9주차 책 p.268 에서 확인: "the frequency is 500 Hz and the period is 1/500 Hz = 2 ms."

---

## 3. 핵심 통찰

"음으로 감소하며 영점" 바로 다음 영점은 정확히 T/2 뒤에 온다 — 그 간격 20 ms 가 반주기이므로 T = 40 ms, f = 25 Hz. 이후 φ 는 영점 위치의 부호 조건 하나로 결정된다.

---

## 4. 풀이

**규약 선언:** peak 진폭 기준(rms 아님), 각도 ° / rad 병기, I_m > 0, ω = 50π rad/s.

### (a) 주파수

"음으로 감소하는 영점"(t = 5 ms)에서 "다음 영점"(t = 25 ms)까지의 간격은 반주기 T/2 이다.

```
T/2 = 25 ms − 5 ms = 20 ms
T   = 40 ms = 0.04 s
f   = 1/T = 1/0.04 = 25 Hz
```

### (b) 표현식

각주파수:
```
ω = 2πf = 2π × 25 = 50π rad/s ≈ 157.1 rad/s
```

i(t) = I_m · cos(50πt + φ) 로 놓는다.

**① φ 결정 — t = 5 ms 조건**

그 시각의 ωt 값:
```
ω × 0.005 s = 50π × 0.005 = 0.25π rad = 45°
```

i = 0 조건 → cos(45° + φ) = 0, 즉 45° + φ = 90° + 180°n

"음으로 감소(di/dt < 0)" 조건. di/dt = −ω I_m sin(ωt + φ)이고 I_m > 0이므로:
```
sin(45° + φ) > 0
```

cos(θ) = 0 이고 sin(θ) > 0 ⟹ θ = 90°, 따라서:
```
45° + φ = 90°
φ = 45° = π/4 rad
```

**② I_m 결정 — t = 0 조건**

```
i(0) = I_m · cos(45°) = I_m × (√2/2) = 50 mA
I_m  = 50 × (2/√2) = 50√2 ≈ 70.71 mA
```

**최종 표현식:**
```
i(t) = 50√2 · cos(50πt + π/4)  mA
     ≈ 70.71 · cos(157.1t + 45°) mA       (t 단위: s)
```

---

## 5. 검산·직관

세 조건 전부 대입 확인:

```
t = 0 ms:  i = 50√2 · cos(0 + 45°) = 50√2 × (√2/2) = 50 mA            ✓
t = 5 ms:  i = 50√2 · cos(45° + 45°) = 50√2 · cos(90°) = 0             ✓
           di/dt = −50√2 × 50π × sin(90°) < 0  (음으로 감소)             ✓
t = 25 ms: i = 50√2 · cos(50π×0.025 + 45°) = 50√2 · cos(225° + 45°)
                = 50√2 · cos(270°) = 0                                   ✓
```

극한 점검: t = 0 에서 45° 위상 이동으로 cos(45°) = √2/2 배 → I_m × (√2/2) = 50 mA 자연스럽다.

---

## 6. 한 줄 요약

> "음으로 감소하는 영점 → 다음 영점" 간격이 T/2 이므로 f = 25 Hz, 그 영점의 위치·부호 조건으로 φ = 45°, t = 0 값으로 I_m = 50√2 mA 를 순서대로 확정한다.
