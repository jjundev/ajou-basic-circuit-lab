# 14.35 풀이

> 출처: 교재 14장, 사용자 첨부 이미지, 1순위 근거 14주차 강의노트(Series Resonant Circuits) + 일반 회로이론(cutoff 주파수 공식), 풀이일 2026-06-14

## 문제 원문

For the bandreject filter in Fig. P14.35, calculate
(a) ω₀; (b) f₀; (c) Q; (d) β in hertz; (e) ω_c1; (f) f_c1; (g) ω_c2; and (h) f_c2.

회로 구성: v_i → R(1875 Ω, 직렬) → 분기점 → L(156.25 mH) 직렬 C(100 nF) → GND.
v_o = 분기점에서 GND 사이 전압 (= L·C 직렬 arm 양단).

---

## 1. 문제 정리

주어진 것: R = 1875 Ω, L = 156.25 mH = 0.15625 H, C = 100 nF = 10⁻⁷ F

규약: 각주파수 rad/s, 진동수 Hz, -3 dB 기준 cutoff.

| 구할 것 | (a) ω₀ | (b) f₀ | (c) Q | (d) β [Hz] | (e) ω_c1 | (f) f_c1 | (g) ω_c2 | (h) f_c2 |

---

## 2. 무엇을 묻고 왜 이 도구인가

이 회로는 직렬 RLC band-reject (notch) 필터다. R이 신호 경로에 직렬로, L과 C는 직렬로 묶여 GND 방향 shunt 암을 형성하고, v_o는 그 shunt 암 양단에서 취한다.

핵심 도구: 직렬 공진. 14주차 강의노트에 따르면 "X = 0 일 때 공진, ωL = 1/(ωC) → ω² = 1/LC"이며, Q = (1/R)√(L/C), BW = f_s/Q. ω₀에서 직렬 LC가 Z = 0(단락)이 되면 shunt 암 전압 v_o = 0 → 신호 차단 = band-reject 동작.

---

## 3. 핵심 통찰

직렬 LC가 ω₀에서 완전 단락(Z_LC = 0)되어 v_o = 0이 되는 것이 bandreject 동작의 전부다. Q·β·cutoff 주파수는 모두 ω₀ = 1/√(LC), Q = (1/R)√(L/C) 두 식으로 결정된다.

---

## 4. 풀이

### (a) ω₀ — 중심 각주파수

(14주차 강의노트, p.3: ω₀² = 1/LC)

```
LC = 0.15625 × 10⁻⁷ = 1.5625×10⁻⁸ H·F

√(LC) = 1.25×10⁻⁴ s

ω₀ = 1/(1.25×10⁻⁴) = 8000 rad/s
```

**(a) ω₀ = 8000 rad/s**

### (b) f₀ — 중심 주파수

(14주차 강의노트, p.3: f_r = 1/(2π√LC))

```
f₀ = ω₀/(2π) = 8000/(2π) = 4000/π ≈ 1273.24 Hz
```

**(b) f₀ ≈ 1273.24 Hz**

### (c) Q — 양호도

(14주차 강의노트, p.3: Q = (1/R)√(L/C))

```
√(L/C) = √(0.15625/10⁻⁷) = √(1.5625×10⁶) = 1250 Ω

Q = 1250/1875 = 2/3 ≈ 0.6667
```

**(c) Q = 2/3 ≈ 0.6667**
(Q < 1 → Low-Q 광대역 특성)

### (d) β — 대역폭 [Hz]

(14주차 강의노트, p.6: BW = f_s/Q)

```
β [rad/s] = ω₀/Q = R/L = 1875/0.15625 = 12000 rad/s

β [Hz] = f₀/Q = 1273.24 ÷ (2/3) ≈ 1909.86 Hz
```

**(d) β ≈ 1909.86 Hz**

### (e)(g) ω_c1, ω_c2 — cutoff 각주파수

⚠ 강의 밖 — 강의노트에 ω_c1, ω_c2 개별 공식이 없어 일반 회로이론으로 보강.

전달함수(전압분배기 → jωC 곱해 정리):

```
H(jω) = (1 − ω²LC) / (1 − ω²LC + jωRC)
```

|H(jω)|² = 1/2 조건 → 분자² = 분모² × (1/2) 정리하면:

```
|1 − ω²LC| = ωRC
```

부호에 따라 이차방정식 두 개:

```
경우 1 (ω < ω₀):  LC·ω² + RC·ω − 1 = 0
경우 2 (ω > ω₀):  LC·ω² − RC·ω − 1 = 0
```

값 대입 (LC = 1.5625×10⁻⁸, RC = 1.875×10⁻⁴), LC로 나누면:

```
ω² ± 12000ω − 64×10⁶ = 0
```

판별식: √(12000² + 4×64×10⁶) = √(144×10⁶ + 256×10⁶) = √(400×10⁶) = 20000

```
ω_c1 = (−12000 + 20000) / 2 = 4000 rad/s
ω_c2 = (+12000 + 20000) / 2 = 16000 rad/s
```

**(e) ω_c1 = 4000 rad/s**
**(g) ω_c2 = 16000 rad/s**

### (f)(h) f_c1, f_c2 — cutoff 주파수 [Hz]

```
f_c1 = 4000/(2π) = 2000/π ≈ 636.62 Hz
f_c2 = 16000/(2π) = 8000/π ≈ 2546.48 Hz
```

**(f) f_c1 ≈ 636.62 Hz**
**(h) f_c2 ≈ 2546.48 Hz**

---

## 5. 검산·직관

```
① 기하평균: √(ω_c1 × ω_c2) = √(4000 × 16000) = √(64×10⁶) = 8000 = ω₀ ✓
② 대역폭:  ω_c2 − ω_c1 = 16000 − 4000 = 12000 rad/s = β ✓
③ Hz 검산: f_c2 − f_c1 = 2546.48 − 636.62 = 1909.86 Hz = β_Hz ✓
```

극한 점검:
- ω → 0: Z_C → ∞ → Z_shunt → ∞ → V_o → V_i (통과) ✓
- ω → ∞: Z_L → ∞ → Z_shunt → ∞ → V_o → V_i (통과) ✓
- ω = ω₀: Z_shunt = jω₀L − j/(ω₀C) = 0 (단락) → V_o = 0 (완전 차단) ✓

---

## 6. 한 줄 요약

> 직렬 LC shunt arm이 ω₀ = 8000 rad/s에서 단락되어 신호를 완전 차단하는 notch 필터이며, cutoff는 |1 − ω²LC| = ωRC 이차방정식 두 개로 직접 구한다 — f_c1 ≈ 637 Hz, f_c2 ≈ 2546 Hz.
