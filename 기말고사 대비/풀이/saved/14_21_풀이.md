# 14.21 풀이

> 출처: 교재 14장, 기말고사 대비/6월13일/04_new_14-21.png, 1순위 근거 14주차 강의노트(권혁준 교수님), 풀이일 2026-06-15

## 문제 원문

Design a series RLC bandpass filter (see Fig. 14.19[a]) with a quality of 8 and a center frequency of 50 krad/s, using a 0.01 µF capacitor.
a) Draw your circuit, labeling the component values and output voltage.
b) For the filter in part (a), calculate the bandwidth and the values of the two cutoff frequencies.

---

## 1. 문제 정리 (Setup)

직렬 RLC **대역통과(bandpass)** 필터를 설계한다 (Fig. 14.19[a] = R–L–C 직렬, 출력 Vo는 **R 양단**).

| 주어진 것 | 값 |
|---|---|
| 양호도 Q | 8 |
| 중심(공진)각주파수 ω₀ | 50 krad/s = 5×10⁴ rad/s |
| 커패시터 C | 0.01 µF = 1×10⁻⁸ F |

- 구할 것 (a) 회로 + R, L 값과 출력전압 표시 / (b) 대역폭 BW와 두 차단주파수 ω_c1, ω_c2

**규약**: ω₀는 각주파수(rad/s). 직렬 RLC, 출력은 R 양단(대역통과). 전력 계산이 없어 rms/peak·½계수는 무관.

## 2. 무엇을 묻고 왜 이 도구인가 (개념 동기)

분석형(회로→파라미터)이 아니라 **설계형(스펙→소자값)**이다. 직렬 공진에서 ω₀, Q, BW는 R·L·C로 완전히 결정되니까(14주차 강의노트), 그 세 식을 **거꾸로 풀어** 미지수 R·L을 역산하면 끝. C가 주어졌으니 자유도가 딱 맞는다.

## 3. 핵심 통찰 (Aha)

> 직렬 RLC 대역통과는 "출력을 R에서 뽑는 직렬 공진회로"다. ω₀ = 1/√(LC)가 L을 정하고, Q = (1/R)√(L/C)가 R을 정한다 — C 하나만 고르면 나머지가 강제된다.

## 4. 풀이 (Worked solution)

**(a) L과 R 역산**

공진식 (14주차 강의노트, p.3): ω₀² = 1/(LC) → L = 1/(ω₀²·C)

```
L = 1 / ((5×10⁴)² × 1×10⁻⁸) = 1 / (2.5×10⁹ × 1×10⁻⁸) = 1/25 = 0.04 H = 40 mH
```

양호도식 (14주차 강의노트, p.3): Q = (1/R)·√(L/C) → R = (1/Q)·√(L/C)

```
√(L/C) = √(0.04 / 1×10⁻⁸) = √(4×10⁶) = 2000 Ω
R = 2000 / 8 = 250 Ω
```

(교차검증: Q = ω₀L/R = (5×10⁴ × 0.04)/250 = 2000/250 = 8 ✓)

회로 (출력 Vo는 R 양단):

```
 Vi ──[ R=250 Ω ]──[ L=40 mH ]──[ C=0.01 µF ]── (루프)
        └────────── Vo (R 양단) ──────────┘
   직렬: Vi → R → L → C → 다시 Vi,  Vo = R 양단 전압
```

**(b) 대역폭과 두 차단주파수**

대역폭 (14주차 강의노트, p.6: BW = f_s/Q, 각주파수형 BW = ω₀/Q):

```
BW = ω₀/Q = (5×10⁴)/8 = 6250 rad/s = 6.25 krad/s
```

(검증: 직렬 RLC에서 BW = R/L = 250/0.04 = 6250 rad/s ✓)

차단주파수는 전력 ½(0.707) 지점 (강의노트 p.6 정의). 두 근은 다음 조건을 만족 — ⚠ 강의 밖(정확한 근 공식은 교재 Nilsson Ch.14 보강, 강의노트는 BW·Q·공진까지만):
- 차 ω_c2 − ω_c1 = BW = 6250
- 곱(기하평균) ω_c1·ω_c2 = ω₀² = 2.5×10⁹

정확한 근:

```
ω_c = ∓ R/(2L) + √( (R/(2L))² + 1/(LC) )
R/(2L) = BW/2 = 3125 rad/s,   1/(LC) = ω₀² = 2.5×10⁹
√( 3125² + 2.5×10⁹ ) = √(2.50977×10⁹) ≈ 50097.6 rad/s
```

```
ω_c1 = −3125 + 50097.6 ≈ 46.97 krad/s
ω_c2 = +3125 + 50097.6 ≈ 53.22 krad/s
```

(주파수 환산: f = ω/(2π) → f_c1 ≈ 7.48 kHz, f_c2 ≈ 8.47 kHz, f₀ ≈ 7.96 kHz, BW ≈ 995 Hz)

## 5. 검산·직관 (Sanity check)

- 차 검증: ω_c2 − ω_c1 = 53.22 − 46.97 = 6.25 krad/s = BW ✓
- 기하평균 검증: √(46.97 × 53.22) ≈ √(2500) = 50.0 krad/s = ω₀ ✓ (대역통과는 ω₀가 두 차단의 **기하평균**, 산술평균 아님 — Q가 클수록 둘이 ω₀에 거의 대칭)
- Q=8은 비교적 고-Q → 좁은 통과대역(BW/ω₀ = 1/Q = 12.5%). 강의노트 High-Q 그래프의 날카로운 피크와 일치 ✓
- 단위·차원: L=1/(ω₀²C) → 1/((rad/s)²·F) = H ✓, R=√(L/C)/Q → √(H/F)=Ω ✓

## 6. 한 줄 요약

> 직렬 RLC 대역통과 설계는 C를 고른 뒤 ω₀=1/√(LC)로 L을, Q=(1/R)√(L/C)로 R을 역산하고, BW=ω₀/Q와 "차=BW·곱=ω₀²"로 두 차단주파수를 얻는다 → R=250 Ω, L=40 mH, BW=6.25 krad/s, ω_c1≈46.97 / ω_c2≈53.22 krad/s.
