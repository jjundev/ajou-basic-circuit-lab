# 10.44 풀이

> 출처: 교재 10장, 사용자 첨부 이미지, 1순위 근거 교재/일반이론(Ch10.6 max power transfer + 종속소스 Thevenin — 대응 lab 주차 없음, ⚠ 강의 밖), 풀이일 2026-06-14

## 문제 원문

Fig. P10.44 회로에서 부하 임피던스 Z_L 을 조정해 최대 평균전력이 Z_L 에 전달되도록 한다.

- a) Z_L 에 전달되는 최대 평균전력을 구하라.
- b) 회로에서 발생(developed)한 전체 전력 중 몇 %가 Z_L 에 전달되는가?

회로: 100∠0° V (rms) 전압원 — 25 Ω — j10 Ω 직렬, 이 가지의 전류가 I_φ. 그 끝(노드 A)에 종속전압원 5·I_φ (+ 위) 가 접지로 연결. 노드 A 에서 1 Ω 을 거쳐 노드 B, 노드 B 에 j3 Ω(접지) 와 Z_L 이 병렬.

---

## 1. 문제 정리 (Setup)

| 소자 | 값 |
|---|---|
| 독립 전압원 | 100∠0° V (rms) |
| 직렬 임피던스 | 25 Ω + j10 Ω, 전류 = 제어변수 I_φ |
| 종속원 | 5·I_φ (CCVS, + 위), 노드 A↔접지 |
| 직렬 | 1 Ω (A→B) |
| 노드 B | j3 Ω (접지) ∥ Z_L |

**규약**: 전압 rms, 각도 °, 인덕터 +jX, 유효전력 P(rms라 ½ 없음). 제어변수 I_φ 는 단자(Z_L) 왼쪽 내부에 있으므로 Thevenin 적용 가능.

구할 것: (a) P_max, (b) P_L / P_developed × 100%.

## 2. 무엇을 묻고 왜 이 도구인가 (개념 동기)

종속소스가 있어 "독립소스 죽이고 직병렬" 만으로는 Z_Th 를 못 구하는 게 보통이다. 그런데 이 회로는 **I_φ 가 Z_L 과 무관하게 좌측 루프만으로 결정**되는 구조라, 종속원이 노드 A 를 고정 전압으로 묶어버린다 → 우측에서 보면 노드 A 가 사실상 독립 전압원이 되고 Thevenin 이 깔끔히 적용된다.

⚠ 강의 밖 — Ch10.6 최대전력전달은 대응 lab 주차 없음, 교재 일반이론.

## 3. 핵심 통찰 (Aha)

> 종속원이 노드 A 를 V_A = 5·I_φ 로 고정하고, I_φ 는 좌측 루프(100 = I_φ(30+j10))만으로 결정되므로 Z_L 과 독립. 즉 노드 A 는 우측에서 보면 독립 전압원 → V_Th = 15 V, Z_Th = 1∥j3 = 0.9 + j0.3 Ω. 나머지는 켤레정합.

## 4. 풀이 (Worked solution)

**(0) I_φ 결정 — 좌측 루프** (V_A = 5I_φ 를 KVL 에 대입):

```
100 = I_φ·(25 + j10) + 5·I_φ = I_φ·(30 + j10)
I_φ = 100/(30 + j10) = (3000 − j1000)/1000 = 3 − j1 A (rms)
V_A = 5·I_φ = 15 − j5 V
```

**Z_Th (테스트법으로 검증)** — 독립 100V 단락 시 좌측 루프 0 = I_φ(30+j10) → I_φ = 0 → 종속원 = 0 (노드 A 단락). 그러면 B 에서 본 임피던스:

```
Z_Th = 1 ∥ j3 = (1·j3)/(1 + j3) = (9 + j3)/10 = 0.9 + j0.3 Ω
```

(종속원이라도 독립원 죽이니 I_φ→0 → 종속원→단락 → 표준 "소스 죽이기" 가 결국 통함.)

**V_Th (B 의 개방전압)** — 노드 A(=15−j5) 가 1Ω–j3Ω 분압:

```
V_Th = V_A·(j3)/(1 + j3) = (15 − j5)(0.9 + j0.3) = 15 + j0 = 15∠0° V (rms)
```

**(a) 켤레정합 + 최대전력**:

```
Z_L = Z_Th* = 0.9 − j0.3 Ω
P_max = |V_Th|²/(4·R_Th) = 15²/(4·0.9) = 225/3.6 = 62.5 W
```

**(b) 전체 발생전력 대비 %** — 정합 부하로 전체 회로 풀이:

부하 병렬부 Z_L ∥ j3 = (0.9−j0.3)·j3 / (0.9−j0.3+j3) = (0.9+j2.7)/(0.9+j2.7) = 1 Ω (순저항).

```
V_B = V_A · 1/(1 + 1) = (15 − j5)/2 = 7.5 − j2.5 V
I_1 (A→B, 1Ω) = V_A − V_B = 7.5 − j2.5 A
```

전원별 발생전력(complex power S = V·I*, 발생 = + 부호):

```
독립원:  S = 100·(3 − j1)* = 100·(3 + j1) = 300 + j100  → P = 300 W
종속원:  I_dep(아래로) = I_φ − I_1 = (3−j1) − (7.5−j2.5) = −4.5 + j1.5 A
         발생 P_dep = −Re{V_A·I_dep*} = −Re{(15−j5)(−4.5−j1.5)} = −(−75) = 75 W
P_developed = 300 + 75 = 375 W
```

전력 평형 검산(소비측): 25Ω = |I_φ|²·25 = 10·25 = 250 W, 1Ω = |I_1|²·1 = 62.5 W, Z_L = 62.5 W → 250+62.5+62.5 = 375 W ✓.

```
P_L / P_developed = 62.5/375 = 0.1667 = 16.67 %
```

## 5. 검산·직관 (Sanity check)

- **부하 전류 실수화**: I_L = V_B/Z_L = (7.5−j2.5)/(0.9−j0.3) = 2.5/0.3 = 8.333 A (순실수) → 정합 시 리액턴스 상쇄의 증거. P_L = |I_L|²·R_L = (25/3)²·0.9 = 62.5 W ✓ (P_max 와 일치).
- **전력 평형**: 발생 375 W = 소비 375 W ✓ (j10·j3 는 무효라 P 기여 0).
- **종속원이 전력을 공급**(+75 W)함에 주의 — 그래서 효율이 50% 가 아니라 16.67% (분모에 종속원 발생분까지 포함).
- **Z_Th 두 방법 일치**: 테스트법(독립원 죽임)과 V_Th/I_sc 모두 0.9 + j0.3 Ω.

## 6. 한 줄 요약

> 종속원이 노드를 고정하고 제어변수 I_φ 가 부하와 무관할 때, 그 노드는 우측에서 독립 전압원처럼 보여 Thevenin(V_Th=15V, Z_Th=0.9+j0.3Ω)이 깔끔히 성립 — 켤레정합으로 P_max=62.5 W, 단 발생전력엔 종속원 75 W 도 포함되어 전달률은 16.67%.
