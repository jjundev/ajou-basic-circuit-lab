# 9.93 풀이

> 출처: 교재 9장, 기말고사 대비/6월10일/문제_6월10일.pdf (p.4), 1순위 근거 9주차 강의노트 (R-L-C COMPONENTS 슬라이드), 풀이일 2026-06-12

## 문제 원문

V_s = 120∠0° V(rms), ω = 2000 rad/s. 전원에 R = 40 Ω 이 직렬, 그 뒤 L = 20 mH 와 C = 10 μF 의 병렬(L ∥ C)이 연결된다. 병렬부 양단 전압 V_o 를 구한다.

(a) Z_L, Z_C, 병렬부 Z_p = L ∥ C 를 구하라.
(b) 전압 분배 V_o = V_s · Z_p/(R + Z_p) 를 크기·위상으로 구하라.
(c) V_o 와 V_s 의 위상차를 말하라.

---

## 1. 문제 정리

| 항목 | 값 |
|---|---|
| V_s | 120∠0° V (rms) |
| ω | 2000 rad/s |
| R (직렬) | 40 Ω |
| L (병렬부) | 20 mH = 0.02 H |
| C (병렬부) | 10 μF = 10×10⁻⁶ F |
| 구조 | V_s → R 직렬 → [L ∥ C] 병렬, 병렬부 양단이 V_o |

구할 것: (a) Z_L, Z_C, Z_p = L ∥ C  (b) V_o (크기·위상)  (c) V_o와 V_s의 위상차

규약: V_s는 rms. ω = 2000 rad/s. 인덕터 Z_L = +jωL, 커패시터 Z_C = 1/(jωC) = −j/(ωC). 각도 °.

---

## 2. 무엇을 묻고 왜 이 도구인가

R 직렬 뒤 병렬 LC 부하의 양단 전압을 구하는 전압 분배 문제다. 시간영역 대신 phasor·임피던스로 바꾸면 V_o = V_s · Z_p/(R + Z_p) 라는 분압식 하나로 끝난다. 핵심은 병렬 LC의 등가 임피던스 Z_p를 먼저 정리하는 것.

근거: 9주차 강의노트 R-L-C COMPONENTS — Z_L = jωL, Z_C = 1/(jωC), 병렬 합성(어드미턴스 합).

---

## 3. 핵심 통찰

병렬 LC는 어드미턴스가 Y_p = j(ωC − 1/(ωL)) 로 순수 허수 → Z_p도 순수 리액턴스(저항분 0). 이 회로는 공진(ω₀ = 1/√(LC) ≈ 2236 rad/s) 바로 아래라 인덕터 가지가 우세 → Z_p가 순유도성(+j200 Ω)으로 나온다.

---

## 4. 풀이

### (a) 소자·병렬부 임피던스 (9주차 강의노트 R-L-C COMPONENTS)

```
Z_L = jωL = j × 2000 × 0.02 = j40 Ω

Z_C = 1/(jωC) = 1/(j × 2000 × 10×10⁻⁶) = 1/(j0.02) = −j50 Ω

병렬부 (어드미턴스 합):
Y_p = 1/Z_L + 1/Z_C = 1/(j40) + 1/(−j50)
    = −j0.025 + j0.02
    = −j0.005 S

Z_p = 1/Y_p = 1/(−j0.005) = j200 Ω = 200∠90° Ω
```

(곱셈공식 검산: Z_p = Z_L·Z_C/(Z_L+Z_C) = (j40·(−j50))/(j40−j50) = 2000/(−j10) = j200 Ω ✓)

### (b) 전압 분배

```
R + Z_p = 40 + j200 Ω
|R + Z_p| = √(40² + 200²) = √41600 ≈ 203.96 Ω
∠(R + Z_p) = arctan(200/40) = arctan(5) ≈ 78.69°
→ R + Z_p = 203.96∠78.69° Ω

V_o = V_s · Z_p/(R + Z_p)
    = 120∠0° × (200∠90° / 203.96∠78.69°)
    = 120∠0° × 0.9806∠11.31°
    = 117.7∠11.31° V (rms)
```

### (c) 위상차

```
∠V_o − ∠V_s = 11.31° − 0° = +11.31°
→ V_o 가 V_s 보다 11.31° 앞선다 (leads).
```

---

## 5. 검산·직관

- Z_p = j200 Ω 순유도성. 분압비 크기 = |Z_p|/|R+Z_p| = 200/203.96 = 0.98 ≤ 1 ✓ (Z_p가 순리액턴스이고 R이 실수라 √(R²+X²) ≥ |X| → 분압비 ≤ 1)
- 위상: 유도성 부하(+90°)를 저항과 직렬 분압 → 출력이 전원보다 앞섬(+11.31°). 분압비 위상 = 90° − 78.69° = +11.31° ✓
- 공진 점검: ω₀ = 1/√(LC) = 1/√(0.02×10×10⁻⁶) ≈ 2236 rad/s. ω = 2000 < ω₀ → 공진 아래 → 병렬 LC가 유도성, Z_p 유한값. ω가 ω₀에 가까워지면 |Z_p|→∞ 로 발산하는 추세와 일관 ✓

---

## 6. 한 줄 요약

> 병렬 LC는 어드미턴스가 순허수 j(ωC − 1/(ωL))라 등가 임피던스가 순리액턴스가 되고, 공진 아래에서는 유도성이 되어 R과의 분압에서 출력 전압이 전원보다 위상이 앞선다.
