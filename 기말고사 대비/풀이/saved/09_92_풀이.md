# 9.92 풀이

> 출처: 교재 9장, 기말고사 대비/6월10일/문제_6월10일.pdf (p.3), 1순위 근거 9주차 강의노트 (R-L-C COMPONENTS 슬라이드), 풀이일 2026-06-12

## 문제 원문

ω = 1000 rad/s. 직렬 가지 Z1 은 R1 = 30 Ω 과 L = 40 mH 의 직렬, 병렬 가지 Z2 는 R2 = 100 Ω 과 C = 10 μF 의 병렬이다. 두 가지는 서로 직렬이다 (Z_T = Z1 + Z2).

(a) Z_L = jωL, Z_C = 1/(jωC) 를 구하라.
(b) 병렬부 Z2 = R2 ∥ Z_C 를 직교형(a + jb)으로 구하라.
(c) 전체 등가 임피던스 Z_T 와 |Z_T|, ∠Z_T 를 구하라.

---

## 1. 문제 정리

| 항목 | 값 |
|---|---|
| ω | 1000 rad/s |
| Z1 (직렬 가지) | R1 = 30 Ω 와 L = 40 mH 의 직렬 |
| Z2 (병렬 가지) | R2 = 100 Ω 와 C = 10 μF 의 병렬 |
| 결합 | Z_T = Z1 + Z2 (두 가지 직렬) |

구할 것: (a) Z_L, Z_C  (b) Z2 = R2 ∥ Z_C 직교형  (c) Z_T, |Z_T|, ∠Z_T

규약: ω = 1000 rad/s. 인덕터 Z_L = +jωL, 커패시터 Z_C = 1/(jωC) = −j/(ωC). 각도 °.

---

## 2. 무엇을 묻고 왜 이 도구인가

직렬부와 병렬부가 섞인 회로의 등가 임피던스를 구하는 문제다. 병렬 합성에서 커패시터의 −j 임피던스가 들어가면 분모가 복소수가 되므로, 어드미턴스 합(Y = 1/R + 1/Z_C)으로 풀면 분수 나눗셈을 곱셈으로 바꿔 부호 실수가 줄어든다.

근거: 9주차 강의노트 R-L-C COMPONENTS — "X_L = 2πfL, X_C = 1/(2πfC)", 직병렬 합성.

---

## 3. 핵심 통찰

병렬부 Z2 = R2 ∥ Z_C 는 어드미턴스로 더한 뒤 역수 — Y2 = 1/R2 + jωC 로 한 줄에 끝나고, 마지막에 Z1(유도성)과 Z2(용량성)를 더하면 리액턴스가 부분 상쇄되어 거의 순저항에 가까워진다.

---

## 4. 풀이

### (a) 소자 임피던스 (9주차 강의노트 R-L-C COMPONENTS)

```
Z_L = jωL = j × 1000 × 0.04 = j40 Ω

Z_C = 1/(jωC) = 1/(j × 1000 × 10×10⁻⁶) = 1/(j0.01) = −j100 Ω

직렬 가지: Z1 = R1 + Z_L = 30 + j40 Ω = 50∠53.13° Ω
```

### (b) 병렬부 Z2 = R2 ∥ Z_C — 어드미턴스 합

```
Y2 = 1/R2 + 1/Z_C = 1/100 + 1/(−j100)
   = 0.01 + j0.01 S          (∵ 1/(−j100) = +j0.01)

Z2 = 1/Y2 = 1/(0.01 + j0.01)
   = (0.01 − j0.01) / ((0.01)² + (0.01)²)
   = (0.01 − j0.01) / 0.0002
   = 50 − j50 Ω = 70.71∠−45° Ω
```

(곱셈공식 검산: Z2 = R2·Z_C/(R2+Z_C) = (100·(−j100))/(100−j100) = (−j10⁴)/(100−j100) = 50 − j50 Ω ✓)

### (c) 전체 등가 임피던스

```
Z_T = Z1 + Z2 = (30 + j40) + (50 − j50)
    = 80 − j10 Ω

|Z_T| = √(80² + 10²) = √6500 ≈ 80.62 Ω

∠Z_T = arctan(−10/80) = arctan(−0.125) ≈ −7.13°

∴  Z_T = 80.62∠−7.13° Ω
```

---

## 5. 검산·직관

- Z1은 유도성(+j40), Z2는 용량성(−j50) → 합산 시 리액턴스가 −10 으로 거의 상쇄 → 전체 약한 용량성(∠ −7.13°). 타당 ✓
- 극한: C 제거 시 Z2 = R2 = 100 Ω 순저항, Z_T = 130 + j40 (유도성). C를 넣으면 병렬부가 용량성(50−j50)으로 바뀌어 저항분도 100→50 으로 줄고 전체 위상이 음수로 넘어감 — 방향 일치 ✓
- |Z2| = 70.71 Ω < R2 = 100 Ω ✓ (병렬은 항상 가지 중 최소보다 작거나 같다)

---

## 6. 한 줄 요약

> 병렬 임피던스는 어드미턴스(Y = 1/R + jωC)로 더해 역수 한 번이 가장 깔끔하고, 유도성 가지와 용량성 가지를 직렬로 합치면 리액턴스가 부분 상쇄돼 등가 임피던스가 순저항 쪽으로 수렴한다.
