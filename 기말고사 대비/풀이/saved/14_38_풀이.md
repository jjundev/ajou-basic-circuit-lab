# 14.38 풀이

> 출처: 교재 14장, 사용자 첨부 이미지, 1순위 근거 14주차 강의노트(Series Resonant Circuits) + 일반 회로이론(병렬 Q/β/cutoff 공식), 풀이일 2026-06-14

## 문제 원문

For the bandreject filter in Fig. P14.38, calculate
(a) ω₀; (b) f₀; (c) Q; (d) ω_c1; (e) f_c1; (f) ω_c2; (g) f_c2; and (h) β in kilohertz.

회로 구성: v_i → [box: L∥C 병렬, 직렬 경로] → 노드 A → v_o; 노드 A → R(750 Ω) → GND.

소자: L = 50 μH (이미지 코일 기호 → 인덕터; 표기 "50 μF"는 μH 오기로 해석),
      C = 20 nF = 20×10⁻⁹ F, R = 750 Ω.

---

## 1. 문제 정리

주어진 것: L = 50 μH = 50×10⁻⁶ H, C = 20 nF = 20×10⁻⁹ F, R = 750 Ω

규약: 각주파수 rad/s, 진동수 Hz/kHz, -3 dB 기준 cutoff.

| 구할 것 | (a) ω₀ | (b) f₀ | (c) Q | (d) ω_c1 | (e) f_c1 | (f) ω_c2 | (g) f_c2 | (h) β [kHz] |

---

## 2. 무엇을 묻고 왜 이 도구인가

이 회로는 병렬 LC(직렬 경로) + shunt R 구성의 band-reject 필터다.

14주차 강의노트(p.3)에 따르면 공진 조건 ω₀ = 1/√(LC)는 직렬·병렬 공통이므로 그대로 적용.
그러나 Q와 β 공식은 직렬 RLC와 다르다.

⚠ 강의 밖 — 전달함수 유도 및 병렬 공진 Q/β 공식은 강의노트에 없어 일반 회로이론으로 보강.

```
Z_par = sL / (s²LC + 1)   [병렬 LC 임피던스]

H(s) = R / (Z_par + R) = (s² + 1/LC) / (s² + (1/RC)s + 1/LC)
     = (s² + ω₀²) / (s² + (ω₀/Q)s + ω₀²)
```

ω₀/Q = 1/(RC) → Q = ω₀RC, β = 1/(RC).
(직렬 RLC의 Q = ω₀L/R, β = R/L 와 쌍대 관계 — R의 역할이 반대.)

---

## 3. 핵심 통찰

병렬 LC가 ω₀에서 Z_par → ∞ (개방)이 되어 v_o = 0이 되는 것이 bandreject 동작이며,
Q = ω₀RC (shunt R이 클수록 Q↑, 협대역)는 직렬 RLC Q의 역수 관계다.

---

## 4. 풀이

### (a) ω₀ — 중심 각주파수

(14주차 강의노트, p.3: ω₀² = 1/LC)

```
LC = 50×10⁻⁶ × 20×10⁻⁹ = 10⁻¹² s²

ω₀ = 1/√(10⁻¹²) = 10⁶ rad/s
```

**(a) ω₀ = 10⁶ rad/s**

### (b) f₀ — 중심 주파수

```
f₀ = ω₀/(2π) = 10⁶/(2π) ≈ 159,155 Hz ≈ 159.155 kHz
```

**(b) f₀ ≈ 159.155 kHz**

### (c) Q — 양호도

(⚠ 강의 밖 — 병렬 구성 Q 공식: Q = ω₀RC)

```
Q = ω₀RC = 10⁶ × 750 × 20×10⁻⁹
          = 10⁶ × 1.5×10⁻⁵
          = 15
```

**(c) Q = 15**

### (h) β — 대역폭 [kHz]

(⚠ 강의 밖 — β = 1/(RC))

```
β [rad/s] = 1/(RC) = 1/(750 × 20×10⁻⁹) = 1/(1.5×10⁻⁵) = 66,667 rad/s

β [kHz] = 66,667/(2π×10³) ≈ 10.610 kHz
```

**(h) β ≈ 10.610 kHz**

### (d)(f) ω_c1, ω_c2 — cutoff 각주파수

(⚠ 강의 밖 — |H(jω)| = 1/√2 조건 풀이)

```
β_r = 66,667 rad/s,   β_r/2 = 33,333 rad/s

(β_r/2)² + ω₀² = (10⁶/30)² + (10⁶)²
               = 10¹² × (1/900 + 1)
               = 10¹² × 901/900

√[(β_r/2)² + ω₀²] = 10⁶ × √901/30 ≈ 1,000,556 rad/s

ω_c1 = −33,333 + 1,000,556 = 967,223 rad/s
ω_c2 = +33,333 + 1,000,556 = 1,033,889 rad/s
```

**(d) ω_c1 ≈ 967,223 rad/s**
**(f) ω_c2 ≈ 1,033,889 rad/s**

### (e)(g) f_c1, f_c2 — cutoff 주파수

```
f_c1 = 967,223/(2π) ≈ 153,942 Hz ≈ 153.94 kHz
f_c2 = 1,033,889/(2π) ≈ 164,552 Hz ≈ 164.55 kHz
```

**(e) f_c1 ≈ 153.94 kHz**
**(g) f_c2 ≈ 164.55 kHz**

---

## 5. 검산·직관

```
① 기하평균: ω_c1 × ω_c2 = (10⁶/30)² × (√901−1)(√901+1)
                          = (10⁶/30)² × 900 = 10¹² = ω₀² ✓

② 대역폭:  ω_c2 − ω_c1 = 2×33,333 = 66,667 rad/s = β_r ✓

③ Hz:     f_c2 − f_c1 ≈ 164,552 − 153,942 = 10,610 Hz = β_Hz ✓
```

극한 점검:
- ω→0: Z_L→0, Z_par→0 → H→R/R = 1 (통과) ✓
- ω→∞: Z_C→0, Z_par→0 → H→R/R = 1 (통과) ✓
- ω=ω₀: Z_par→∞ → H→0 (완전 차단) ✓

Q = 15 → High-Q 협대역 (14.35의 Q=2/3 광대역과 대비).

---

## 6. 한 줄 요약

> 병렬 LC가 ω₀ = 10⁶ rad/s에서 개방되어 신호를 차단하며, Q = ω₀RC = 15의 협대역 특성으로 β = 1/(RC) ≈ 10.61 kHz 대역을 거부한다 — 직렬 RLC와 Q/β 공식이 R에 대해 쌍대 관계임에 주목.
