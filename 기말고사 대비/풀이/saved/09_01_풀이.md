# 9.1 풀이

> 출처: 교재 9장, 사용자 첨부 이미지, 1순위 근거 9주차 강의노트·정리노트, 풀이일 2026-06-08

## 문제 원문

A sinusoidal current is given by the expression

i = 100 cos(600t + 45°) mA.

Find (a) f in hertz; (b) T in milliseconds; (c) I_m; (d) i(0); (e) φ in degrees and radians; (f) the smallest positive value of t at which i = 0; and (g) the smallest positive value of t at which di/dt = 0.

---

## 1. 문제 정리 (Setup)

주어진 신호: i = 100 cos(600t + 45°) mA

표준형 i = I_m cos(ωt + φ) 와 대조:

| 파라미터 | 읽은 값 |
|---|---|
| 각주파수 ω | 600 rad/s |
| 진폭(peak) I_m | 100 mA |
| 위상각 φ | 45° |

**규약**: peak(진폭) 표기. t 단위 초[s]. 각도는 °와 rad 병기. cos 인수 안 600t는 rad 단위 → φ = 45° = π/4 rad 로 통일 계산.

구할 것: (a) f [Hz], (b) T [ms], (c) I_m, (d) i(0), (e) φ, (f) i=0 이 되는 최소 양의 t, (g) di/dt=0 이 되는 최소 양의 t

---

## 2. 무엇을 묻고 왜 이 도구인가 (개념 동기)

정현파 수식 i = I_m cos(ωt + φ) 에서 각 특성값을 직독하고, ω–f–T 관계와 영점 조건을 적용하는 문제. (9주차 정리노트, p.3 "정현파 신호 특성값" 표: ω = 2πf, T = 1/f; 9주차 강의노트 "AC VALUES": v(t) = A cos(2πf_c t + θ))

---

## 3. 핵심 통찰 (Aha)

i = I_m cos(ωt + φ)에서 **ω 하나만 알면** f, T, 영점 시각이 모두 결정된다 — ω = 2πf → T = 2π/ω, 그리고 cos = 0 ↔ 인수 = π/2 + nπ.

---

## 4. 풀이 (Worked solution)

### (a) f in hertz

(9주차 정리노트, p.3: ω = 2πf)

$$f = \frac{\omega}{2\pi} = \frac{600}{2\pi} = \frac{300}{\pi} \approx 95.49\ \text{Hz}$$

### (b) T in milliseconds

(9주차 정리노트, p.3: T = 1/f)

$$T = \frac{1}{f} = \frac{2\pi}{\omega} = \frac{2\pi}{600}\ \text{s} = \frac{\pi}{300}\ \text{s} \approx 10.47\ \text{ms}$$

### (c) I_m (peak 진폭)

I_m = **100 mA**

(9주차 강의노트 "AC VALUES": A = 최대값)

### (d) i(0)

$$i(0) = 100\cos(45°) = 100 \times \frac{\sqrt{2}}{2} = 50\sqrt{2} \approx 70.71\ \text{mA}$$

### (e) φ in degrees and radians

φ = 45° = π/4 rad

### (f) i = 0 이 되는 최소 양의 t

cos(600t + π/4) = 0 조건:

$$600t + \frac{\pi}{4} = \frac{\pi}{2} + n\pi \quad (n = 0, 1, 2, \ldots)$$

$$600t = \frac{\pi}{4} + n\pi$$

n = 0 에서 최소 양의 해:

$$t = \frac{\pi/4}{600} = \frac{\pi}{2400}\ \text{s} \approx 1.309\ \text{ms}$$

### (g) di/dt = 0 이 되는 최소 양의 t

$$\frac{di}{dt} = -100 \times 600 \sin(600t + \tfrac{\pi}{4})\ \text{mA/s} = 0$$

sin(600t + π/4) = 0 조건:

$$600t + \frac{\pi}{4} = n\pi \quad (n = 0, 1, 2, \ldots)$$

$$600t = n\pi - \frac{\pi}{4}$$

- n = 0: t = -π/2400 < 0 (제외)
- n = 1: t = (3π/4)/600

$$t = \frac{3\pi}{2400} = \frac{\pi}{800}\ \text{s} \approx 3.927\ \text{ms}$$

---

## 5. 검산·직관 (Sanity check)

- **(d) 검산**: cos45° = √2/2 = 0.7071 → 100 × 0.7071 = 70.71 mA ✓
- **(f) 검산**: cos(600 × π/2400 + π/4) = cos(π/4 + π/4) = cos(π/2) = 0 ✓
- **(g) 검산**: sin(600 × π/800 + π/4) = sin(3π/4 + π/4) = sin(π) = 0 ✓
- **f와 T 역수 관계**: f × T = (300/π) × (π/300) = 1.000 ✓
- **직관**: 위상 +45°(= π/4)만큼 앞서 있으므로 ωt = 0 시점 값이 cos(45°) ≈ 0.707 I_m이고, 영점은 T/4(≈ 2.62 ms)보다 이른 t ≈ 1.31 ms ✓

---

## 6. 한 줄 요약

> i = I_m cos(ωt + φ) 에서 ω만 읽으면 f = ω/(2π), T = 2π/ω 가 즉시 나오고, 영점(i=0)은 cos 인수 = π/2 + nπ, 극값(di/dt=0)은 sin 인수 = nπ 조건으로 최소 양의 t를 고른다.
