# 9.43 풀이

> 출처: 교재 9장, 사용자 첨부 이미지, 1순위 근거 ⚠ 강의 밖(일반 회로이론 Nilsson Ch.9 Thévenin), 풀이일 2026-06-09

## 문제 원문

The sinusoidal voltage source in the circuit in Fig. P9.43 is developing a voltage equal to 50 sin 400t V.

- Circuit: v_g (left) → 320 Ω (series) → node A (= terminal a), with 31.25 μF (node A to ground) and 400 mH (terminal a to terminal b = ground)

a) Find the Thévenin voltage with respect to the terminals a,b.  
b) Find the Thévenin impedance with respect to the terminals a,b.  
c) Draw the Thévenin equivalent.

---

## 1. 문제 정리

| 항목 | 값 |
|---|---|
| 전압원 | v_g = 50 sin 400t V (ω = 400 rad/s) |
| 직렬 저항 | R = 320 Ω |
| 병렬 커패시터 | C = 31.25 μF |
| 인덕터 (a–b 사이) | L = 400 mH |
| (a) 구할 것 | V_Th (터미널 a,b 기준) |
| (b) 구할 것 | Z_Th (터미널 a,b 기준) |
| (c) 구할 것 | 테브난 등가회로 |

---

## 2. 무엇을 묻고 왜 이 도구인가

AC 정상상태 → phasor·임피던스 변환 후 주파수영역 테브난 분석.

테브난 정리: 선형 회로 전체를 V_Th + Z_Th 직렬 등가로 대체.
- V_Th = 터미널 a,b 개방 시 전압
- Z_Th = 독립 전원 단락 후 a,b에서 본 임피던스

⚠ 강의 밖 — 9주차 강의노트 PDF 미읽힘, 일반 회로이론(Nilsson Ch.9 Thévenin)으로 풀이.

---

## 3. 핵심 통찰

C와 L이 같은 노드 A(= 터미널 a)에 병렬로 달려 있어 Z_C ∥ Z_L 한 덩어리가 된다. V_Th는 R과 그 병렬 덩어리의 전압분배기 한 줄로, Z_Th는 전원 단락 후 세 소자 어드미턴스 합의 역수로 바로 나온다.

---

## 4. 풀이

**규약 선언:** 코사인 기준 페이저, peak 진폭 기준, ω = 400 rad/s.

v_g = 50 sin 400t = 50 cos(400t − 90°) → V_g = 50∠−90° V

**임피던스 변환:**

```
Z_R = 320 Ω
Z_C = 1/(jωC) = 1/(j × 400 × 31.25×10⁻⁶) = −j80 Ω
Z_L = jωL    = j × 400 × 0.4               = j160 Ω
```

**Z_C ∥ Z_L 병렬 합성:**

```
Y_eq = j/80 − j/160 = j(2−1)/160 = j/160  S
Z_eq = 160/j = −j160  Ω   (용량성, ω > ω₀ ≈ 283 rad/s)
```

### (a) V_Th — 전압분배기

```
V_Th = V_g × Z_eq/(Z_R + Z_eq)
     = 50∠−90° × (−j160)/(320 − j160)
```

320 − j160 = 160(2 − j) = 160√5∠−26.57°

```
V_Th = 50∠−90° × (160∠−90°)/(160√5∠−26.57°)
     = 50∠−90° × (1/√5)∠−63.43°
     = (50/√5)∠(−153.43°)
     = 10√5∠−153.43°  V  ≈  22.36∠−153.43°  V  (peak)
```

시간영역:

```
v_Th(t) = 10√5 cos(400t − 153.43°) V  ≈  22.36 cos(400t − 153.43°) V
```

### (b) Z_Th — 전원 단락 후 a,b에서 본 임피던스

V_g = 0 (단락) → R, Z_C, Z_L 세 소자 모두 node A → 접지 병렬.

```
Y_Th = 1/320 + j/80 − j/160
     = 1/320 + j(2−1)/160
     = (1 + 2j)/320

Z_Th = 320/(1 + 2j)
     = 320(1 − 2j)/5
     = 64 − j128  Ω
```

극형식: 64√5∠−63.43° Ω ≈ 143.1∠−63.43° Ω

소자 분해 (ω = 400 rad/s):
```
R_Th = 64 Ω
C_Th = 1/(400 × 128) = 1/51200 ≈ 19.53 μF
```

### (c) 테브난 등가회로

```
     v_Th              64 Ω    19.53 μF
  ┌──[소스]────────[R]────[C]──── a ●
  │
  └──────────────────────────── b ●

v_Th = 10√5 cos(400t − 153.43°) V
Z_Th = 64 Ω + 19.53 μF (직렬)
```

---

## 5. 검산·직관

**V_Th 크기:**

```
분배비 = |Z_eq|/|Z_R + Z_eq| = 160/(160√5) = 1/√5 ≈ 0.4472
|V_Th| = 50 × 0.4472 ≈ 22.36 V  ✓
```

**Z_Th 대안:**

```
Z_Th = 320 ∥ (−j160)
     = (320/√5)∠−63.43° = 64√5∠−63.43°  ✓
```

**KCL 교차검증 (V_Th):**

```
node A: V_A × (1 + 2j)/320 = V_g/320
V_A = 50∠−90°/(1 + 2j) = 10√5∠−153.43°  ✓
```

---

## 6. 한 줄 요약

> C∥L → Z_eq = −j160 Ω 한 덩어리로 묶으면 V_Th는 전압분배기 한 줄(= 10√5∠−153.43° V), Z_Th는 어드미턴스 합의 역수 한 줄(= 64 − j128 Ω)로 떨어진다.
