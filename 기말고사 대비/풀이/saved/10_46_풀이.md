# 10.46 풀이

> 출처: 교재 10장, 사용자 첨부 이미지, 1순위 근거 교재/일반이론(Ch10.6 max power transfer, 순저항 부하 제약 — 대응 lab 주차 없음, ⚠ 강의 밖), 풀이일 2026-06-14

## 문제 원문

Fig. P10.46 회로의 가변 저항 R 을 흡수 평균전력이 최대가 되도록 조정한다.

- a) R 을 구하라.
- b) 최대 평균전력을 구하라.
- c) Appendix H 에서 평균전력이 가장 많이 전달될 저항을 찾아라.

회로: 300∠0° V (rms) 전압원(+ 위) — 500 Ω — j300 Ω 직렬로 노드 A. 노드 A 에 j200 Ω(접지). 노드 A 에서 200 Ω — (−j480 Ω) 직렬로 노드 B. 노드 B 에 가변저항 R(접지).

---

## 1. 문제 정리 (Setup)

| 소자 | 값 |
|---|---|
| 전압원 | 300∠0° V (rms) |
| 좌측 직렬 | 500 Ω + j300 Ω |
| 중앙 가지 | j200 Ω (노드 A → 접지) |
| 우측 직렬 | 200 Ω − j480 Ω (A → B) |
| 부하 | **R (순수 저항, 가변)** — 노드 B |

**규약**: 전압 rms, 각도 °, 인덕터 +jX·커패시터 −jX, 유효전력 P(rms라 ½ 없음). **부하가 복소 임피던스가 아니라 순저항**이라는 점이 핵심.

구할 것: (a) R, (b) P_max, (c) Appendix H 표준저항.

## 2. 무엇을 묻고 왜 이 도구인가 (개념 동기)

R 이 보는 나머지 회로를 Thevenin 등가(V_Th, Z_Th)로 압축하는 건 10.42·10.44 와 같다. 그런데 **부하가 켤레로 맞출 수 있는 복소 임피던스가 아니라 순수 저항 R 하나**다. 리액턴스를 상쇄할 자유가 없으므로 최대전력 조건이 켤레정합(R = R_Th)이 아니라 **R = |Z_Th|** 로 바뀐다 — 이게 이 문제의 시험 포인트.

⚠ 강의 밖 — Ch10.6, 대응 lab 주차 없음, 교재 일반이론.

## 3. 핵심 통찰 (Aha)

> 부하가 순저항이면 P(R) = |V_Th|²·R / ((R_Th+R)² + X_Th²) 를 R 로 미분해 0 → R² = R_Th² + X_Th² = |Z_Th|². 즉 **R = |Z_Th|** (켤레정합 R_Th 가 아님).

## 4. 풀이 (Worked solution)

**V_Th (B 의 개방전압)** — R 을 떼면 200−j480 가지에 전류가 없어 V_B = V_A. V_A 는 좌측 분압:

```
V_Th = V_A = 300 · (j200)/((500+j300) + j200) = 300 · (j200)/(500+j500)
     = 300 · (0.2 + j0.2) = 60 + j60 V (rms) = 84.85∠45° V
```

**Z_Th** — 전압원 단락 후 B 에서 본 임피던스. 노드 A 에서 (500+j300) 와 j200 가 병렬, 그 뒤 200−j480 직렬:

```
Z_A = (500+j300) ∥ (j200) = (−60000 + j100000)/(500+j500) = 40 + j160 Ω
Z_Th = (200 − j480) + Z_A = (200 − j480) + (40 + j160) = 240 − j320 Ω
|Z_Th| = √(240² + 320²) = √160000 = 400 Ω
```

**(a) 순저항 부하의 최대전력 조건** — P(R) 를 R 로 미분해 0 으로 두면

```
R² = R_Th² + X_Th² = |Z_Th|²  ⇒  R = |Z_Th| = 400 Ω
```

(주의: 켤레정합값 R_Th = 240 Ω 이 아니라 |Z_Th| = 400 Ω.)

**(b) 최대 평균전력** — R = 400 Ω 대입:

```
|I|² = |V_Th|² / |Z_Th + R|² = (60√2)² / |640 − j320|²
     = 7200 / (640² + 320²) = 7200 / 512000 = 0.0140625 A²
P_max = |I|²·R = 0.0140625 × 400 = 5.625 W
```

순저항 부하 닫힌형 검산: P_max = |V_Th|²/(2(R_Th + |Z_Th|)) = 7200/(2·640) = 5.625 W ✓.

**(c) Appendix H 표준저항** — P(R) = 7200·R/((240+R)² + 102400) 을 400 Ω 근처 표준값에서 평가:

```
R = 390 Ω: P = 7200·390/(630² + 102400) = 2808000/499300 = 5.624 W
R = 470 Ω: P = 7200·470/(710² + 102400) = 3384000/606500 = 5.580 W
```

→ 400 Ω 에 가장 가까운 390 Ω 이 최대(5.624 W). **(c) 답: 390 Ω.**

## 5. 검산·직관 (Sanity check)

- **조건 구분**: 복소 부하면 Z_L = Z_Th* = 240 + j320 Ω 로 P 가 더 컸겠지만(켤레정합 P = |V_Th|²/(4R_Th) = 7200/960 = 7.5 W), 순저항 제약 때문에 R = 400 Ω 에서 5.625 W 로 떨어진다. 5.625 < 7.5 ✓ — 자유도가 줄면 최대전력도 준다(물리적으로 타당).
- **R = |Z_Th| 의 의미**: 리액턴스를 못 없애므로, 부하저항을 전체 임피던스 크기에 맞춰 |Z_Th+R| 대비 R 비중을 최적화한 결과.
- **단위·rms**: V_Th rms 사용 → P 식에 ½ 없음, 차원 W ✓.

## 6. 한 줄 요약

> 부하가 순수 저항으로 제약되면 켤레정합(R=R_Th)이 불가능 — 최대전력은 R = |Z_Th| 에서, P_max = |V_Th|²/(2(R_Th+|Z_Th|)). 여기선 R=400 Ω, P=5.625 W, 표준값은 390 Ω.
