# 14.11 풀이

> 출처: 교재 14장, 기말고사 대비/6월12일/07_new_14-11.png, 1순위 근거 14주차 강의노트(-3dB 정의) + ⚠ 강의 밖(RC 고역통과 필터 전달함수 — 교재/일반 회로이론 보강), 풀이일 2026-06-14

## 문제 원문

**14.11**
a) Find the cutoff frequency (in hertz) for the high-pass filter shown in Fig. P14.11.
b) Find H(jω) at ω_c, 0.125ω_c, and 8ω_c.
c) If v_i = 75 cos ωt V, write the steady-state expression for v_o when ω = ω_c, ω = 0.125ω_c, and ω = 8ω_c.

**Fig. P14.11 회로:** 직렬 80 μF 커패시터 → 병렬 20 Ω 저항. v_o는 20 Ω 양단 전압.

---

### 1. 문제 정리

| 항목 | 값 |
|---|---|
| 회로 | 직렬 C = 80 μF → 병렬 R = 20 Ω, v_o는 R 양단 |
| 입력 v_i | peak 진폭 표기 |
| (a) 구할 것 | 차단주파수 f_c [Hz] |
| (b) 구할 것 | H(jω) at ω_c, 0.125ω_c, 8ω_c |
| (c) 구할 것 | v_i = 75 cos ωt V → 정상상태 v_o |

**규약:** 진폭 = peak 기준, 각도 = °, 커패시터 임피던스 = −j/(ωC), ½계수 불필요.

---

### 2. 무엇을 묻고 왜 이 도구인가

직렬 C, 병렬 R에서 v_o를 R 양단으로 취하는 구조 → phasor + 임피던스 전압분배가 자연스럽다.

- Z_C = 1/(jωC) → 주파수 낮을수록 임피던스 증가 → 전압이 C에 집중 → V_o 감소
- 주파수 높을수록 Z_C → 0 → V_o ≈ V_i

따라서 고역통과(high-pass) RC 필터.

(14주차 강의노트) -3 dB 정의: "전력이 1/2가 되는 주파수에서 I_o = 0.707·I_i" → |H(jω_c)| = 1/√2 조건의 근거.
H(jω) 유도는 ⚠ 강의 밖 — 교재 Ch.14 일반 회로이론 보강.

---

### 3. 핵심 통찰

H(jω) = j(ω/ω_c) / (1 + j(ω/ω_c)) 형태이며, 분자에 jω가 있어 저주파(ω→0)에서 H→0, 고주파(ω→∞)에서 H→1. 차단주파수 ω_c = 1/(RC).

---

### 4. 풀이

**(a) 전달함수 & 차단주파수**

임피던스 전압분배:

```
H(jω) = R / (R + 1/(jωC)) = jωRC / (1 + jωRC)
```

ω_c = 1/(RC) 로 놓으면:

```
H(jω) = j·(ω/ω_c) / (1 + j·(ω/ω_c))
```

|H(jω_c)| = 1/√(1²+1²) = 1/√2 → -3 dB 조건 (14주차 강의노트)

```
ω_c = 1/(RC) = 1/(20 × 80×10⁻⁶) = 1/0.0016 = 625 rad/s

f_c = ω_c/(2π) = 625/(2π) ≈ 99.5 Hz
```

**(b) H(jω) 계산**

u = ω/ω_c 로 두면: |H| = u/√(1+u²), ∠H = 90° − arctan(u)

① ω = ω_c (u=1):

```
|H| = 1/√(1²+1²) = 1/√2 ≈ 0.7071
∠H = 90° − arctan(1) = 90° − 45° = +45°

→ H(jω_c) = 0.7071∠+45°
```

② ω = 0.125ω_c (u=1/8):

```
|H| = (1/8)/√(1 + (1/8)²) = (1/8)/(√65/8) = 1/√65 ≈ 0.1240
∠H = 90° − arctan(1/8) ≈ 90° − 7.13° = +82.87°

→ H(j·0.125ω_c) ≈ 0.1240∠+82.87°
```

③ ω = 8ω_c (u=8):

```
|H| = 8/√(1+64) = 8/√65 ≈ 0.9923
∠H = 90° − arctan(8) ≈ 90° − 82.87° = +7.13°

→ H(j·8ω_c) ≈ 0.9923∠+7.13°
```

**(c) 정상상태 v_o**

V_i = 75∠0° V (peak), v_o(t) = 75|H| · cos(ωt + ∠H) V

ω = ω_c = 625 rad/s:

```
v_o = (75/√2) · cos(625t + 45°) ≈ 53.03 cos(625t + 45°) V
```

ω = 0.125ω_c = 78.125 rad/s:

```
v_o = (75/√65) · cos(78.125t + 82.87°) ≈ 9.30 cos(78.125t + 82.87°) V
```

ω = 8ω_c = 5000 rad/s:

```
v_o = (600/√65) · cos(5000t + 7.13°) ≈ 74.44 cos(5000t + 7.13°) V
```

---

### 5. 검산·직관

극한 케이스:
- ω→0: Z_C→∞(개방), H→0 ✓ (저주파 완전 차단)
- ω→∞: Z_C→0(단락), H→1 ✓ (고주파 완전 통과)
- ω=ω_c: |H|=1/√2 ✓

14.1 저역통과와 대칭성 (ω_c 중심 로그 대칭):
|H(j·0.125ω_c)| = 1/√65 ↔ |H(j·8ω_c)| = 8/√65 — 고역통과라 값이 뒤집힘 ✓

위상 부호: 모두 양수(+) → 출력이 입력보다 위상 앞섬 ✓ (커패시터 용량성 특성 — 14.1 인덕터의 −45°와 정반대)

---

### 6. 한 줄 요약

> RC 고역통과 필터의 차단주파수는 ω_c = 1/(RC)이며, 차단주파수에서 출력은 입력의 1/√2로 +45° 위상 앞섬이 생긴다 — 저역통과 RL의 −45° 지연과 정반대.
