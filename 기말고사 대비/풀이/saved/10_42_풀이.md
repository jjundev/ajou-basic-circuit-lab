# 10.42 풀이

> 출처: 교재 10장, 사용자 첨부 이미지, 1순위 근거 교재/일반이론(Ch10.6 max power transfer — 대응 lab 주차 없음, ⚠ 강의 밖), 풀이일 2026-06-14

## 문제 원문

회로(Fig. P10.42)의 위상 전압 V_ab 는 단자 a, b 에 외부 부하가 없을 때 300∠0° V (rms) 이다. 단자 a, b 에 임피던스 200 − j500 Ω 인 부하를 연결하면 V_ab 는 156 − j42 V (rms) 가 된다.

- a) 최대 평균전력 전달을 위해 a, b 에 연결해야 할 임피던스를 구하라.
- b) (a) 의 부하로 전달되는 최대 평균전력을 구하라.
- c) 소스 주파수가 500 Hz 일 때 Appendix H 의 부품으로 (a) 의 임피던스를 구성하라.

---

## 1. 문제 정리 (Setup)

| 항목 | 값 | 의미 |
|---|---|---|
| 무부하 시 V_ab | 300∠0° V (rms) | 개방회로 전압 = V_Th |
| 부하 Z_L1 | 200 − j500 Ω | 테스트용 부하 |
| 부하 연결 시 V_ab | 156 − j42 V (rms) | Z_L1 양단 전압 |
| 주파수 (part c) | 500 Hz | ω = 2π·500 rad/s |

**규약**: 전압은 모두 rms, 각도는 도(°), 임피던스 부호는 인덕터 +jX·커패시터 −jX. 전력은 유효(평균)전력 P, rms 값이므로 ½ 계수 없음.

구할 것: (a) 정합 Z_L, (b) P_max, (c) R·L(또는 R·C) 부품값.

## 2. 무엇을 묻고 왜 이 도구인가 (개념 동기)

회로 내부는 안 보이고 단자 a, b 의 거동만 주어졌다. 이럴 때 **Thevenin 등가**(V_Th 직렬 Z_Th)로 내부를 한 점으로 압축하면, 최대전력전달은 곧장 켤레정합 한 줄로 끝난다. 핵심은 **Z_Th 를 역산**하는 것. 무부하 전압이 곧 V_Th 이고, 테스트 부하 하나를 걸었을 때의 분압 관계로 Z_Th 를 풀 수 있다.

⚠ 강의 밖 — Ch10.6 최대평균전력전달은 대응 lab 주차가 없어 교재 일반 이론으로 푼다.

## 3. 핵심 통찰 (Aha)

> V_Th = 300∠0° (무부하 전압). 테스트 부하의 분압식 V_ab = V_Th·Z_L/(Z_Th+Z_L) 을 Z_Th 에 대해 풀면 내부 임피던스가 드러나고, 최대전력은 Z_L = Z_Th* (켤레정합).

## 4. 풀이 (Worked solution)

**(0) V_Th 확정**: 무부하 V_ab 가 개방전압이므로

```
V_Th = 300∠0° V (rms)
```

**Z_Th 역산** — 부하 전류부터:

```
I = V_ab / Z_L1 = (156 − j42)/(200 − j500)
  = (52200 + j69600)/290000
  = 0.18 + j0.24 A (rms)
```

(분모 켤레 곱: |200−j500|² = 200²+500² = 290000)

전체 임피던스(V_Th 를 전류로 나눔):

```
Z_Th + Z_L1 = V_Th / I = 300 / (0.18 + j0.24)
            = (54 − j72)/0.09 = 600 − j800 Ω
```

따라서

```
Z_Th = (600 − j800) − (200 − j500) = 400 − j300 Ω
```

**(a) 최대전력 정합 — 켤레**:

```
Z_L = Z_Th* = 400 + j300 Ω
```

**(b) 최대 평균전력** — 정합 시 표준식(rms):

```
P_max = |V_Th|² / (4·R_Th) = 300² / (4·400) = 90000/1600 = 56.25 W
```

**(c) 500 Hz 부품 구성** — Z_L = 400 + j300 Ω 은 **저항 + 인덕터 직렬**(리액턴스 +j300 이므로 인덕터):

```
ω = 2π·500 = 3141.59 rad/s
X_L = ωL = 300  ⇒  L = 300/3141.59 = 95.49 mH
```

→ R = 400 Ω 저항과 L ≈ 95.49 mH 인덕터를 직렬 연결.

## 5. 검산·직관 (Sanity check)

- **역검증**: Z_Th = 400 − j300 으로 분압 재계산 → V_ab = 300·(200−j500)/(600−j800) = 300·(0.52 − j0.14) = 156 − j42 V ✓ (주어진 값과 일치).
- **켤레정합 의미**: Z_Th + Z_L = (400−j300)+(400+j300) = 800 Ω 순저항 → 리액턴스 완전 상쇄, 회로가 순저항이 되어 전력 최대.
- **전력 평형**: 정합 시 부하전류 I = V_Th/(800) = 0.375 A (rms). P_부하 = I²·R_L = 0.375²·400 = 56.25 W ✓. 내부 R_Th 에도 동일하게 56.25 W 소비 → 효율 50% (최대전력전달의 특징).
- **단위·rms**: V rms 사용했으므로 P 식에 ½ 없음, 차원 W 정상.

## 6. 한 줄 요약

> 보이지 않는 내부는 Thevenin 으로 압축 — 무부하 전압이 V_Th, 테스트 부하의 분압으로 Z_Th 를 역산한 뒤 Z_L = Z_Th* 로 켤레정합하면 P_max = V_rms²/(4R_Th).
