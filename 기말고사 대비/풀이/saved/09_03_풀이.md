# 9.3 풀이

> 출처: 교재 9장, 사용자 첨부 이미지, 1순위 근거 9주차 강의노트·정리노트, 풀이일 2026-06-08

## 문제 원문

Consider the sinusoidal voltage v(t) = 25 cos(400πt + 60°) V.

a) What is the maximum amplitude of the voltage?
b) What is the frequency in hertz?
c) What is the frequency in radians per second?
d) What is the phase angle in radians?
e) What is the phase angle in degrees?
f) What is the period in milliseconds?
g) What is the first time after t = 0 that v = 0 V?
h) The sinusoidal function is shifted 5/6 ms to the right along the time axis. What is the expression for v(t)?
i) What is the minimum number of milliseconds that the function must be shifted to the left if the expression for v(t) is 25 sin 400πt V?

---

## 1. 문제 정리 (Setup)

주어진 신호: v(t) = 25 cos(400πt + 60°) V

표준형 v(t) = V_m cos(ωt + φ) 대조:

| 파라미터 | 읽은 값 |
|---|---|
| 각주파수 ω | 400π rad/s |
| 진폭(peak) V_m | 25 V |
| 위상각 φ | 60° = π/3 rad |

**규약**: peak 표기. t 단위 초[s]. 각도 °와 rad 병기.

---

## 2. 무엇을 묻고 왜 이 도구인가 (개념 동기)

9.1과 동일한 정현파 특성값 직독 문제이지만, (h)(i)에서 **시간축 이동 ↔ 위상 변환** 관계를 추가로 묻는다. 오른쪽 이동 Δt → 위상 −ωΔt, 왼쪽 이동 → 위상 +ωΔt. (9주차 정리노트, p.3: ω = 2πf, T = 1/f)

---

## 3. 핵심 통찰 (Aha)

**시간 이동 Δt ↔ 위상 변화 ωΔt**: 오른쪽 이동이면 위상을 빼고, 왼쪽 이동이면 위상을 더한다. (h)(i)는 이것의 역 — "목표 위상을 맞추려면 얼마나 이동해야 하나?"

---

## 4. 풀이 (Worked solution)

### (a) Maximum amplitude

V_m = **25 V**

### (b) f in hertz

(9주차 정리노트, p.3: ω = 2πf)

$$f = \frac{\omega}{2\pi} = \frac{400\pi}{2\pi} = 200\ \text{Hz}$$

### (c) ω in rad/s

ω = **400π ≈ 1256.64 rad/s**

### (d) Phase angle in radians

φ = 60° = **π/3 rad**

### (e) Phase angle in degrees

φ = **60°**

### (f) T in milliseconds

$$T = \frac{1}{f} = \frac{1}{200}\ \text{s} = 5\ \text{ms}$$

### (g) First t > 0 where v = 0 V

cos(400πt + π/3) = 0 조건:

$$400\pi t + \frac{\pi}{3} = \frac{\pi}{2} + n\pi \quad (n = 0, 1, \ldots)$$

$$400\pi t = \frac{\pi}{6} + n\pi$$

n = 0에서 최소 양의 해:

$$t = \frac{\pi/6}{400\pi} = \frac{1}{2400}\ \text{s} = \frac{5}{12}\ \text{ms} \approx 0.4167\ \text{ms}$$

### (h) 오른쪽으로 5/6 ms 이동

오른쪽 이동 Δt = 5/6 ms → v(t − Δt) = 25 cos(400π(t − Δt) + 60°)

위상 변화량:

$$\omega \cdot \Delta t = 400\pi \times \frac{5}{6} \times 10^{-3} = \frac{\pi}{3}\ \text{rad} = 60°$$

새 위상 = 60° − 60° = 0°

$$v(t) = 25\cos(400\pi t)\ \text{V}$$

### (i) v(t) = 25 sin(400πt) V 가 되려면 왼쪽으로 최소 몇 ms?

항등식: sin(θ) = cos(θ − 90°) → 목표: 25 cos(400πt − 90°)

왼쪽 이동 Δt → 새 위상 = 400πΔt + 60°. 목표 위상 조건:

$$400\pi \Delta t + 60° = -90° + 360°n$$

$$400\pi \Delta t = -\frac{5\pi}{6} + 2\pi n$$

n = 1:

$$\Delta t = \frac{7\pi/6}{400\pi} = \frac{7}{2400}\ \text{s} = \frac{35}{12}\ \text{ms} \approx 2.917\ \text{ms}$$

---

## 5. 검산·직관 (Sanity check)

- **(g) 검산**: cos(400π × 1/2400 + π/3) = cos(π/6 + 2π/6) = cos(π/2) = 0 ✓
- **(h) 검산**: 25 cos(400πt − π/3 + π/3) = 25 cos(400πt) ✓
- **(i) 검산**: cos(400πt + 7π/6 + π/3) = cos(400πt + 3π/2) = cos(400πt − π/2) = sin(400πt) ✓
- **Δt vs T**: (i) Δt = 35/12 ms = 7T/12, (h) Δt = 5/6 ms = T/6. 모두 T 이내 ✓
- **극한**: φ = +60° → 영점이 위상 없을 때 T/4 = 1.25 ms보다 이른 0.417 ms ✓

---

## 6. 한 줄 요약

> 시간 이동 Δt는 위상 ωΔt 의 가감이므로, "목표 위상 − 현재 위상 = ±ωΔt" 방정식을 풀어 최소 양의 Δt를 구하면 된다.
