# 9.91 풀이

> 출처: 교재 9장, 기말고사 대비/6월10일/문제_6월10일.pdf (p.2), 1순위 근거 9주차 강의노트 (R-L-C COMPONENTS 슬라이드), 풀이일 2026-06-12

## 문제 원문

60 Hz 전원 v(t) = 170 cos(2π·60·t) V 가 R = 50 Ω, L = 0.2 H, C = 40 μF 인 직렬 RLC 회로에 인가된다.

(a) 리액턴스 X_L = ωL, X_C = 1/(ωC) 를 구하라.
(b) 총 임피던스 Z = R + j(X_L - X_C) 와 크기 |Z| = √(R² + X²), 위상 θ = arctan(X/R) 를 구하라.
(c) 전류 페이저 I (피크와 rms) 를 구하라.
(d) V_R, V_L, V_C 를 구하고 E = √(V_R² + (V_L - V_C)²) 로 KVL(페이저 합)을 검증하라.

---

## 1. 문제 정리

| 항목 | 값 |
|---|---|
| 전원 | v(t) = 170 cos(2π·60·t) V, f = 60 Hz |
| R | 50 Ω |
| L | 0.2 H |
| C | 40 μF = 40×10⁻⁶ F |
| ω | 2π × 60 = 120π ≈ 376.99 rad/s |

구할 것: (a) X_L, X_C  (b) Z, |Z|, θ  (c) I 피크·rms  (d) V_R, V_L, V_C + KVL 검증

규약: 피크 진폭 170 V 기준 (rms = 170/√2). 인덕터 +jX_L, 커패시터 −jX_C. 각도 °.

---

## 2. 무엇을 묻고 왜 이 도구인가

정현파 정상상태 직렬 RLC 회로에서 임피던스·전류·각 소자 전압을 구하는 문제다. 시간영역 미분방정식 대신 phasor·임피던스로 변환하면 미분이 사라지고 복소 대수 V = IZ 한 식으로 전부 해결된다.

근거: 9주차 강의노트 R-L-C COMPONENTS 슬라이드 — "Total impedance: Z = R + jX_L − jX_C, X_L = 2πfL, X_C = 1/(2πfC)"

---

## 3. 핵심 통찰

X_L > X_C 이면 유도성 → 전류가 전압보다 뒤지고(θ > 0°), X_L < X_C 이면 용량성 → 전류가 앞선다. 이 부호 하나가 임피던스 위상과 전류 위상 전체를 결정한다.

---

## 4. 풀이

규약 재확인: 피크 기준, ω = 120π rad/s, 인덕터 +jX_L, 커패시터 −jX_C, 전류 위상 θ_I = −θ_Z

### (a) 리액턴스 (9주차 강의노트 R-L-C COMPONENTS)

```
ω = 2π × 60 = 120π ≈ 376.99 rad/s

X_L = ωL = 376.99 × 0.2 = 75.40 Ω

X_C = 1/(ωC) = 1/(376.99 × 40×10⁻⁶)
     = 1/0.01508
     = 66.31 Ω
```

### (b) 총 임피던스

```
X = X_L − X_C = 75.40 − 66.31 = 9.09 Ω  (양수 → 유도성)

Z = 50 + j9.09 Ω  (직교형)

|Z| = √(50² + 9.09²) = √(2500 + 82.63) = √2582.63 ≈ 50.82 Ω

θ_Z = arctan(9.09/50) = arctan(0.1818) ≈ 10.29°

∴  Z = 50.82∠10.29° Ω
```

### (c) 전류 페이저

```
V_s = 170∠0° V  (피크, 기준 페이저)

I = V_s / Z = 170∠0° / 50.82∠10.29°
  = (170/50.82)∠(0° − 10.29°)
  = 3.346∠−10.29° A  (피크)

I_rms = 3.346/√2 ≈ 2.366 A  (rms)
```

시간영역: i(t) = 3.346 cos(2π·60·t − 10.29°) A

### (d) 각 소자 전압 페이저 + KVL 검증

R은 전류와 동위상(0°), L은 전류보다 +90°, C는 전류보다 −90°.

```
V_R = I × R      = 3.346∠−10.29° × 50∠0°        = 167.3∠−10.29° V
V_L = I × jX_L   = 3.346∠−10.29° × 75.40∠90°    = 252.3∠79.71°  V
V_C = I × (−jX_C)= 3.346∠−10.29° × 66.31∠−90°   = 221.9∠−100.29° V
```

페이저 KVL 검증 (직교형으로 합산):

```
V_R =  164.6 − j29.9  V
V_L =   45.1 + j248.3  V
V_C =  −39.7 − j218.4  V
─────────────────────────
합   =  170.0 + j0.0   V  ≈  170∠0° V  ✓  (전원 V_s = 170∠0° V 일치)
```

---

## 5. 검산·직관

- KVL 페이저 합: (164.6 + 45.1 − 39.7) + j(−29.9 + 248.3 − 218.4) = 170.0 + j0.0 = 170∠0° V ✓
- X_L(75.40) > X_C(66.31) → 유도성 → θ_I = −10.29° (전류 뒤짐) ✓
- |Z| = 50.82 Ω > R = 50 Ω ✓ (리액턴스가 더해지므로 Z > R)
- rms 일관성: I_rms × R = 2.366 × 50 = 118.3 V, E_rms = 170/√2 = 120.2 V
  → √(118.3² + (178.4 − 156.9)²) = √(13995 + 462) = √14457 ≈ 120.2 V ✓

---

## 6. 한 줄 요약

> 직렬 RLC 임피던스의 핵심은 X = X_L − X_C 부호 하나 — 양수면 유도성(전류 뒤짐), 음수면 용량성(전류 앞섬), 그리고 |Z| = √(R² + X²), θ = arctan(X/R)으로 크기·위상이 한 번에 결정된다.
