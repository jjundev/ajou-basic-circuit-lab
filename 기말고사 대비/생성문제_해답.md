## 9.91 직렬 RLC 임피던스(유도성)
- X_L = ωL = 75.40 Ω,  X_C = 1/(ωC) = 66.31 Ω  (ω=377 rad/s)
- Z = 50 + j(75.4-66.3) = 50 + j9.08 Ω,  |Z| = 50.82 Ω,  θ = +10.30° (유도성)
- I_peak = 170/|Z| = 3.345 A,  I_rms = 2.365 A
- V_R=167.3, V_L=252.2, V_C=221.8 V (피크) → E=√(V_R²+(V_L-V_C)²)=170.0 V ≈ 170 V ✓

## 9.92 직·병렬 등가 임피던스
- Z_L = jωL = j40.0 Ω,  Z_C = 1/(jωC) = -j100.0 Ω
- Z1 = 30 + j40 Ω,  Z2 = R2∥Z_C = 50.00 - j50.00 Ω
- Z_T = Z1 + Z2 = 80.00 - j10.00 Ω
- |Z_T| = 80.62 Ω,  ∠Z_T = -7.13°

## 9.93 페이저 전압 분배
- Z_L = j40 Ω,  Z_C = -j50 Ω,  Z_p = L∥C = -0.0+j200.0 = j200 Ω
- V_o = 120·Z_p/(40+Z_p) = 115.38+j23.08 V
- |V_o| = 117.67 V(rms),  ∠V_o = 11.31°  → V_s 보다 11.3° 앞섬(진상)

## 9.94 직렬 RLC KVL 합(용량성·모의)

- Z = 20 + j(18.8-132.6) = 20 - j113.78 Ω,  |Z| = 115.52 Ω,  θ = -80.03° → 용량성(X_C>X_L)
- I_peak = 0.866 A,  I_rms = 0.612 A
